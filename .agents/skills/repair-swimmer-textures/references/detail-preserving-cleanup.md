# 保留设计的角色贴图精修

执行质量与交付门槛前，完整阅读[角色模型贴图精修规范](../../../../docs/角色模型贴图精修规范.zh.md)。该规范用于已有设计的源贴图修复，不授权重新设计、运行资源替换或外部上传。

## 任务路由

- 用户说脏花、颜色毛边、头发／袜子杂色、三角错色或清晰重绘：先走本流程。
- 暗部已确认为皮肤底色中的烘焙阴影：再使用主技能的局部 `repair-shadow` 流程；服装接缝不是腋下阴影。
- 请求换色：按主技能选择遮罩／白色键。已标定为换色区的绿色设计块保留换色语义，固定绿色点缀不自动并入；不把绿色当作污染整体清除。
- 严重碎片化／重叠 UV 阻碍保真：转入 [UV 重排技能](../../character-uv-repack-pipeline/SKILL.md)，说明需要改变的结构与额外验证；不要自动重排。
- 真正的网格、权重或动作问题：转对应 Blender／动作技能，不能靠涂色处理。

## 局部工作循环

1. 建立源文件、已确认版、候选版；审计尺寸、计数与绑定信息，不覆盖唯一源。
2. 在模型上确认问题，分别看无光照底色与正常光照。建立受保护设计清单和区域清单。
3. 只对已确认区域修色／重画。选择时结合空间、拓扑、权重和原图颜色；核验轴向与颜色空间，模型专用数值不可迁移为默认阈值。
4. 灰白区域去非设计杂色并保留明暗；颜色交界处保持衣片走势、滚边宽度和图案可辨识度。
5. 对连续的跨 UV 分色，核对邻接面采样；必要时在模型表面拟合后离线烘焙。候选面覆盖跨界三角，实际修复遮罩保持局部。
6. 用同机位、同材质、同灯光回看；同时检查原分辨率与交付分辨率。所有生成／重绘结果先作为候选，不以图集清晰代替模型检查。
7. 只替换图片时检查非图像数据不变；若重新导出，比较结构、绑定与动画数值。最终重新导入并核对实际使用的贴图版本。
8. 按规范分开报告源美术、换色动作、运行时验收状态，交付实际文件路径和残留问题。

## 禁止替代手段

- 不用整张模糊、扩大擦除或大面积平涂代替边界绘制。
- 不因为细节尺寸小就删掉已确认设计；无法在运行预算内保真时单独提出设计取舍。
- 不把真实袜褶、发束、轮廓凹口和所有深缝当作脏色。
- 不让整张图集重绘新增纹样、换掉标识或改变衣片分界。
- 不根据单次案例提高所有角色的分辨率、材质数、面数或更改色彩阈值。

## 复用边界

项目案例文件可帮助理解修复方式，但不是共享技能的执行依赖。坐标区间、骨骼别名、裤边高度、鞋底曲线和色值均需按新模型重新测量。通用代码经参数化、测试后才放入本技能的 `scripts/`；本地模型专用脚本不直接升级为通用工具。
