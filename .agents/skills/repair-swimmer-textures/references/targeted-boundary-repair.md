# 定点修边与黑斑处理

适用于大面积去噪后仍有局部毛边、黑斑，尤其是用户提供近景标注的情况。基础保真流程见 [保留设计的精修流程](detail-preserving-cleanup.md)。

## 从标注建立修复范围

先为每处问题建立固定近景机位，记录实际部位、污染、应保留的设计和分界终点。底色视图用于辨别贴图污染，同光照视图用于检查实际观感；最后补看正、背、左、右全身。全身看起来干净不代表近景通过，也不能未经定位就把真实缺陷归因于低分辨率。

保护皮肤、服装的含义是保护未受污染的设计，不是整块跳过。手背等皮肤上的已确认棕黑污染仍应局部修复。深色既可能是污染，也可能是屏幕、拉链、鞋口、后跟或外底；不能只靠亮度阈值或多数滤波处理，否则容易截断细黑带。

## 在模型表面定义连续边界

- 结合模型空间、拓扑及原色结构测量边界，让相邻三角使用同一连续分界。候选面需覆盖跨界三角，实际改色仍由局部覆盖限制；不要逐 UV 岛独立填色或全图模糊。
- 袖口沿真实袖轴拟合，左右独立检查，保留滚边宽度；袜口沿真实高度修边。鞋底还要保留侧面上翻走势与细黑结构。
- 圆形装饰可按原轮廓拟合圆／椭圆后局部重画，同时保留外圈、背壳及独立亮斑，不能借清理改设计。
- 拉链、前襟等长条结构同时核验走向、宽度与终点。空间窗口只是候选范围，不能让拉链延伸到衣摆以下的内搭，或把表屏涂到表带尾部。
- 每轮回贴检查新出现的裂线、缺口和越界。例如鞋带白裂线、鞋底白缺口，即使原黑斑消失也不能视为修复通过。

图像生成结果先作为候选。若回贴出现逐岛明暗跳变、错位或新增纹样，应拒绝直接替换整张图集，改用经过核验的局部结果或模型空间重画。记录最终采用的来源，不能把未采用的生成候选描述为成品。

## 离线采样与合成检查

- 模型空间定位图可离线超采样以保留细边。尺寸改变时同步检查坐标换算、数组形状和裁剪上界 `N-1`，防止仅覆盖部分图集。
- 合成前处理遮罩外的非有限值；`NaN * 0` 仍为 `NaN`，不能依靠乘零保护未编辑像素。仅在有效覆盖内写入，并检查输出为有限值。
- UV 岛扩边只延伸到空白 padding，不能串入相邻岛。扩边距离按采样倍率与岛间距确定，不沿用单个案例的像素常数。
- 同分辨率局部交付应比较解码像素，确认编辑覆盖外与选定基线一致。覆盖遮罩是编辑记录，不等同于运行时 R/G/B 换色遮罩。
- 仅替换 GLB 内嵌图片时，逐字节比较非图像 bufferView，并核对节点、材质及 accessor 等结构描述，排除图片外的意外改动。重新导入确认实际贴图版本；结构不变和视觉合格分别报告。

## 源美术版与运行规格

高采样源美术版可保存新绘制的细边，同时保留原尺寸对照以判断缩图损失。未重绘部分仍继承原图细节，不能宣称整个模型获得新的高清细节。源版分辨率不自动成为移动端预算，也不授权替换游戏资源。

交付时区分原始版、修复基线、最终版、近景对照和审计。用户认可源美术效果只记录为该版视觉认可；换肤、服装换色、动作、选择／草稿／存档、Creator 实际导入和真机检查须分别记录，未执行即未验证。重新导入得到的 `.blend` 检查副本也不能称作分层绘画源文件。

## 本地案例：蛙帽少年 v3

本次用户认可的是六处定点精修：帽饰、腕表与手背、左袖口、右袖口、袜鞋、领口与拉链。此前仅清大面积颗粒或扩大去噪仍不足，按上述部位重画连续边界后获得认可。

项目相对目录 `tools/characters/f073_cleanup/` 保存案例文件（本地参考，不是技能执行依赖，也不表示已提交或同步）：

- `Character_FineRefined_v3_source2048.glb` 与 `Character_FineRefined_v3.glb`：2048 源美术版与 512 规格对照；尺寸仅适用于本例。
- `v3六处修前修后.jpg`、`v3规格和全身对照.jpg`、`精修说明-v3.md`：视觉基线、残留细边和交付范围。
- `compatibility-audit-v3-source2048.json`、`compatibility-audit-v3.json`、`local-composite-audit-v3.json`：最终文件与结构／像素审计。

本例保留 1 网格、1 材质、4007 顶点、5601 三角面、41 骨骼，7 个非图像 bufferView 字节不变；512 对照版覆盖外像素与 v2 一致。最终未直接采用生成整图。源模型无动画片段，结构检查不能代替动作验证；本例未完成游戏接入和真机验收。极近景仍有少量不规则细边，用户认可不等于全部像素瑕疵消失。

本例专用脚本、坐标窗口、颜色阈值、鞋底曲线及采样尺寸留在工作目录；复用时重新测量，不提升为全部角色的默认参数。
