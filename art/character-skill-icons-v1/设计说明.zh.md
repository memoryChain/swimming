## 图二的造型分析

1. **外轮廓先于内部细节。** 拳头、盾牌、骷髅、火焰等主形靠轮廓即可辨认，内部细节多用背景色镂空。适合技能栏快速扫视。本套保留这个层次，并进一步扩大主要色块。
2. **弧线有动作含义。** 参考里的环绕笔势常用来表示旋转、恢复、持续或加速；冲击类则更多采用斜切、尖端和放射结构。弧线不能仅为凑圆而添加，本套只在涟漪、跳跃轨迹、猫的回正、蹬墙反弹与火轮等确有含义的地方使用。
3. **粗壮根部与收尖末端形成力量感。** 参考并非均匀线宽的线性图标，粗细节奏和方向性让它更像游戏能力符号。本套以饱满块面建立主体，水流、尾迹和火焰保留收尖。
4. **轮廓多样，但中心和体量统一。** 参考有对称、旋转、斜向和横向构图。本套分别采用水滴的稳定中轴、跃蛙与踢腿的斜线、胸甲的对称、火轮的循环以及冲撞的横向力量，避免十枚都成为环形纹章。
5. **小尺寸需要比参考更少的细节。** 图二中部分细环、短刺和多重装饰，在图一的技能尺寸下容易粘连。这里以大块负空间和少数辅助符号替代细碎纹样；保留教练肺部图标的平面、清楚、略亲和的方向。

## 统一规则

- 圆底统一为不透明深灰 `#303638`。这是本轮预览色值，正式接入时应复用游戏已有底板并核对其透明度。
- 一枚图标只用一种主题色。前景和圆底分别呈现；原始图标 PNG 没有角色名、技能名或按钮文字。
- 大图用于检查造型，每枚另附 48、64 像素圆底预览。可切换「同色辨识」，排除颜色对辨认的帮助。
- 主题色预览用 PNG 透明轮廓作为 CSS 遮罩，以指定纯色显示；不依赖生成稿内部的轻微色差。原稿视图用于核对原始 PNG。此处是离线设计展示，并非建议在 Cocos 中使用 CSS 或逐帧绘图。
- 健身教练对照图直接复制现有 `assets/race/ui/lobby-b/skill-breath.png`，没有重新生成。

## 文件与复现

- `preview.html`：自包含交互预览，包含主题色、同色辨识及生成原稿三种视图。
- `overview.png`：主题色总览；`overview-monochrome.png`：同色总览。
- 十枚以技能 ID 命名的 PNG：内置 ImageGen 独立生成的透明原稿，均为 1254 × 1254。
- `manifest.json`：角色、技能、颜色、图形描述与共用提示词。
- `build-preview.py`：仅构建 HTML，不修改源图像像素。
- `render-preview.cjs`：使用 Playwright 与独立无界面 Chrome 截取离线 HTML。需要本机可用的 `playwright` 模块和 Chrome。

飞毛腿另做了一次局部修订：保留池壁、脚掌、腿和反弹箭头构图，删除生成稿多余光晕、渐变和腿部细窄装饰镂空，将接触处碎片简化为一枚三角符号。最终原稿为修订后的版本。

已查看主题色及同色总览和 48／64 像素样式。细节在 48 像素下会有所合并，主体符号仍可区分；这些是设计预览检查，不代表已完成 Cocos 内实机验收。当前未写入 `assets`，无需触发 Creator 导入或纹理压缩策略。

## 饱满度修订

按用户反馈，仅修订蛙少、忍者哥、潜水哥。沿用原配色、技能含义和透明剪影形式，通过内置 ImageGen 修改原稿：

- 蛙少：增大头腹和后腿，远处的细长跃动轨迹收为贴身双弧。
- 忍者哥：加宽掌心及手指，缩短飘带，收紧手掌与命中标记之间的构图。
- 潜水哥：加厚头部、躯干与四肢，水面靠近泳者，气泡简化为一枚。

以 alpha ≥ 128 的像素数除以画布总像素数，实色面积占比由蛙少 9.6% 增至 27.9%、忍者哥 13.8% 增至 27.7%、潜水哥 11.8% 增至 22.0%。此指标用于验证主体面积变化，不能代替视觉判断。已查看更新后的整套总览及同尺寸前后对照。

`history/before-fuller/` 保留三枚旧原稿；当前同名 PNG、`preview.html` 和总览已更新。`fuller-comparison.html`／`fuller-comparison.png` 为修订前后对照，`fuller-revision-prompts.json` 保存本轮完整提示词。仍处于美术设计预览阶段。
