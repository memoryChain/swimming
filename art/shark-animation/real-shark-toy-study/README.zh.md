基于 `../archive/SharkModel_pre_D.blend` 的实际网格修改，原作者源与运行时资源均保留。未调用当前圆头玩具鲨的几何生成器。原躯干与鳍尾比例保持，仅微调鳍尖和眉峰，局部缩短、柔化八个原牙齿部件。保留原七骨架的静止矩阵与蒙皮；本次不改动作时序，不做整段采样。作者源保留原动作，试稿 GLB 不导出动作，不能直接当作已接入的动画替换件。

蓝青与浅腹色使用单顶点色材质，无贴图。气阀背盘逐点贴合原后侧壳面，底层有 0.001 模型单位的受控嵌入，软塞与背盘相交 0.0015，连体拉片从塞侧延伸。两侧细接缝沿实际网格射线落点制作。背盘、软塞、拉片和接缝在作者源中可独立选择；仅导出副本合并为单蒙皮网格。

造型拆分为：原头身与收腰、原背鳍与胸鳍、原分叉尾、原眉眼与嘴部、后侧气阀、侧壳接缝。原模型约长 0.998、含胸鳍宽 0.596、含背鳍高 0.510；没有鼓大头腹。六面用于检查轮廓与附着关系；原版对比和新试稿使用同一离线灯光与镜头。

复现（项目根目录）：

```powershell
python scripts/run-blender.py -- --python art/shark-animation/real-shark-toy-study/build_study.py
python scripts/run-blender.py -- --python art/shark-animation/real-shark-toy-study/render_study.py
node art/shark-animation/real-shark-toy-study/build_review.cjs
```

Blender MCP 工具检索无可用工具，因此使用仓库后台入口。此轮只做造型试稿，未启动、重启或截图 Creator。原版配色用于对照，不代表要恢复原来的玩法伤害表现。正式动画适配、图标统一、引擎水线与手机画面在造型方向认可后的接入阶段验证。
