# 垃圾漂流低模资产

本目录保存“垃圾漂流大乱斗”的可复现 Blender 源资产。运行时继续使用共享顶点色网格，不加载贴图。

## 分类与轮廓

- `RigidLitter`：硬质垃圾。主体为一只横卧的可乐塑料瓶；连续十边形截面依次形成瓶盖、细颈、肩部、瓶身、红色环绕标签和收底。长径比约 `2.9`，碰撞时会被明显拨走并快速翻滚。
- `SoftLitter`：软质垃圾。主体为扁薄零食袋；不规则边缘形成包装褶皱，上下有压封边，正面以实体薄层形成徽标和两条折痕。厚宽比约 `0.17`，水面姿态更扁并带轻微鼓动。

两者都采用硬边低多边形、单网格、单顶点色材质。运行时最多十个节点，只在类型变化时切换两份共享网格。
可乐瓶运行时统一缩放为 `0.72`，最终可见长度约 `0.66m`；几何源保持标准化尺寸，便于继续调整轮廓和共用重建脚本。

## 接触关系

- 可乐瓶所有相邻截面共用端环，没有瓶盖、瓶颈或标签之间的悬空间隙。
- 零食袋上下压封边各与袋身重叠 `0.05m`，不会在旋转时露缝。
- 正面徽标和折痕只向袋身前方抬高 `0.001m` 后起厚度，避免明显悬浮。

## 重建

配置 Blender 后，从项目根目录运行：

```powershell
python scripts/run-blender.py -- --python art/litter-debris/build_litter_debris.py
```

脚本会重建 `LitterDebris.blend`、导出 `LitterDebris.glb`，并写出 `litter-debris-audit.json`。这些文件用于源模型复核；游戏内网格由 `LitterDebrisGeometry.ts` 的同组尺寸生成，避免额外 Prefab、贴图和异步加载。
