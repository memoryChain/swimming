# 泳道水花第二版

美术源稿由内置 imagegen 生成，经用户确认的概念方向制作；本目录保留原始 RGBA，运行时只使用缩小后的贴图。不是截图加工出的运行时粒子。

生成约束：低矮、紧凑的半透明浅青水片，少量白边高光与水滴，避免实白核心和长尖刺；尾流由断续泡沫构成，后端稀疏淡出；波纹为中心透明、有缺口的单圈水面贴花。两格图集左侧尾流、右侧波纹，所有边缘保留透明留白。

导出：`python3 scripts/export-swimmer-water-art.py`（需 Pillow）。当前输出为 512×256 的 4×2 水花序列帧与 512×256 水面图集。旧单张水片源稿保留作对照。缩放仅做离线尺寸适配，运行时不生成贴图。

Creator 导入后执行 `npm run textures:fix` 和 `npm run textures:check`；保持现有水花贴图 UUID。
