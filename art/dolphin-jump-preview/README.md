# 海豚跳特效预览

本目录仅保存视觉预览，不在运行时资源目录中，也未接入正式游戏脚本。

`preview.js` 在已加载游戏的独立浏览器中执行，定义 `installDolphinSplashPreview(splash, cc)`。传入当前角色的 SplashEmitter 实例和引擎命名空间，返回 `events` 与 `restore()`。它临时替换该实例的 `triggerBigSurfaceBurst`；使用既有真实起落事件和既有水花素材，不修改起跳轨迹、速度或能量判定。录制时使用近景镜头，手动提供满能量以启动原有海豚跳。

- 破水：一张约 1.55～1.8 米宽的主水片，水滴向两侧后方抬起。
- 落水：主水片扩大到约 1.8～2.1 米，水滴向两侧散开，重用一圈短波纹。
- 每拍一张水片，两侧分别 6 粒主滴 + 3 粒细滴；没有空中持续发射，没有新增粒子系统或纹理。
- 已录到一次真实破水和一次真实落水事件，序列截图用于检查时机、轮廓和消散。

预览约束：通过当前事件强度 2.6/3.2 区分起落，仅用于直线近景方案验证；正式接入应使用明确阶段参数并检查转向、反向与远端角色。尚未实现空中滴水或延迟分段落水，也未做微信真机性能验收。

刷新页面可完整恢复所有粒子参数；`restore()` 仅恢复原事件方法。源码可通过 `node --check art/dolphin-jump-preview/preview.js` 检查语法。正式接入前按仓库动效与特效规范验证生命周期、坐标、预算与联机。
