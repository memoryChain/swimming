# 比赛 UI 第二版：轻松派对风

用户明确纠正：机甲是角色皮肤，游戏不是科幻题材。整体参考《元梦之星》这类轻松游戏的圆润、明亮、亲切感，不复制其品牌、角色或专属图标。

## 本版视觉准则
- 奶白实心圆角卡片、湖蓝软边、短而柔和的落影；消除黑色仪表、玻璃屏、细线霓虹边与尖锐斜切。
- 湖蓝与青色是主色，柠檬黄是本人或关键状态强调，珊瑚橙用于低体能/延迟；文字用深蓝保证水面背景下可读。
- 图标饱满，口令和连击用圆润运动贴纸感；不铺满泡泡、星星和表情脸。
- 3D泳馆、角色及既有结算不属于本次重新设计范围；图中生成背景只用于概念展示。
- 20个状态沿上一版流程，保持隐形左右半屏触控。速度固定左下、读数左上、进度中上、名次右上，评价和冲刺分区。

## 图板
1. 赛事介绍、名单、准备、GO。
2. 低段蓄力、高段蓄力、起跳品质、延迟出发。
3. 常规游进、水下游进、连击、高连击。
4. 冲刺与低体能、蓄气就绪、海豚跳释放、蓄气不足。
5. 排名展开、完赛等待、最后3秒、完赛过渡。

## 交互与实现边界
详细状态、起跳/蓄气阈值、联机权威数据、字体与性能规则沿用第一版的交互说明；视觉色彩与材质以本版为准，不再使用第一版的深色科幻皮肤。
文字、图标、底板分层；头像复用项目现有资源。所有条形读数比例必须取真实数据，概念图比例不作为数值逻辑。参考基准画布1672×941，手机安全区和微信胶囊位置需按实际设备适配。卡片、口令厚边与高光为美术效果，不以运行时大量Graphics或伪粗体实现。

此轮为内置ImageGen视觉概念稿，不是可编辑PSD或透明切图，尚未接入游戏。生成提示词随稿保存。
