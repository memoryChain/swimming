# 比赛开场：赛制与参赛阵容同屏

状态：概念稿，待确认；1290×720；未修改PSD或运行时。

## 设计

- 左上紧凑赛制区：模式、距离与泳姿、人数、难度、胜利目标。
- 下方8列选手卡：泳道号、参赛角色肖像、玩家昵称、角色名。泳道号不代表比赛排名。不同玩家允许选同一角色；本稿用四种现有角色示例，不代表真实对局配置。
- 本人第5卡仅金色细边、昵称及“我”标记。角色卡与玩家头像是两种数据，本页使用角色肖像。
- 中央保留泳池与选手视野；赛前不显示比赛操作HUD。

## 后续动效提案

以下为制作起点，尚未实现或确认：

| 时段 | 表现 |
| --- | --- |
| 0–0.3秒 | 赛制区短距离移入并淡入，场景继续运镜 |
| 0.15–0.9秒 | 卡片从下方移动约16–24px并淡入，每张错开约60ms，无弹跳 |
| 0.9–4.9秒 | 完整同屏停留约4秒，让玩家读取赛制与阵容；本人金色标记保持静态 |
| 4.9–5.2秒 | 信息整体淡出并小幅移出，进入准备与发令镜头 |

用同一时间轴控制，不逐个等待角色加载才入场。联机须由既有比赛阶段控制，视觉播放不自行启动比赛计时。资源未准备时使用稳定占位，不能重新排序泳道或绑定错人。

## PS与接入准备

赛制底、强调线、各行文字分别分层；每张卡独立分组，其卡底、角色智能对象、昵称、角色名、泳道号、本人标记独立。原图与去旧UI修复层分开。可重复使用同一肖像资源，不生成8套重复纹理。卡片动效以节点透明度和位移实现，不逐帧重绘；文字仅在数据变化时更新。画像采用现有资源，概念图不直接切图接入。
