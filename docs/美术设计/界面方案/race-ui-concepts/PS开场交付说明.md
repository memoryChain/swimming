## 开场素材与字体

已按用户纠正替换为当前游戏正式引用的角色卡资源：`assets/race/ui/character-v1/portrait-{id}.png`。泳道1–8依次为cartonSwimmer6（跃浪少女）、cartonSwimmer8（蛙跃潮童）、cartonSwimmer5（逐浪少女）、cartonSwimmer9（霓光灵猫）、cartonSwimmer10（青影忍浪）、cartonSwimmer11（疾风浪客）、cartonSwimmer12（绿电潮童）、muscleMan（铁臂狂鲨）。引用依据为ResourcePaths.ts与PlayerCharacterConfig.ts。蓝帽／红帽抱鸭子是旧PSD占位资源，已从开场稿移除，不再使用。8张立绘为嵌入智能对象，有独立裁切蒙版；昵称、泳道、角色名和本人标记可编辑。排列为静态示例，不代表实际对局身份绑定。

字体按本目录UI规范和源PSD实际字形使用PingFangSC-Semibold、PingFangSC-Medium、PingFangSC-Regular；新稿30个文字层、9个智能对象。角色插画为嵌入智能对象，不依赖外部图片路径。运行时字体打包仍遵守项目ShuiMaster UI政策。
