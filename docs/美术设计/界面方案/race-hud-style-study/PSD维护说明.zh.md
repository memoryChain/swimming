# 比赛 HUD 主文件

后续界面制作以 [项目界面制作规范](../../界面规范/界面制作规范.zh.md) 为入口，用户最新要求与当前 PSD 优先。新页面统一 1290×720；本页保留1672×941主稿和已另存的1280×720分层副本。

## 当前修订
- 新增“12 泳道玩家名字与排名”组，为画面内五位玩家显示名次和名字。名次圆底重建为28×28px正圆、数字使用与右侧列表相同的 PingFangSC-Semibold，字号21px、横纵缩放100%、几何居中，名字20px并带轻微暗色投影；普通排名紫色底，本人金色底。名字、名次与底图分别独立编辑。使用原截图示例身份和排名；此为静态排版，接入时从玩家身份与权威名次读取，屏幕投影位置随角色更新。
- 最新交互：按住对应划水按钮后白点移动，进入完美区间表示完美划水。完美区由单点改为沿弧线的连续绿色区段，带起止边界，左右镜像。完美区已下移靠近尾端，图中暂示 t=0.15–0.35、宽6px，白点示 t=0.65；这些是排版示意参数，不是游戏判定阈值。旧中心点与横向刻度隐藏保留，线条两端渐隐保持。
- 本轮只更新 PSD；未实现按住动画、输入判定或网络同步。用户未明确的松手、越区、重复触发规则不在此擅自定义。
- 背景改回用户最初提供的正常游进截图 `codex-clipboard-1db312f0-48ce-4263-bd8e-9a4f16984fff.png`，项目留存为 `比赛HUD-原始截图.png`。按原画布缩放，原图层与“旧UI清除｜局部修复”层独立保留；仅旧UI区域叠加修复内容，原生成场景层隐藏备份。当前 HUD 图层保持可编辑。
- 可起跳状态：圆环内部增加独立金色按钮面、薄厚度底和弱亮边，海豚改深色以保证识别，外环继续承担蓄气显示；起跳文案位于环外下方。新增隐藏组“备用状态 起跳按下｜隐藏”，按钮面与海豚下移 3px，并隐藏厚度底与亮边。蓄气中状态保持弱化图标。此处为 PSD 状态设计，未接入真实点击事件。
- 起跳海豚依据用户最新黑色剪影参考重绘：长吻、厚实头背、向下弯的身体与宽尾鳍，保留朝左金色效果和可编辑形状层，两个起跳状态均更新。
- 泳程图标保留 A 简洁泳者、B 泳帽护目镜、C 小浮标三个可编辑方案组；这是历史备选，用户后续曾隐藏或删除，最终显示以当前 PSD 为准。对比图为 `泳程图标-三方案.png`。
- 速度数字与单位改用自行绘制的 `ShuiMasterSpeed-Heavy`，已安装到本机字体目录。字体和可复现生成脚本保存在同目录 `fonts/`，包含 0–9、小数点、m、s、斜杠与空格。依据原稿切角粗体重新绘制，不是提取出的原始字体；其他文字继续使用项目 ShuiMaster UI。Jersey 25 已被替换。
- 本次字体仅用于 PSD，未改动游戏运行时字体。后续接入时需将数字字体纳入项目字体构建和打包流程。
- 划水线采用按钮内侧倾斜弧线：右侧从 (1240,808) 弯向 (1392,578)，控制点 (1240,703)、(1272,635)；左侧围绕 x=836 镜像。完美区采用连续弧段，靠下方尾端 t=0.15–0.35，白点示 t=0.65；旧中心点和横向刻度隐藏，两侧镜像。划水弧线增加独立渐隐蒙版，上下两端各约60px由透明过渡到原不透明度。保留原有“完美”文字隐藏状态；曲线与按钮不交叉。

- 唯一可编辑主文件：`比赛HUD.psd`。后续修改均在该文件内进行，每次完成局部改动及时保存，不另建轮次 PSD。
- 画布为 1672 × 941，72 DPI。`比赛HUD-预览.png` 是由 PS 导出的预览，后续随主文件更新。
- 速度、心率、体力、泳程、连击、起跳、左右按钮、左右划水节奏、排名分别分组。文字为可编辑文字层，使用项目字体 `ShuiMasterUI-SemiBold`；底图、圆环及图标为独立形状层。
- 头像已替换为游戏当前 assets/race/ui/avatar-picker-v1/ 的真实头像，按资源目录01–08依次放入排名1–8作静态示例；此顺序不代表真实对局的身份映射。每张为独立嵌入式智能对象，圆外透明，普通头像34px、本人60px，保留原圆框与金色高亮。未更改任何运行时 avatarId、UUID 或资源文件。原设计图保留为隐藏对照层。
- 场景为原始游戏截图，旧状态条、调参、泳程、速度、连击、姓名名次和红色角色标记已局部清除。场景不作为运行时 UI 资源导出。
- 已制作心率正常、起跳蓄气中及起跳按下等备用状态。用户可能调整其保留与可见状态，操作前读取当前 PSD；查看状态时避免与同类默认组重叠。
- 不从效果图裁出带背景的控件。导出按钮时分别导出底图和图标，隐藏文字，文字继续使用运行时 Label。
- `ps-hud-helpers.jsx` 为首次建稿的辅助函数，不自动重建主文件；后续以 PSD 实际图层为准。
- 本次仅 PS 设计分层，未接入 Cocos，也未验证触控与真机表现。
