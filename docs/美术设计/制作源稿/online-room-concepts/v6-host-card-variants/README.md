# 房主卡四版概念设计

## 本次修改

- 模式选择改用浅薄荷、奶白黄、冰蓝或白色控件，去除深蓝底。
- 数字与英文全部使用粗体视觉。
- 四版均为独立房主卡概念；未替换工程资源，也未修改整屏稿。
- 后续整屏合成：房主卡白色卡体的上边缘与右侧成员面板上边缘水平对齐；挂扣位于对齐线上方，不得因挂扣而将整张卡下移。两侧面板底边也应统一，按钮在面板之外。
- 最终落地以可编辑 Label 承载文字，数字英文采用实际粗字体文件，头像复用项目已有资源；概念图不可直接作为含字按钮切图导入。
