# 四版房主卡整屏概念合成

内置 image_gen 合成，输出四张 1280×720 整屏预览。未修改运行时工程或替换美术资源。

- A-mint-1280x720.png：薄荷薄卡。

## 验证及已知局限

已目视确认四版包含8个成员位（房主在内）、浅色赛制选择、粗体数字英文、退出房间与开始比赛按钮。输出属于生成式风格预览而非像素精确合成。已尝试局部对齐修正，但部分版本左右面板边缘仍不完全齐平，少数挂扣细节有变化；不得宣称已完成严格对齐。选定风格后的正式排版仍须统一两侧卡体上边缘及底边，不把挂扣计入卡体高度。
