# 相似字形候选

已安装到当前用户的 `~/Library/Fonts`，并通过 CoreText 字体名称匹配验证。

| 字体 | 用途 | Photoshop 字体与样式 |
| --- | --- | --- |
| Changa One | 粗厚紧凑，斜体最接近概念稿；优先试用 | Changa One / Italic、Regular |
| Bungee | 方正、街机标题感 | Bungee / Regular |
| Russo One | 轮廓利落，作为较克制备选 | Russo One / Regular |

来源为 Google Fonts 官方仓库，三个目录均保留 SIL Open Font License 1.1。字体可用于商业项目，分发时遵守各自 OFL 条款并保留许可证。

- https://github.com/google/fonts/tree/main/ofl/changaone
- https://github.com/google/fonts/tree/main/ofl/bungee
- https://github.com/google/fonts/tree/main/ofl/russoone

这些是相似字体，不是生成概念图的精确原字体。本次仅安装候选字体，未替换用户修改的 PSD 字体或样式，也未添加运行时字体资源。安装后当前 Photoshop MCP 字体列表仍未刷新；若 UI 中搜索不到，保存文档并重新打开 Photoshop 后再查看。
