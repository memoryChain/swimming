# 比赛起跑 HUD

主稿：`比赛起跑HUD.psd`，1290 × 720 px，RGB，72 DPI。

## 已制作内容

- READY：蓝色渐变字面、斜体字形、窄斜面、深蓝轮廓与青色外发光。
- GO：黄色渐变字面、窄斜面、暖棕轮廓与金色外发光。
- 蓄力条：共用矢量槽体与闪电；空槽、橙红低蓄力、绿色中蓄力、金黄高蓄力独立状态组。填充和白色位置标记分层。
- 五个可编辑文字层、十四个矢量形状层；场景原图与局部修复层单独保留。
- 六个图层复合及对应 PNG 预览；`状态总览.png` 用于并排查看。

## 在 Photoshop 中切换

打开“窗口 → 图层复合”，可切换 READY 空槽、低／中／高蓄力、黄色 GO、无中央文字的蓄力状态。默认保存 READY 中蓄力。

也可在“02_发令文字_独立开关”和“03_起跳蓄力条”中手动组合。蓄力条只打开一个填充状态；READY 与 GO 不同时打开。文字样式包含渐变叠加、斜面、描边、投影和外发光，可直接调整。

英文采用已安装的 Avenir Next Heavy Italic，中文采用项目 ShuiMaster UI SemiBold。主稿保留可编辑字体，不将概念图裁出来冒充文字。英文美术字的运行时字体方案需在正式接入时确定。

## 范围与验证

本次仅制作 Photoshop 源稿与预览，未修改运行时资源、字体子集、游戏代码、单机或联机时序，未添加 3／2／1。场景使用用户实际截图，旧竖条和调参按钮在独立修复层局部处理；场景仅作展示，不随 UI 导出。

已检查 PSD 保存状态、像素尺寸、文字与形状类型、六个状态预览。预览不表示游戏内动画或真机验收。PNG 位于 `previews/`，是整屏效果预览，不是透明运行时切图。

`build-ui.jsx` 为初次搭建脚本，在已准备的场景文档上运行；日后修改以现有 PSD 为真源，不重新执行覆盖手动调整。外发光最终参数为不透明度 72%、大小 18 px、扩展 3 px；深色字边保持 2 px，将清晰轮廓与柔光分开。

## 最新局部修订

字效按数字参考改为亮色字面、窄斜面和贴边柔光。READY 保持蓝色，GO 保持黄色；外发光最终为 85%、11 px、扩展 2 px。蓄力槽、填充与白标采用同一中心线，左右留白一致。浅色外框不透明度 45%；“蓄力”文字由 16 pt 调至 19 pt，增加 1.5 px 深色描边，不透明度 60%。六个状态已重新导出核对。

### 发令数字参考效果

最新 READY 与 GO 保留可编辑文字，改为亮色实面、3 px 同色系斜切厚边、窄斜面和 14 px 贴边柔光。GO 使用亮黄与橙金，READY 使用浅蓝与中蓝；新增独立可开关的矢量细光环。不添加数字倒数。主稿目前打开 GO 状态便于对照参考。
