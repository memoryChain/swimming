## 分层与对齐

PSD 包含 17 个图层组、44 个可编辑文字层、146 个形状层、9 个嵌入式智能对象。

顶部导航、房主卡、8 个成员位、底部操作、赛制抽屉分别分组。头像、公共按钮背景、金币/设置资源作为智能对象使用。按钮文案与背景分开；没有将整屏截图作为可见 UI 层。

两侧卡片主体上边缘统一为 `y=102`，下边缘统一为 `y=592`。左卡 `x=76, w=380`；右面板 `x=476, w=744`。挂扣在卡体外向上延伸，阴影不计入对齐尺寸。PSD 内保留对应辅助线。

展开抽屉：显示顶层 `06 赛制抽屉展开态（默认隐藏）`。默认仍保留收起态，未在工程中实现交互。

## 字体

中文及混排文字使用真实字重 `ShuiMasterUI-SemiBold`；独立房间号、等级、货币与席位数字使用 `Arial-BoldMT`。没有用描边、重叠文本或阴影模拟加粗。另一台电脑打开前安装 `fonts/` 内的项目字体，并确认存在 Arial Bold。静态字库来自项目现有自动生成结果，本次未改动字库。

本机已安装项目 Regular/SemiBold 字体至个人 `Library/Fonts`，并通过 Photoshop 字体刷新确认可用。
