# 划水大师潮玩头像图标 v1

## 交付内容

- `source/`：图像生成输出的高分辨率透明源图，便于后续调整。
- `100x100/`：最终游戏图标，统一为 100×100、RGBA、圆形安全区外透明。
- `avatar-icons-contact-sheet.png`：十个头像的透明背景总览。
- `build_icons.py`：统一缩放、居中、圆形裁切与总览图生成脚本。

## 生成提示词摘要

生成模式：内置图像生成工具，逐角色独立生成/编辑。

共同要求：参考新版角色设计的潮玩手办语言；大头小身、圆润塑料与软胶材质、棚拍级柔和光照、黑白基础色搭配荧光绿/粉/橙色点缀；正面或轻微三分之二视角的头肩像；无背景底板、无圆环、无阴影、无文字、无标志、真正透明 PNG。

每张图在共同要求基础上分别保留对应角色的关键识别元素，例如潜水镜、未来感面罩、快递头盔、反戴滑板帽、蛙帽或救生员护目镜。两张误带棋盘格的初稿已通过图像编辑重新提取为真实透明通道；救生员图同时移除了服装文字和医疗十字符号。

## 导入说明

最终文件没有内置蓝色底盘或白色描边，可直接叠放在游戏已有的头像渐变底图和选中框之上。所有可见像素限制在直径约 94 px 的圆形安全区域内，避免超出头像框。
