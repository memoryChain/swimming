# 定时水球模式玩法说明

更新日期：2026-09-22。C1／C2 首版资源与运行时接入已完成，使用 B1 浮圈恢复和 B2 共用喷水。本文沿用原文件名以保持链接；“定时炸弹”是历史题材，当前展示为定时水球。

## 定位与兼容

定时水球是 200 米娱乐玩法，也作为统一娱乐的争夺事件运行。模式入口 ID 保留 `timed-bomb-brawl`，规则 ID 保留 `timed-bomb`；旧 `mine-relay-brawl`／`mine-relay` 选择仍按现有逻辑迁移。内部 `bomb`、`fuse`、`exploded`、`disarmed` 标识仅作兼容，不代表当前画面仍使用炸药。

独立玩法全程安排 6 轮，在领游者到达 24、52、82、112、142、168 米时依次触发。统一娱乐使用导演的压缩轮次与赛程锚点，详见[统一娱乐说明](统一娱乐模式玩法与实施计划.zh.md)，不能将独立模式参数覆盖到统一模式。

## 核心规则

- 每轮按比赛共享种子，从仍在比赛且未处于浮圈调整／恢复保护的选手中选择初始携带者。优先从纵向约 4.8 米、横向约 5.4 米内确实存在可追目标的人群中随机；全场没有合适人选时才回退到全部有效选手。
- 三层传递依次为：消费人物碰撞求解器的真实接触记录；双方身体椭圆与前后帧相对路径扫掠；持续对齐后的定向短传。贴身静态总范围为纵向 1.6 米、横向 1.3 米。辅助短传要求同向前方 0.4～2.8 米、横向差不超过 1.2 米，并对同一目标连续对齐 0.18 秒；不会任意传给身后或横向未对齐的人。
- 初次接球保护 0.55 秒，后续传递冷却 0.45 秒，上一携带者有 1.1 秒防回传保护。锁定期间所有交接停用；超过 3 米的相对位置校正不沿整段补传。
- 最后 0.8 秒锁定，不能转交。倒计时归零后水球破开喷水，携带者进入 3.5 秒浮圈调整：先失衡、落稳，再找圈、双臂搭圈，头露水面并保留眩晕星。空中和潜水命中沿共用落水／回到水面流程衔接，不表现为持续失能下沉。
- 调整结束后在权威赛程进度与本泳道中心以零速度恢复，获得 2 秒保护。保留旧位置闪退、隐藏换位、新位置闪入和稳定保护光；恢复阶段开始即释放控制，视觉闪入不延迟操作。
- 喷水外围范围约为纵向 5.2 米、横向 4.2 米。其他有效选手受冲击、翻滚和失速，但不因此进入浮圈调整；携带者是本次唯一直接击倒对象。
- 范围按 `RaceCourseLayout.distanceToWorldX()` 换算后的泳池实际坐标判定，包含折返与场景长度校准；不能直接相减累计赛程。短传前方按当前泳向计算，迎面真实近身接触仍可交接。
- 水球结算不写永久淘汰或 DNF；泳者节点、主镜头目标及原体力／角色能力状态沿用既有规则。
- 携带者在归零前冲线，或已离开有效比赛状态，本轮按原解除规则结束；带球冲线显示“成功带球冲线”。
- 携带者被其他事件击倒时，水球按既有状态保留，调整期间暂停倒计时。调整或保护中的选手不能成为新的初始携带者或接收者。

## 模型与完整表现

- 正式资源为 `assets/race/items/TimedWaterBalloon.glb`：橙色主体、宽黄色瓣、扎口和短软连接件，2 网格、1 个不透明顶点色材质、696 三角面、无贴图。作者源与复现脚本见[源目录说明](../art/timed-water-balloon/README.zh.md)。
- 使用 `TimedWaterBalloonMount.ts` 的 11 个体型配置，挂点跟随真实 `Spine02` 肩背骨。实例仍由世界根管理，避免角色模型销毁时误删；模型重建后重新取得挂点。潜水、海豚跳和翻滚时跟随肩背，不把道具强留水面。
- 首次投放沿原看台来向，约 0.55 秒飞到正在移动的肩背挂点；可靠事件实时播放，快照或模型晚加载直接补当前状态。
- 随倒计时将球体从 1.00 倍鼓胀到约 1.22 倍，连接件不跟着放大。摇摆／抖动从本轮时间派生，锁定时增强短促抖动；不改变碰撞判定。
- 转交立即改变权威归属，同一枚球再沿约 0.22 秒、弧高约 0.55 米的短弧飞到新携带者。飞行时隐藏软连接件，保留鼓胀和剩余时间，不出现两份有效球。
- 到时先记录解绑前球体真实世界中心，再隐藏模型，向 B2 提交局部碎水中心与同 X/Z 的水面点。局部喷水随球体实际高度出现；外围命中仍使用权威事件中的赛程与横向位置。
- 带球冲线时约 0.28 秒泄气退出。重开、离场和销毁清掉挂点引用、短传、泄气、显隐与共享池 owner；迟到加载回调不能复活上一局道具。

## HUD、广播与画中画

- 持续条沿用无图标斜切组件，携带泳道、剩余时间、锁定和剩余轮数均为程序文字；10Hz 采样并比较最终字符串／颜色后更新。锁定提示为“即将喷水 · 无法转交”。
- 使用“水球接力”“水球喷水”“带球冲线”等受控栏目；统一导演保留二十组确定性预告／行动广播。收到、传入和传出走个人反馈；到时进入 B1 后不再叠加重复大提示。
- B1 恢复卡的小状态签固定“调整中”，正文每次受击确定一句轻松提示，整次调整内不换句；按既有规则保留循环点号。暂停与保护的控制规则由共用恢复系统负责，详见[统一恢复规范](统一娱乐模式玩法与实施计划.zh.md#9-击倒浮圈调整与连锁保护)。
- 主镜头沿用普通比赛的 `RaceCameraDirector`。事件画中画复用唯一 `RaceEventPictureInPictureCamera`，读取实际球体与携带者位置，水下／空中不强锁水面。
- 首次发放约显示 1.2 秒；转交时已有镜头平滑转向，关闭后约重开 0.8 秒，连续转交受 1 秒重开冷却限制。最后锁定阶段保持观察直到结算；结果约保留 1 秒，到时视角拉开容纳喷水与浮圈恢复。
- 保留鲨鱼接触／水炮即时事件优先于定时水球、定时水球优先于漩涡教学的让位规则。受占用时缓存最新携带者，锁定时待镜头空闲再接续。画中画不能替代主画面球体、持续条与个人反馈。

## 联机与边界

- 单机与房主负责发放、传递、倒计时结算与解除。结果随机来自权威状态与 `SharedRNG`；访客只显示计时并应用权威事件／快照。AI 携带者仍主动接近对手，原接球保护与非携带者避让窗口不变。
- 可靠帧发送发放、转交与结算；结算携带权威赛程、横向坐标和外围冲击泳道掩码。快照保留当前轮次、携带者、计时、冷却、完成账本及各泳道调整／保护阶段和恢复距离。
- 完成账本、结果事件和携带者击倒分别去重；快照先到不吞外围冲击，下一轮开始后旧事件不能清掉新球、重置计时或覆盖新轮镜头。超过 3 秒的旧冲击不补施；返场代次和比赛身份继续拒绝旧局事件。
- 广播降级复用与浮标、硬垃圾共用的有界恢复缓存：最多 32 条、3 秒有效，每次周期快照至多补发 4 条；持续断流不保证递送。无新增水球表现协议字段。
- 接触消费、扫掠、短传候选和 0.18 秒确认仅由房主运行。确认进度不入快照，房主迁移后最多重新确认 0.18 秒；不按客机画面重新判定归属。
- 统一娱乐首位选手完赛后取消未发放轮次，只让当前水球自然结算。取消通过 revision、完成掩码和快照恢复；没有当前球时关闭持续条。重赛保持现有会话，不调用 `endGame`。
- 当前协议版本以 `assets/scripts/net/NetRaceProtocol.ts` 为准。此前 v82、v92、v93 是相关功能演进记录，不能作为当前混房版本值。

## 性能与资源生命周期

- 同一时刻复用一枚水球，不在传递时新建模型、材质或碰撞体。装饰摇摆／鼓胀按 20Hz 采样，世界挂点跟随与玩法计时不受装饰频率限制。
- B2 使用原 `TIMED_BOMB` owner 与 `EXPLOSION` 档，强度 1.25、总时长 0.95 秒。视觉为白蓝局部碎水、水冠、弧形水柱和错时余波；局部碎水约 0.304 秒前收低，主体约 0.589 秒前落下，余波随后退出。不使用暖色爆心或完整爆压球壳。
- 共用轻 4／重 3／冲击 3 槽；水球不另建喷水池。局部与水面位置在触发时复制，不跟随之后移动的选手；C 的模型、HUD、镜头和 B2 池各自按既有 owner／生命周期清理。
- 镜头复用 256×144 RenderTexture，最高 30Hz，隐藏时关闭；HUD 字符串只在显示值变化时更新，隐藏状态零文字／几何工作，不使用逐帧 `Graphics` 重绘特效。
- E 的浮标已解除对本模块旧水雷几何帮助函数的依赖；旧导出仅为兼容保留，当前水球模型不使用它们。
