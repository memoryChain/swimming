# 定时炸弹模式玩法说明

## 定位

定时炸弹模式是 200 米娱乐玩法。模式入口 ID 为 `timed-bomb-brawl`，规则 ID 为 `timed-bomb`。旧 `mine-relay-brawl`／`mine-relay` 选择会在读取时迁移到本模式，不再显示旧“漂雷传递”入口。

## 核心规则

- 全程安排 6 轮炸弹，领游者到达 24、52、82、112、142、168 米时依次触发。
- 每轮通过比赛共享种子，从仍在比赛且未处于急救／重生无敌阶段的选手里直接随机选择初始携带者；不会先在泳池中生成漂浮水雷。
- 携带者贴近另一名未处于急救／重生无敌阶段的选手时自动传出炸弹。传递有全局冷却，且上一名携带者短时间内受防回传保护。
- 引信最后 0.8 秒锁定，不能再传递。归零时当前携带者遭受致命爆炸，进入 2.5 秒急救阶段；随后在原赛程进度和自己的泳道中心以零速度重新入水，并获得 2 秒无敌保护。
- 爆心外围约纵向 2.8 米、横向 2.35 米内的其他选手会被冲击波击退、翻滚并失速，但不会进入急救；携带者始终是唯一直接击倒者。
- 爆炸不会写入永久淘汰或 DNF；泳者节点、镜头目标和既有体力／角色能力积累继续复用。
- 携带者在引信归零前冲线，或已经离开有效比赛状态，本轮视为拆弹成功。

## 表现与操作

- 炸弹使用独立的低多边形模型：三根红色炸药管、两道深色绑带、顶部计时器和橙色警示灯，不再复用水雷模式的带刺球模型。
- 炸弹直接挂在携带者身上，以轻微摇摆保持计时器可辨认；警示灯随剩余时间加快闪烁。
- HUD 使用娱乐玩法统一的持续状态条外观，以 10Hz 更新携带泳道、剩余时间、锁定状态和剩余轮数；文本与颜色只在结果变化时写入。
- 炸弹随机发放、爆炸和拆弹属于赛事广播；炸弹落到本人、传入或传出属于个人反馈，不使用通用 Toast。本人被炸倒后使用共用的“急救中……”压暗层和重生无敌状态条。AI 携带者会主动贴近对手，附近非携带 AI 会尝试横向避让。
- 本模式不写入或接管 `RaceCameraDirector`，也不启用事件画中画；主镜头继续按普通比赛规则跟随角色。

## 联机

- 单机与房主负责发放、传递、爆炸和拆弹判定；所有结果随机都来自 `SharedRNG`。
- 房主通过可靠帧通道发送装雷、传递和结算事件；爆炸结算同时携带权威赛程距离、横向爆心和受冲击泳道掩码。权威快照携带当前轮次、携带者、引信、冷却、已结算轮次，以及各泳道的急救／无敌阶段和重生距离。
- 访客只推进显示计时并应用权威事件／快照；迟到事件和重复爆炸通过递增 revision 与轮次掩码去重，恢复快照负责丢包和房主迁移兜底。

## 性能约束

- 同一时刻只有一枚可见炸弹和一个池化爆炸网格；爆炸复用炮火与障碍水雷的立体水爆，由暖色爆心、双层冲击环、环形水冠、有厚度的弧形水柱和块状水滴组成，不再使用交叉透明薄片。
- 炸药管、绑带和计时器合并为一个顶点色网格，另用一个小网格表现警示灯。
- 不增加贴图、外部 GLB 或额外材质种类。挂载后不逐帧计算世界跟随；表现最多按 20Hz 更新摇摆、闪烁和爆炸缩放。
- 不使用运行时 `Graphics` 绘制特效，不创建逐帧 UI 字符串或临时节点。
