## 真源与导出

- 高清正方形源图：`output/avatar-street-v2/01-柚夏.png` 至 `10-岩川.png`，每张 1254×1254，背景已绘入。
- `output/avatar-street-v2/manifest.json` 保存逐张提示词与生成来源；使用内置 ImageGen 分别生成。
- `scripts/export-street-avatars.py` 从源图导出 256×256 RGBA PNG，四倍超采样生成圆形 alpha，保留透明区域 RGB，圆内人物与背景保持完整。需 Python 与 Pillow。
- 输出复用 `assets/race/ui/avatar-picker-v1/avatar-*.png`，不改旧文件名或 UUID。文件名描述历史造型，不再代表当前人物；按下表识别。
- `output/` 是本地设计产物，跨机重导出前确认源文件与 manifest 均存在；不能仅凭脚本已同步就认为源稿已同步。

## 裁切与尺寸

共用 `avatar-base.png` 画布为 86×86，蓝色内圈直径约 72 像素。头像与底图同心，少量覆盖内圈过渡像素，保留白色边框。

| 使用处 | 圆底/框显示尺寸 | 头像显示尺寸 | 说明 |
| --- | --- | --- | --- |
| IdentityEditPanel | 90×90 | 76×76 | 由原 72 调整，覆盖内圈蓝边 |
| ResourceHeadBar | 68×68 | 58×58 | 保留已有尺寸 |
| SettlementView | 56×56 | 48×48 | 由原 56 调整，避免覆盖白框 |
| OnlineRoomView 成员 | 独立框 78×78 | 72×72 | 原有位置、尺寸不改 |
| OnlineRoomView 房主 | 既有面板 | 112×112 | 原有位置、尺寸不改 |

PNG 本身圆外透明，各使用点不再新增圆形 Mask。`Sprite.SizeMode.CUSTOM` 与 `trim=false` 保证完整画布。头像选择不重建整个界面，不改变网络协议、头像 ID 或比赛结果逻辑。
