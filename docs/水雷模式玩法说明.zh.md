# 水雷模式玩法说明

## 定位

水雷模式是独立的 200 米娱乐玩法。模式入口 ID 为 `minefield-brawl`，规则 ID 为 `minefield`。水雷是泳池中的公共障碍物，不会被玩家拾取、携带或传递。

## 核心规则

- 全局共三波水雷：开局一波，领先选手达到约 65 米和 130 米时各触发一波补充。场上同时最多 7 枚，后两波只补齐已经空出的槽位，不会在仍存活的水雷上额外叠加。
- 出生布局、漂移相位由比赛共享种子确定。水雷围绕锚点缓慢漂动，始终留在可游区域内。
- 选手身体进入水雷判定椭圆时立即爆炸。直接触雷范围拆为“水雷自身椭圆＋人物身体椭圆”，总触发距离仍保持原来的纵向 `1.35` 米、横向 `1.05` 米；判定会扫掠上一帧到当前帧的移动路径，身体边缘擦到水雷或高速游过时都不会漏触发。
- 直接触碰水雷的选手会被击倒，进入 3.5 秒急救阶段；本地压暗层显示运动转播式急救牌，以一个、两个、三个点循环显示“急救中”，卡片短促横向切入后保持稳定。若命中时人物仍在空中则先快速落回水面，落水后其他玩家看到其保持侧翻失能姿态，胸腹与骨盆下沉更快，四肢受浮力滞后而相对上抬并轻微异步摆动，头部正上方三颗稍放大的卡通星以 20Hz 缓慢旋转。随后在原赛程进度和自己的泳道中心以零速度重新入水，并获得 2 秒无敌保护。击倒不计为永久淘汰。
- 爆心外围扩大到约纵向 3.2 米、横向 2.5 米；范围内其他选手只会被冲击波击退、翻滚并失速，不进入急救。
- 每一枚具体生成出的水雷只能爆炸一次，爆炸后不会原地复活；后续波次会在空槽中生成一枚新的水雷。仍存活的旧水雷保持原位置和漂移进度，不会被传送或重新播放入场。首位选手完赛后停止触发尚未开始的新波次。
- AI 在接近同横向区域的水雷时会向水雷另一侧绕行。

## 表现与镜头

- 所有水雷复用一份低面数网格和一份材质，仅各自保留一个世界节点。模型由分面球壳、凸起腰线、八根分段尖刺、顶部触发器和侧面警示牌组成；不对称细节用于强化轮廓和旋转读性。
- 水雷不再在水面直接显形。启用掩码从隐藏变为可用时，各实例按 `0.04` 秒的小间隔开始入场：先在水下约 `0.82` 米处用 `HEAVY_ENTRY` 的纯波纹制造低强度扰动，再用 `0.72` 秒破水上浮，经过 `0.3` 秒回落稳定后接入常态漂浮；不新增粒子系统或运行时绘制。
- 水雷在水面附近轻微上下起伏，并以约每秒 14° 缓慢自转、叠加不超过 9°／7° 的俯仰和侧倾漂摆；破水使用共享重入水池，爆炸使用共享水爆池的 3 个预建槽。
- 爆炸水花由暖色爆心、双层立体水面冲击波、环形水冠、九束有厚度的弧形水柱和少量块状水滴组成；冲击波使用带白蓝高亮浪尖的断续低矮波峰，水柱约 0.6 秒完成，波峰继续扩散并沉降到约 0.95 秒。不再使用两张交叉透明面表现水柱，避免比赛镜头下出现白色三角形。
- 水雷变换和爆炸缩放最多按 20Hz 更新，不重建网格，不使用运行时 `Graphics`。
- 本模式不写入或接管 `RaceCameraDirector`，也不启用事件画中画。赛前规则卡说明“碰到立即爆炸”，比赛开始后不重复弹出规则 Toast；本人触雷时使用娱乐玩法共用的个人反馈，其他选手触雷只播放世界爆炸、水花和角色受力。

## 联机

- 房主是唯一命中判定方。访客可以本地播放相同的确定性漂移，但不能自行决定谁触雷。
- 每次命中通过可靠帧事件发送水雷 ID、直接命中泳道、爆炸位置、受冲击泳道掩码和 revision；访客只接受递增 revision，避免重复受力。独立模式与六合一使用同一套直接击倒规则。
- `S|` 周期快照同步权威漂移时钟、存活／启用掩码、当前波次和每个复用槽位的代次。已经爆炸的旧水雷不会因事件丢失、晚到或房主迁移而复活；只有房主触发的新波次可以把空槽配置为新一代水雷，更旧 revision 和倒序波次仍会拒绝。
- 视觉漂移不依赖 iOS JavaScriptCore 与 Android V8 的浮点锁步一致性；周期快照会修正可见偏差，比赛结果仍只以房主事件为准。

## 首版调参入口

当前关键参数集中在 `MINEFIELD_TUNING`：水雷数量、第二／第三波触发距离、水雷自身接触半径、人物身体触雷半径、外围冲击半径、漂移半径与速度、AI 预判距离和避让偏移；对应参数已接入 Debug 调参面板与 `tuning.json`。

## 验证范围

离线回归覆盖确定性水雷布局、直接击倒与外围冲击范围、扫掠命中、可靠事件去重、三波补齐而不叠加、存活水雷不重置、完赛停止新波次、波次／槽位代次快照恢复、旧快照拒绝、20Hz 表现更新、水下扰动与破水上浮参数、精修水雷结构、轻微三轴漂转，以及爆炸水花不再使用交叉薄片。仍需在 iOS／Android 微信真机检查击退手感、三波节奏、上浮表现、模型小尺寸辨识度、透明排序、连续多雷入场／爆炸时的填充开销和正式比赛镜头下的水花辨识度。
