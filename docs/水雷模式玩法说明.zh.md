## 气球版设计与制作基线（保留方案记录）

用户认为首轮圆盘精细度不足、触发功能不明确，提出在上方系漂浮气球，并选择**水滴爆花＋感叹号**。本节保留制作前的完整设计基线；实际交付参数与验证状态以上文接入记录为准。水炮与 C 定时水球不在此次造型调整范围内。

### 目标与视觉含义

暂称“气球喷水浮标”，正式入口仍可沿用“喷水浮标”。玩家应在正常比赛尺寸读出三个信息：上方气球提示这里需要避让；下方宽软边是身体会撞到的部位；碰撞会导致气球爆开和底座喷水。气球是系在装置上的漂浮玩具，不在文案里指定氢气，也不把气体燃烧作为效果来源。

当前模型的不足是盘面、边圈、喷口几乎只有三层同心形状，缺少接缝、厚度变化和受碰部位。改进先处理轮廓、连接和材质分区，再添加小细节；不靠堆螺丝、发光或粒子提升精细度。以下尺寸与时序是首轮制作基线，需要经实际小尺寸与正常速度预览调整，并非已测量的新成品。

### 造型与可编辑部件

| 部件 | 计划造型 | 功能读性与连接要求 |
| --- | --- | --- |
| 圆盘底座 | 保留约 1.32m 宽、0.26m 厚的碰撞轮廓；青蓝盘面、奶白承托层、橙黄软包边；增加窄接缝、下沿收口和四段明显缓冲分区 | 软边是受碰入口，分区不能形成尖刺；下沿厚度使其像能浮起来的设施，而非薄盖子 |
| 喷水组件 | 中央低矮短喷口，加圆钝口缘和可见内孔；周边做四条宽浅的导水槽 | 让喷口和水的出处可见；槽由源网格制作，不用逐帧绘制 |
| 气球 | 饱满但略呈梨形，底部收颈和结口；以偏暖的柠檬黄为主，白色印花底、深青色水滴爆花与感叹号 | 初始宽约 0.55～0.65m、高约 0.70～0.80m，总道具高度约 1.2～1.4m；与 C 橙色肩背水球及水炮蓝青小球区分 |
| 系带与安装座 | 一根较粗、略弯的软系带，连到喷口旁的低矮圆钝扣座；不遮住中央喷口 | 明确检查扣座—系带—气球结口三处连接；游戏小尺寸下仍能看出它们属于同一物体，避免像三个悬空零件 |
| 警示印花 | 简洁水滴置于爆花中，搭配粗感叹号；前后两个主要观看面可读 | 不用炸弹、火焰、骷髅、文字计时或闪红灯；先用少量同网格颜色面实现，避免另建透明贴花层；不得与球面共面闪烁 |

气球不增加碰撞体：从它上方或旁边掠过不触发，实际接触仍由水面底座的原范围决定。系带允许小幅倾斜，气球不能大幅漂离底座而误导避让。不得始终强制面向镜头；通过前后印花与轮廓保证方向可读。

### 从出现到爆开的完整演出

入场沿现有约 1.3 秒视觉结构安排。出生安全、启用时刻和碰撞均由原控制器决定；下表不是新增的无敌期、倒计时或延迟命中。

| 阶段 | 首轮时序 | 画面与反馈 |
| --- | --- | --- |
| 水下提示 | 入场 0～0.28s | 复用 B2 水下扰动；能隐约看见圆盘或收拢气球的色块接近水面，不直接在水面凭空出现完整道具 |
| 破水上浮 | 0.28～1.00s | 底座斜着破水，气球带着系带展开并竖起，水花来自底座穿过水面的实际位置；表现为浮出和展开，不增加漫长充气等待 |
| 回落就位 | 1.00～1.30s | 底座轻回落，气球因惯性再摆一下；系带拉住气球后收敛，不持续乱晃 |
| 稳定漂浮 | 直到原接触事件 | 底座沿用共享重物漂浮，气球小幅滞后摇摆；警示主要靠黄色轮廓与图案，不做持续膨胀、闪灯或滴答声，避免被误读为 C 定时水球 |
| 接触瞬间 | 命中 t=0 | 原权威结算立即执行，B1 恢复与 B2 喷水当帧启动；软边／底座立即压低，气球轻微横向鼓开。不能等它完成膨胀或爆开才结算 |
| 气球爆开 | 命中后 0～0.10s | 鼓开后迅速压扁并消失，产生一声短促气球“啪”；用清楚的轮廓变化表达爆开，不做飞火、黑烟或长时间碎片模拟。系带随之失去支撑并收回／隐藏 |
| 喷水主段 | 命中后约 0.05～0.30s，与前段重叠 | 气球消失后，中央喷口和向上的 B2 水柱成为主体；水面冲击与外围推开继续原规则，局部喷水坐标取真实喷口，不能移到上方气球中心 |
| 底座退出 | 命中后 0～0.30s | 受压底座沿原尾段下潜，软边压缩后收敛；气球爆开的短动作完成后整套消失，不留一根悬空系带，不留下可再次碰撞的空盘 |
| 水面余波 | 由 B2 原寿命收尾，当前约 0.95s | 水冠、碎水与涟漪继续原池，不延长整套残留，也不补发第二次冲击 |

“爆开”和“喷水”属于同一个触发瞬间的连续读感，不是气球爆一次、底座再爆一次。首轮不增加气球独立粒子池或爆裂碎片；如果正常速度看不清，优先调大气球轮廓、改爆开前后形变及短音效，不先增加特效层。

未启用阶段、正在上浮就被合法接触、晚加入和快照恢复需单独处理：未启用时不提前播放爆开；已启用且可碰撞时必须有可见的底座或警示轮廓，不能为了播完气球入场制造不可见障碍。接触可立即中断任何入场阶段。成熟快照直接恢复当前漂浮状态，已消耗快照不自动补爆。

1. **先做轮廓和功能分镜。** 基于当前浮标与真实角色尺寸制作灰模、三种比赛观看方向及入场／漂浮／爆开／喷水／退出关键帧。先看清系带连接、受碰软边、气球图案和喷口，再补接缝与内孔。
2. **完成同一作者源的精修与动作。** 在 `art/water-play-obstacles/SprayBuoy.blend` 维护浮标；首轮圆盘版留可恢复记录。建模脚本先增加只构建／导出浮标的选项，渲染脚本同样限定浮标，防止重导水炮。源动作包含两部分的滞后漂浮、接触压缩与气球爆开，检查结口和系带不会脱节或穿过喷口。
3. **接入现有浮标表现。** 延续固定节点、同源几何回退与晚加载只换网格；原底座节点与新增气球组件独立控制。新 generation 清除旧气球、压缩和喷水尾段；旧 revision 不得爆开或隐藏新气球。退出、隐藏、重开与销毁必须清掉两部分及音效触发记录。

5. **交付完整离线预览，再分别记录引擎和真机检查。** 预览保留正常速度／慢放、时间轴、三方向、角色参照和小尺寸图标；制作与离线完成不等于引擎和真机通过。

## 定位与规则

喷水浮标是 200 米娱乐玩法中的世界公共障碍物，不能拾取、携带或传递；统一娱乐模式也使用同一控制器与表现。

- 独立玩法共三波：开局、领先选手约 65 米和 130 米时补位；同时最多 7 个，后续波次只在空槽生成新代次。存活浮标不重置位置或入场；首位完赛后停止新波次。
- 共享种子决定出生布局与漂移相位。保留出生安全区、选手离开后连续安全 0.45 秒才启用，以及可游区域限制；不贴脸投放并瞬时命中。
- 道具椭圆半径纵向 0.67m、横向 0.65m，加上人物身体半径后总触发距离维持纵向 1.35m、横向 1.05m。保留上一帧到当前帧的路径扫掠和原潜水接触规则。
- 接触时立即权威结算一次；本人沿用 B1 的 3.5 秒浮圈调整、原进度／泳道恢复、速度清零与 2 秒保护。显示“调整中”恢复卡，不再叠加“撞上水雷 · 急救中”个人大提示。
- 外围纵向 3.2m、横向 2.5m 内的其他选手保留推开、翻滚和失速，不进入调整。AI 使用原预判与转向绕行。
- 一枚浮标只触发一次。下压、喷水和下潜不推迟命中、不改变结果，也不让旧实例原地复活。

- `MinefieldBrawlPresentation` 已解除对 `MineRelayBrawlPresentation` 的旧水雷几何与材质依赖。C 水球文件与兼容导出保持原样。
- 同源固定几何作为立即可见回退，GLB 就绪后只交换网格引用。晚加载不改变当前位置／漂浮／下潜；失败不显示旧水雷，也不产生不可见障碍。
- 入场保留每槽 0.04 秒错开、0.28 秒扰动段、0.72 秒展开上浮和 0.3 秒稳定；未武装时可从水下约 0.82m 扰动，已武装时软边与警示轮廓立即可见，浅水入场不等待槽位错开。进入后继续使用 `WaterFloatMotion.heavyHazard` 共享漂浮与轻微三轴旋转，气球以扣座为锚点小幅滞后摆动。
