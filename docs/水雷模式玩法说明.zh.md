# 水雷模式玩法说明

## 定位

水雷模式是独立的 200 米娱乐玩法。模式入口 ID 为 `minefield-brawl`，规则 ID 为 `minefield`。水雷是泳池中的公共障碍物，不会被玩家拾取、携带或传递。

## 核心规则

- 泳池中同时维持 7 枚水雷，出生点分散在不同纵向位置和横向区域。
- 出生布局、漂移相位由比赛共享种子确定。水雷围绕锚点缓慢漂动，始终留在可游区域内。
- 选手身体进入水雷判定椭圆时立即爆炸。判定会扫掠上一帧到当前帧的移动路径，避免低帧率或高速游过时漏触发。
- 爆炸会把选手掀翻并造成明显失速，但首版不直接淘汰。
- 爆炸后的水雷隐藏 4.2 秒，再在原区域重新浮出，保证整场持续存在障碍压力。
- AI 在接近同横向区域的水雷时会向水雷另一侧绕行。

## 表现与镜头

- 所有水雷复用一份低面数网格和一份材质，仅各自保留一个世界节点。
- 水雷在水面附近轻微上下起伏和旋转；爆炸使用 3 个预建网格循环复用。
- 水雷变换和爆炸缩放最多按 20Hz 更新，不使用运行时 `Graphics`。
- 本模式不写入或接管 `RaceCameraDirector`，也不启用事件画中画；触雷时只播放世界爆炸、水花、角色受力和短提示。

## 联机

- 房主是唯一命中判定方。访客可以本地播放相同的确定性漂移，但不能自行决定谁触雷。
- 每次命中通过可靠帧事件发送水雷 ID、命中泳道、爆炸位置和 revision；访客只接受递增 revision，避免重复受力。
- 视觉漂移允许设备间存在微小差异，比赛结果只以房主事件为准，因此不依赖 iOS JavaScriptCore 与 Android V8 的浮点锁步一致性。

## 首版调参入口

当前关键参数集中在 `MINEFIELD_TUNING`：水雷数量、纵横判定半径、漂移半径与速度、重生时间、AI 预判距离和避让偏移。后续如果这些参数进入正式手感调优，应同步接入 Debug 调参面板与 `tuning.json`。
