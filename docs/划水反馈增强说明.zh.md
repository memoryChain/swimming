# 划水反馈增强

第一版复用已有手掌、白点、水花粒子与划水音源。左右半屏触控、短按踢腿、长按划水、质量判定、推进和联机协议沿用原实现。

## 表现与时机

- 按下立即将同侧手掌缩至 88%，提高不透明度；不等待长按门槛或 30Hz 判定采样。松手恢复，普通成功回弹至 108%、完美成功至 115%，0.2 秒收回。新按压优先于旧队列的延迟结算。
- 手掌和白点在现有判定快照的完美区内提亮，继续按 30Hz 采样，只在状态变化时写颜色。
- 原先动作开始时的音效改在划水结算时播放。复用同一水声音源，普通音量 0.32、完美 0.52，继续服从音量设置；失误不播放成功音效。
- 水面有效划水结算时调用现有同侧手部粒子池，普通每个发射器请求 3 粒、完美 7 粒；最终数量仍受原有发射器缩放、最低数量和喷洒策略控制。不上新材质、节点或贴图，遵守粒子禁用与离屏裁剪开关。水下不添加水面水花。
- 本地水面追逐镜头在结算后轻微拉开再追上。完美默认最大后拉 0.16m、目标视野增加 1.2°、持续 0.32 秒；普通为其 45%。连续触发重置有界脉冲，不累计位移；转身、水下、海豚跳、完赛和观战专用镜头清除脉冲。

## 调参

调参面板「冲刺与终点相机」新增 `camera.strokeFeedbackBackDistance`、`camera.strokeFeedbackFov`、`camera.strokeFeedbackSeconds`。前两项可设为 0 分别关闭后拉和视野变化；沿用现有 JSON 保存及启动覆盖流程。

## 性能与同步

原有反馈不新增节点或监听；手掌波纹新增左右各三个固定 Sprite，不增加 Graphics 绘制；手掌 Tween 仅由结算事件启动，按压、隐藏和销毁时停止。隐藏 HUD 不采样；连续状态只比较数值和颜色，不新增逐帧数组或向量。镜头新增标量脉冲，复用既有镜头计算结果。即时松手和延迟队列结算共用表现入口，音效和镜头仅由本地玩家结算触发。水花由既有动作结算产生，不增加网络消息，不修改成绩或物理状态。

## 验证范围

自动检查覆盖 HUD 隐藏、连续按压、旧结算与新按压竞争、短按与长按输入顺序、结算音效分档、镜头双向幅度上限及恢复，并回归开场和终点镜头。TypeScript 使用固定 5.4.5 检查；新增调参文案通过项目字体构建与审计。

尚需在实际游戏及 iOS／Android 微信体验版验证：背景音乐下普通与完美的音量差、左右手水花位置与遮挡、快速左右划水时镜头舒适度，以及双端联机帧耗时和透明粒子开销。离线测试不代表这些项目已经验收。未自动启动或截图 Cocos Creator。

## 手掌扩散波纹与内发光

每次按下仅发出一圈波纹，并闪亮一次按钮内侧高光；长按不追加，松手不重播。再次按下才发出新的一圈。左右各三槽仅用于快速连续点按，不代表一次发三圈。

波纹使用专用 256×256 RGBA `assets/race/ui/race-stroke-v1/ripple-ring.png`，替代低分辨率排名圈；内发光为独立 128×128 RGBA `inner-glow.png`，位于按钮底图上方、手掌与文字下方。两张原始 PNG 合计约 19.3 KiB。资源路径集中在 `ResourcePaths.raceHudUi.strokeRipple` 和 `strokeInnerGlow`，Creator 已生成元数据，已执行纹理策略修复与审计。

矢量源稿位于 `tools/ui-source/stroke-feedback/`。安装或配置 sharp 后，运行 `node scripts/export-stroke-feedback.cjs` 可离线复现导出。规则圆形使用矢量绘制，没有调用图像生成模型；渐变已烘焙进 alpha，运行时不绘制圆形。`preview.png` 为静态分时离线合成示意，不是引擎截图。

波纹约 0.78 秒，节点直径 104→320 设计像素（亮环实际最大直径约 300），不透明度从 180 渐降至 0；内发光在 0.36 秒内从 230 淡出，中心透明，不遮住手掌。最大六张扩散 Sprite 加两张按钮内发光 Sprite，不增加材质种类。六个扩散方形的理论总面积约 61 万设计像素，透明重叠和合批开销需真机确认；没有整屏透明层。波纹后期接近屏幕下边缘时已经接近透明。

复用 HUD 的 30Hz 采样，只写变化后的整数直径和透明度；无循环 Tween、逐帧分配或节点创建，隐藏时清空且停止采样。单机和联机都只消费本地按压状态，不改变玩法与网络数据。

自动测试覆盖一次按下一圈、扩大范围、内发光层级与淡出、长按不重播、左右独立、固定节点数、隐藏重开无残留。实际视觉质感与帧耗时仍需游戏及微信真机确认。

## 白点外发光与完美松手闪光

白点保持原来的 18px 和移动方式，后方增加一张 48px 外发光 Sprite，使用离线矢量导出的 64×64 `marker-glow.png`。白点可见时，光晕始终以不透明度 110 跟随同一坐标移动；按下不闪光，也不提前显示白点。只有实际 PERFECT 松手结算后，光晕瞬间提高到 255，在松手位置保留白点和光晕，短暂高亮后一起于约 0.18 秒内消失。普通松手不闪光；新一划优先取消旧闪光。没有尾迹或白点缩放。

左右各一个固定光晕节点和一个白点透明度组件，复用现有 30Hz 采样，只在状态变化时写属性；隐藏时清空。单机和联机只消费现有本地显示快照和划水结算，不更改判定、物理或网络状态。自动测试覆盖常态跟随、按下不闪光、完美松手增强、白点与光晕同步消失、普通松手不闪光及隐藏重开。
