# 碰撞柔性反馈试用版

2026-09-06：碰撞后从自由泳混合到关节惯性模拟，双侧上臂／前臂／手腕、大腿／小腿／脚踝共十二根骨骼采用受限松弛姿态，随后恢复当前划水姿态。上臂／大腿具有独立的球面运动速度，保留身体转动前的世界朝向；肘膝与手脚各自保存角度和角速度，通过父关节加速度产生拖后、回摆和边界碰撞。新增碰撞给速度注入冲量，弱弹簧与阻尼负责回弹，而不是插值到固定姿势。强碰撞默认最多 95% 采用松弛目标，持续划水不会立即拉回四肢。只使用关节限位与前臂避头的简化保护，不启用完整刚体自碰撞；不改变骨骼长度、角色根位置、推进、碰撞范围或能量奖励。

## 试玩

- 调试模型选择自由泳；J / I / O 分别注入左侧、正面、右侧冲量。A / D 继续控制划水，可在划水中连续测试。
- 调试参数的「碰撞」组中提供「启用碰撞松软」「碰撞松软强度」「松软回摆频率」「松软回摆阻尼」「松软手臂幅度」「松软腿部幅度」。沿用现有保存流程，稳定 id 为 `collision.soft*`。
- 比赛中接触开始时自动触发。转身、海豚跃、进入水下滑行、停赛、重置和完赛均清空柔性状态。
- 浅碰与侧擦增加 `collision.softMinimumImpact`（松软最小冲量，默认 0.8）：先为整对泳者设置最低视觉冲量，再按双方体重拆分；0 可恢复原始比例。实际击退、转体和能量仍取原冲量。持续划水不会清空松软状态，强碰撞会暂时降低划水姿态的显示权重。
- 新增「碰撞松弛比例」「松弛恢复时间」「四肢跟随速度」：默认 0.95、0.65 秒、1。跟随速度越低，关节弹性回复越迟缓；此时间控制松弛权重的恢复，不是硬性的动画时长。
- 从正面、侧面和斜后方检查双臂、肘膝方向，尤其检查不同划水阶段、仰面翻滚和连续撞击；切换角色后重复。

## 玩家碰撞水花与水面波纹（已接入，待真机收敛）

2026-09-20 已完成第三轮分层时序收敛：碰撞求解器在稳定接触开始边沿提交原始中点、碰撞法线、双方共同流向、相对切向速度和体重拆分前的共同强度；`SwimmerCollisionSplashPool` 使用四个预建槽、四份共享低模网格和一份无光照顶点色透明材质，以 20Hz 推进“挤压／主体／余波”三个阶段。没有新增贴图、粒子系统、运行时 `Graphics`、网络字段或消息。

当前阈值保持不变：标准模式只在 `mag >= 2.2` 时显示强档；狂野模式在 `0.9`／`2.1` 进入中等／强档；娱乐模式在 `0.75`／`1.9` 进入中等／强档。第二轮把娱乐模式整体倍率从 1.25 收敛到 1.08，改由较低触发阈值、8% 透明度增强、额外一颗小水滴和延长 0.04 秒体现模式差异。自动检查已覆盖轻擦过滤、接触边沿、持续贴靠不重播、分离后重触发、遍历顺序、流向与切向速度、池预算和联机协议不增长；这些数值仍需正常比赛镜头与 iOS／Android 微信真机验证后收敛。

### 设计定位

玩家之间的身体碰撞使用一套全比赛通用的水面反馈，不做成娱乐模式独占特效。轻微擦碰和持续贴靠保持安静；中等碰撞只显示短挤压水脊、贴水泡沫切痕和延迟余波，强碰撞才增加低水片与水滴。强碰撞始终弱于鲨鱼咬伤、炮火、水雷和定时炸弹的致命命中水花。

视觉层级固定为：普通手脚拍水 < 玩家身体碰撞 < 娱乐模式强化碰撞 < 鲨鱼咬伤／爆炸。碰撞水花不使用暖色爆心、双层冲击环或高耸爆炸水柱，也不承担命中范围提示，避免把普通身体碰撞误读成玩法事件。

### 触发与强度标定

1. 首版以既有强度公式和自动化代表场景标定，不在正式赛帧中增加日志、数组或事件对象。真机收敛时分别记录同向擦肩、持续侧压、追尾、侧撞、迎面撞和三人以上拥挤，只在临时调试构建使用定长缓冲，验证结束后关闭。
2. 当前阈值保持集中配置；真机样本如果证明同向轻擦进入中档，或明确追尾／侧撞被漏掉，再根据分布调整“无表现／中等／强”分界，不能用提高全部水花尺寸掩盖触发错误。
3. 只在现有 `_newContact` 接触开始边沿触发一次。双方持续重叠时不重播；分离超过现有释放余量后再次接触，才允许重新触发。首版不另加 `Map`、计时器或逐对象冷却。
4. 强度使用一对泳者共同的碰撞量，即分配体重冲量之前由穿入深度与闭合速度合成并封顶的 `mag`。不使用拆给双方的 `impI`／`impJ`，避免同一次接触因为角色体重不同而在两端显示成两个档位。
5. 水花仍是纯视觉结果。视觉阈值和倍率不得反向修改分离、击退、转体、体力、排名或碰撞柔性反馈。

### 空间、方向与生命周期

- 出生点取接触开始前双方位置的中点，Y 轴放在 `waterY` 上方约 0.03～0.05 米，最终高度以正常比赛镜头不闪烁、不沉入水面为准。
- 碰撞法线只定义两名泳者的中心连线；主水片沿其垂线向两侧挤出，不再沿中心连线前后喷。双方共同流向用于让略强的一侧尽量偏向后方；无明确流向时对法线做世界轴规范化，避免交换泳者遍历顺序后整片效果翻转。
- 相对切向速度连续调节横纵缩放：侧擦越明显，水花越低、越沿切线拉开、沿中心连线越窄。强侧擦达到高切向占比时改用贴水泡沫切痕，不抬起完整水片；正撞、追尾和斜撞才保留强档水片与水滴。
- 水花出生后固定在世界接触点，不跟随任一泳者移动，也不因后续网络位置校正被拖走。
- 中等碰撞总可见期为 0.34 秒，强碰撞为 0.46 秒；娱乐模式各增加 0.04 秒。前 0.08 秒只显示中央挤压水脊；中档主体在 0.20 秒结束、余波从 0.15 秒开始，强档主体在 0.28 秒结束、余波从 0.22 秒开始。主体和余波只重叠约一个 20Hz 采样间隔，避免人物已经分开后仍悬着完整水片。
- 海豚跃离水、深潜、水下滑行、转身保护、重生无敌、网络瞬移校正或碰撞暂时禁用期间不触发。断线恢复、周期快照和晚加入只恢复泳者当前状态，不补播已经过去的碰撞水花。

### 美术规格与模式预设

播放按三个阶段组织。第一阶段所有有效碰撞只显示一条短中央挤压水脊；第二阶段中等碰撞切换成两条不对称贴水泡沫，强碰撞切换成两片低水片与 2 颗块状水滴，娱乐强档增加第 3 颗小水滴；第三阶段才显示两段切线方向月牙余波。波纹不接近整圈椭圆，因此更像两人之间的水被横向挤开，而不是爆炸冲击环。不使用运行时 `Graphics`、通用粒子系统堆叠、新的全屏水面扰动或大透明方片。

| 比赛预设 | 触发范围 | 表现规则 |
| --- | --- | --- |
| 标准模式 | 只显示强碰撞 | 尺寸和水滴最克制，不让普通竞技画面持续冒水花 |
| 狂野模式 | 显示中等与强碰撞 | 作为通用基线，清楚交代身体碰撞方向和接触点 |
| 娱乐模式 | 显示中等与强碰撞 | 复用同一实现，几何倍率只比狂野高 8%，主要增加亮度、小水滴和 0.04 秒停留，不再把普通碰撞放大成爆炸 |

模式差异只由一份 `BODY_CONTACT` 预设覆盖阈值和视觉倍率，不复制娱乐专用类、网格或材质。若未来其他玩法需要相同身体碰撞反馈，直接选用现有预设。

### 代码职责与性能预算

- `SwimmerCollisionResolver` 只在接触开始时提交紧凑的纯视觉标量：世界接触点、碰撞法线、共同流向、相对切向速度和共同强度；碰撞解算器不创建事件对象、表现节点，也不持有材质或对象池。
- `GameManager` 只负责把固定回调接到比赛级表现器。节点创建、固定池、20Hz 生命周期采样、模式预设和清理位于 `swimmer` 模块，不把细节继续堆入主编排文件。
- 碰撞水花使用独立的 4 槽固定池，不抢手脚拍水发射器，也不占用苏打、垃圾、重入水或水爆的娱乐道具槽。池满时复用剩余寿命最短的槽，赛中不扩容或临时创建节点。
- 每槽预建一个瞬时／主体渲染节点和一个余波渲染节点。主体节点在 0.08 秒时只切换共享网格，不新建节点；余波延迟激活，并与主体只重叠约一个采样间隔。单个强效果跨两层仍约为标准／狂野 52 三角形、娱乐 60 三角形；通常每槽只有一次透明绘制，理论峰值为四个碰撞同时处于短重叠窗口时的 8 次透明绘制，须在真机最坏用例验证。
- 活跃槽以 20Hz 更新，网格切换和显隐只在阶段边沿写入，变换只更新当前存活层。热路径复用固定槽和已有标量，不创建 `Color`、`Vec3`、事件对象、闭包或格式化字符串。
- 低性能档可先取消娱乐强档的第 3 颗小水滴，再取消主体与余波的短重叠（把余波推迟到主体结束），最后缩短余波寿命；不得通过降低碰撞模拟、网络帧率或权威快照频率换取特效预算。

### 联机边界

碰撞水花从每台设备已经执行的接触开始结果派生，不增加协议字段、可靠消息、广播或 revision。房主与客机因预测和校正可能在接触点、开始帧或纯视觉水滴角度上略有差异，可以接受；碰撞结果、速度、排名及柔性反馈仍按现有权威纠正链路处理。

为避免重复播放，远端快照中的持续接触、位置校正和断线恢复不得伪造新的 `_newContact`。若实机证明预测碰撞会频繁出现“一端有水花、另一端没有”的明显问题，再单独评估复用现有碰撞柔性事件的边沿，不应直接新增每次碰撞网络消息。

## 联机与开销

`CollisionSoftnessModel` 用两个解析阻尼振子保存左右、前后位移及各自速度。新的 `<softness>` 字段追加在 `S|`、`P|` 和 frame self 的尾部，以千分之一量化；静止为 `0`，活动为 `side:forward:sideVelocity:forwardVelocity`。不上传逐骨骼变换。真人跟随 owner 自状态，AI 跟随房主；房主自己的 AI 不消费旧的柔性快照。

表现层把上次的四标量信号按同一解析振子推进，当前信号与预测值的速度差用于识别新增冲量，避免把自然回摆反复当作新撞击。关节惯性是本地表现，不新增网络字段，不保证跨端逐关节姿态相等。

活动快照只消费一次，缓存快照不会在断流期间每帧重新注入能量；收到权威静止状态则清空预测残留。远端采用平滑校正，因此网络延迟下不保证两端瞬时姿态完全相同。协议版本升到 12，双端需使用同一版本。

未激活时振子立即返回。激活时每个角色推进两个振子，并更新四条肢链、十二根骨骼的受限姿态；每条肢链按最多十二个 120Hz 小步积分，常规 60Hz 为两个小步，长帧最多推进 0.1 秒表现模拟；表现层从同步位移与速度共同计算松弛权重，过零时不会闪回划水。骨骼混合沿用已有 AI 姿态降频与离屏裁剪，离屏时清空表现缓存，复用四元数缓存，不增加模型、材质、绘制批次或每帧对象分配。
