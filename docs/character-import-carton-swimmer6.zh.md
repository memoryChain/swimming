## 换色分区

复用 `SwimmerDynamicColor.effect`，没有新增 Shader、材质槽或赛中纹理生成。

- R：原图绿色的圆耳帽、外套、腕带、腰带、挂饰及鞋部饰件，统一使用服装颜色。
- B：面部、耳朵、脖颈、手臂、腰腹与腿部皮肤，使用独立肤色。暖肤色保留原图，深肤色使用现有配色。
- G 保持为零，A 全不透明。绿色区域不拆成独立帽子通道。
- 棕色头发、粉色眼镜和布料、黑白装备保留原色。

首次预览发现默认肤色识别会覆盖棕发及部分粉色布料，因此为生成脚本增加可选 `light-peach` 配色规则：用浅桃色亮度和绿色相对蓝色的差值排除这两类区域。原默认规则不变，既有遮罩无需重生成。此模型的 UV 碎片较多，禁用皮肤闭运算，避免将覆盖扩展到相邻装备。

```powershell
python scripts/generate-green-recolor-mask.py --input tools/characters/tripo_790f398d/basecolor.jpg --output assets/race/models/CartonSwimmer6ColorMask.png --skin-close-radius 0 --skin-palette light-peach --preview-prefix CartonSwimmer6
```

UV 重排后的最终遮罩中，衣服非零像素 77,993，皮肤非零像素 89,093；像素数变化来自新图集的面积分配、烘焙扩张与下摆内侧补片，不改变 R/G/B 通道语义。已检查原色、六组高对比换色及正面、背面、侧面的装备边界。

黑色换色实机截图首先暴露出后腰衣摆内侧仍保留暗绿色。普通绿色规则对这套偏黄绿色布料的暗部权重不足，因此从重排后的底图以 `--garment-palette lime` 重建衣服 R 通道，保留原有肤色 B 通道，并在交界处按衣服权重压低 B。

后续低机位截图进一步确认，目标不是露出的后腰皮肤，而是皮肤前方、只有角色俯身仰视时才出现的第二层上衣内衬。单层射线首先命中后腰皮肤，不能用来划分这部分；最终改用多层射线定位其后的下摆内圈，并用法线方向和网格连通关系筛出 16 个向下的内衬面。补片从未修改后腰皮肤的干净遮罩重新生成，只写入这 16 个面的 UV，以 8 倍采样和 1 像素边缘扩张提高 477 个衣服纹素，其中 318 个为新增衣服覆盖；未选中任何腰部皮肤面。静止低机位红色对照中皮肤保持原色，内衬面的几何高亮形成一圈独立薄面。有效阶段备份保存在 `CartonSwimmer6ColorMask_BeforeDarkGreenFix.png`、`CartonSwimmer6ColorMask_BeforeLowerShirtInnerFix.png` 与 `CartonSwimmer6ColorMask_BeforeInnerRingFix.png`。

## 骨架与动作

源模型先绕竖轴旋转 -90°统一朝向，再使用 `tools/normalize-character-to-canonical-rig.py` 对齐标准骨架轴。原始最大骨架方向差约 53.04°；导出后最大局部旋转误差约 0.000304°。关节位置、网格顶点和权重改动均为零。

复用 `model-actions/tPose`，没有复制整套动作。离线遍历 21 个动作资源、3,661 个采样，涵盖跳水准备：无缺骨、非有限网格数值或标准轴参照下的左右手顺序差异。自由泳另外使用实际 `FreestylePoseController.ts`、Cocos 数学库及保存调参，检查三种划水模式共 363 帧，数值有限且循环闭合。已检查九个高风险动作各五帧、跳水准备三视角，以及自由泳双臂动作的俯视和斜视渲染。

保留源模型的左右关节差异。双臂前伸时左肘约 12.37°、右肘约 3.72°，未为视觉对称移动关节或修改共享动作。

### 接地验收欠项

通用 Hip 对齐和双骨 IK 离线计算的支撑骨骼残差最大约 0.000497 模型单位。但舞蹈动作中鞋底网格仍有约 -0.01593 至 +0.01265 模型单位的接触偏差，超过 0.001 网格接地目标，明确记录为视觉验收欠项。未改其他角色的接地逻辑或共享动作来补偿该鞋型。
