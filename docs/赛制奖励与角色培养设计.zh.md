# 赛制、奖励与角色培养设计

更新时间：2026-09-13。状态：设计方案，核心功能已接入原型；实际首轮数值与差异见 [原型接入记录](赛制养成原型接入记录.zh.md)。

本文整理本轮讨论，作为后续策划与开发入口。用户明确要求与建议测试参数分开记录；文中的金额、倍率、轮次门槛和成长时长不是已验证的最终平衡值。

配套界面方案见 [大厅与赛事二级界面设计](大厅与赛事二级界面设计.zh.md)。

## 1. 已确认边界

- 当前基础比赛为 200 米和 400 米，用户提供的典型比赛时长分别为一分多钟、约三分钟。
- 单人快速比赛只提供 200/400 米和标准/狂野两组赛事选择。AI 根据当前角色等级以及玩家联赛、杯赛水平自动适配，不提供手动难度选项。
- 联赛级别、积分与晋级资格属于账号，换角色不重置、不降低联赛难度。角色是否有能力取得奖励由实际比赛结果决定，不因未培养而额外补偿。
- 杯赛进度与夺冠记录属于角色，对手采用预先配置的固定难度，与角色等级无关。同一角色可在轮间升级，最新属性下一轮生效；其他角色不能接替其赛程。
- 联机只做朋友之间的单场快速对战，不做多轮赛事。
- 联机不给任何奖励：不发金币、联赛积分，不推进任务、首胜、奖励型成就、生涯或培养进度；不设置赛后奖励广告。成绩展示与返回房间继续保留。
- 所有正式可用角色从一开始都能使用。角色培养资格通过一笔较大金币支出，或观看激励视频解锁；解锁后才可花金币升级。
- 后续已授权功能原型实现，当前接入范围及本地后台/广告限制见原型接入记录。

其余为建议方案，包括首个免费培养名额、视频次数、赛事命名和以下数值，需要通过体验和经济测算校准。

## 2. 产品循环与入口

核心循环：免费体验角色 → 选择主力并签约培养 → 单人比赛赚金币 → 升级 → 挑战更高赛事 → 培养其他角色。

| 入口 | 内容 | 金币 | 生涯积分 | 主要作用 |
| --- | --- | --- | --- | --- |
| 单人生涯·联赛 | 以单场 200 米为主 | 有 | 有 | 日常成长主线 |
| 单人生涯·杯赛 | 两轮晋级杯，后期三轮大师杯 | 有 | 不重复增加联赛积分 | 晋级、奖杯、阶段挑战 |
| 单人快速比赛 | 自选 200/400 米和已有玩法规则 | 有 | 无 | 碎片游玩、练习新角色 |
| 好友对战 | 联机单场 200/400 米 | 无 | 无 | 朋友对战乐趣 |

赛事类别、距离、玩法规则、AI 强度是四个独立维度。不能把 400 米理解为更高段位，也不能把“狂野”自动理解为更高等级 AI。正式生涯每项赛事固定距离与规则；快速比赛只允许选择距离和玩法规则，AI 自动适配。

游戏主打狂野模式：全部联赛与杯赛各轮统一采用狂野规则。单人快速比赛保留标准/狂野选择，新档默认200米狂野；已有快速比赛偏好继续保留。杯赛固定对手难度、角色轮次归属和奖励规则不变。

## 3. 生涯联赛

建议六个生涯级别：泳馆新秀 → 俱乐部选手 → 城市精英 → 区域强者 → 全国大师 → 冠军级。

联赛进度账号共享，任何角色参赛都推进同一条联赛进度。换成未培养角色仍面对所选联赛的固定难度，不自动退回新手联赛或安排弱对手；达不到奖励条件就没有对应奖励，不按角色等级直接发奖或拒奖。

- 每级目标暂定 100 积分；8 人局前四名依次获得 20/14/10/6 分，后四名 0 分。
- 100 分封顶，解锁本级晋级杯；该级额外比赛不储存下一等级积分。
- 晋级杯夺冠后升一级，新级积分从 0 开始；最高级保留满级进度，杯赛作为重复挑战。
- 杯赛失败保留满积分和已获金币，可重新报名，不消耗入场金币。
- 首版全级别不扣积分、不降级、不做赛季重置。高段位扣分仅作为后续选项，不形成当前待实现分支。
- 回打已解锁低级联赛可获得相应金币，但不增加当前高级联赛积分。
- 等级只是推荐，不强制角色达到指定等级才能参赛。

生涯级别代表养成、操作、决策共同形成的竞争力，不叫真人天梯，不展示未经验证的“超过全国多少玩家”。AI 对手身份明确。

## 4. 杯赛与中断规则

| 杯赛 | 距离与轮次 | 晋级条件（8 人局） | 纯比赛用时 |
| --- | --- | --- | --- |
| 常规晋级杯 | 200 米预赛 → 200 米决赛 | 预赛前四；决赛冠军完成晋级 | 约 2～3 分钟 |
| 大师冠军杯 | 200 米预赛 → 200 米半决赛 → 400 米决赛 | 前四 → 前三 → 冠军夺冠 | 约 5～6 分钟 |

建议前三次级别晋级使用两轮杯，后两次使用三轮杯；冠军级保留大师杯挑战。首版可先交付两轮杯，三轮赛事配置后续开放。

以上时长不含加载、赛前展示、结算和用户停留，界面必须注明“纯比赛约……；可分轮完成”。400 米也作为独立快速比赛长期可选。

### 4.1 赛程连续性

- 每个角色最多保留一届进行中的单人杯赛，不同角色各自保存。可以离开去玩其他模式，切回该角色后续赛；换角色不能继承其他角色的轮次。
- 报名时确定杯赛配置版本、种子、全部轮次配置和对手候选名单。各轮 AI 等级、智力及阵容范围均由杯赛配置决定，不读取玩家角色等级或玩家水平来缩放难度。
- 杯赛报名记录归属角色，但不锁定其等级或报名属性；每轮开赛读取该角色的最新等级与属性。每轮恢复正常开赛状态，不继承上一轮体力或受伤。
- 轮间可培养该角色，下一轮直接生效，对手配置不变；无需重新报名。换角色后显示新角色自己的杯赛进度，原角色赛程继续保留。
- 杯赛开放资格沿用账号联赛进度，角色独立保存报名和通关记录，不要求每个角色重打账号联赛。用于账号晋级的杯赛，任一角色满足当前晋级条件即可完成一次账号晋级；其他角色重打旧杯不重复推进账号级别。
- 每轮结束保存结果并即时结算；预赛晋级者应保留身份进入下一轮。下一轮仍为 8 人时，补位来自其他预赛组，不声称被淘汰者复活。
- 轮间离开保留进度。单人比赛中异常中断，重开当前未结算轮，沿用原阵容与种子；不发未完成轮奖励，也不换一批更弱对手。
- 结果已结算但客户端未展示时，恢复到该轮结算/下一轮入口，不重跑已结算轮。
- 淘汰后本届结束，保留已得单场奖励；重新报名从预赛开始。
- 放弃已有杯赛需明确提示将失去当前轮次进度；已发金币不收回。此确认只用于有损退出，不用于普通轮间返回。

## 5. AI 分配与玩家评估

### 5.1 固定赛事强度

正式联赛与杯赛的对手阵容由“赛事级别的强度范围＋轮次配比＋角色打法”决定。角色等级与操作智力独立，不按玩家领先距离赛中加速，不因玩家刚升级就同步升级正式赛事对手。单人快速比赛采用下述赛前自动适配规则。

当前 `AiRaceConfig.ts` 已有俱乐部 1～5 级、区域 8～15 级、精英 20～30 级配置；当前三个旧入口均映射俱乐部。六级生涯需扩展配置，不能直接把三个配置等同六个新级别。

预赛偏本级下限；半决赛以同级对手为主；决赛安排本级上限种子选手，保留弱强差异与角色风格。测试极限档不进入普通生涯。

现有 [AI 离线基准](AI离线基准结果.zh.md) 有 990 场样本，可作初始参考，但不含完整出发、碰撞和玩家干扰，均值不能直接作晋级成绩线。下一步应按角色、等级、智力、距离及规则分组测成绩分布，而不是只按智力标签排序。

### 5.2 后台评估

| 指标 | 输入 | 用途 |
| --- | --- | --- |
| 生涯级别 | 正式联赛与杯赛成绩 | 前台成长展示与赛事解锁 |
| 当前角色竞争力 | 角色、等级、赛事条件、近期有效成绩 | 推荐适合当前角色的赛事 |
| 操作表现估计 | 判定准确率、稳定性、配速与体力使用 | 练习建议与快速比赛推荐 |

- 前 3 场有效单人比赛形成初步估计，后续参考最近约 10 场；样本不足时不展示精确技术分。
- 200/400 米及不同玩法规则分开建基线，换角色/升级修正竞争力预估，不能简单视为操作提升。
- 名次与有效完赛表现优先，操作指标只作辅助，避免追求高判定率却不前进。
- 未完赛不伪造完赛时间，记录进度与实际结果；退出/异常中断不作为正常完赛样本。
- 正式生涯标准固定，评估只建议去哪里比赛；快速比赛由系统在赛前自动确定 AI 阵容，玩家不能选择或覆盖难度。
- 不按一场失败立即降难，不通过反复退出降低正式赛事门槛。
- 好友比赛不输入奖励或生涯评估链路，首版也不采纳为单人技术评级样本。

纯技术挑战后续再做，需要统一角色/属性条件；首版不引入完整真人评级算法。

### 5.3 单人快速比赛自动适配

用户确认的输入为当前角色等级与联赛、杯赛水平。建议按下列方式组合，具体权重与上下限待基准测试，不先编造精确评分公式：

- 当前角色及等级确定属性竞争力基线；未签约角色按实际初始等级处理，不能用账号最高等级角色代替。
- 已达到的联赛级别、近期有效联赛成绩，以及杯赛晋级轮次和最终成绩共同估计操作与竞赛水平。杯赛水平取已完成成绩，不取尚未完成的报名目标。
- 同时结合所选距离、标准/狂野规则的成绩基线选出对手等级范围与智力组合；不机械地让全部 AI 与玩家同等级。
- 换低等级角色时降低属性侧基线，同时保留已有赛事成绩体现的操作能力；升级后只在下一场准备时重新估计，不要求 AI 按相同幅度同步升级。
- 没有联赛或杯赛记录时，按当前角色等级使用保守的新手先验；有历史后平滑更新，避免一次失败导致阵容骤降。退出和未完成报名不构成降难依据。
- 赛前生成并锁定本场阵容，开赛后不随玩家领先、落后或实时表现变更 AI 属性与智力。
- 自动适配只影响单人快速比赛；不改变正式联赛/杯赛门槛，不改变好友对战。

界面仅显示“对手将根据当前角色等级和联赛、杯赛表现自动匹配”，不显示可点击的难度档、推荐档选择或隐藏的手动覆盖入口。

## 6. 培养资格

用“签约培养”表示永久升级资格，不叫“解锁角色”。所有正式可用角色均可免费以初始等级参赛，未签约不能升级；已拥有的外观和角色特性不因签约额外削减。

建议首个培养名额免费，完成引导后由玩家自选，不自动绑定第一场角色。首签前可先试不同角色。

| 项目 | 测试基线 |
| --- | --- |
| 后续角色金币签约 | 6,000 金币 |
| 视频签约 | 累计 3 次有效激励视频 |
| 每次已完成视频抵扣 | 2,000 金币 |
| 视频进度 | 按角色永久记录，不要求连续，不重置 |
| 升级 | 签约后使用账号共享金币，最高 30 级 |

剩余签约价格为 `max(0, 6000 - 已确认视频次数 × 2000)`。第 3 次有效视频直接完成签约，不再扣币。金币与视频获得相同培养权限。

免费名额未用时默认引导免费签约，不诱导玩家先付费；免费名额本身按账号记录，消费不可重复。签约和扣币作为一个权威事务，重复点击/重复广告回调不重复扣费或增次。

广告不可用/中途关闭不增加进度、不扣币，显示可稍后再试或使用剩余金币方案。广告有效完成以平台回调与后台核验为准，不以打开广告页面为准。

旧档迁移建议：已有培养记录的角色保留等级并视为已签约，不要求重新付费；已有明确培养角色的旧账号视为已享首签，新账号及没有培养记录的旧账号获得首签名额。具体历史字段不足时需先核查，不能仅凭前端显示猜测并抹掉等级。

## 7. 金币与阶段奖励

金币是升级货币，签约卡与染色剂是可消费道具；联赛积分只晋级，奖杯与称号只记录成就。每日任务可后续加入，首版不把任务奖励计入必要成长预算；若加入，只统计符合条件的单人场次。

### 7.1 常规单场

| 奖励项 | 200 米基线 |
| --- | ---: |
| 完赛基础 | 200 |
| 第 1/2/3/4 名 | 200 / 140 / 100 / 70 |
| 第 5～8 名 | 40 |
| 操作表现 | 0～100 |

操作奖励改为有界的判定准确率与连击稳定性评分，具体权重待测；不沿用无上限按 Perfect 次数堆金币。200 米冠军加 80 操作分共 480；第六名加 50 操作分共 290。

定义常规奖励为 `round((完赛基础 + 名次 + 操作) × 距离倍率 × 赛事系数)`。只在最后取整。

- 200 米距离倍率 1；400 米先测 2.2，依据实际整局耗时校准每分钟收益。
- 六级赛事系数先测 1/1.15/1.3/1.5/1.7/2.0。
- 快速比赛首版赛事系数统一为 1，距离倍率照常生效，不依赖玩家手选难度或账号最高生涯级别。后续如细分收益，应按赛前自动匹配的阵容强度固定映射并单独验证，不能在结算时临时改变系数。
- 低级赛事重复游玩有常规金币，无重复首次奖励。

### 7.2 未完赛

当前规则是首人完赛后 10 秒尾随计时，DNF 无金币。新生涯必须联合调整尾随策略和保底奖励，避免新手“无法完赛→没有金币→无法培养”。

后续确认采用固定难度形成养成门槛，原型不实施未完赛保底：被尾随计时结束、主动退出和挂机均不发金币。正常完赛仍按实际名次与表现领奖，不按角色是否培养额外补偿或剥夺奖励。

联机是否完赛均无奖励；不为适配单人生涯擅自改变联机尾随规则。

### 7.3 杯赛道具奖励

杯赛定位为晋级赛，金币主要由联赛产出。预赛、半决赛以及未夺冠的决赛不发金币和道具。每次夺冠发少量金币并按权重抽取一项道具；每级账号首次夺冠另外给万能签约卡，换角色挑战不重复领取首次奖励。

| 联赛级别索引 | 冠军金币 | 首次万能签约卡 | 染色剂数量／权重 | 随机专属签约卡数量／权重 |
| --- | ---: | ---: | --- | --- |
| 0 | 60 | 1 | 1／80 | 1／20 |
| 1 | 70 | 1 | 1／75 | 1／25 |
| 2 | 80 | 1 | 1／70 | 1／30 |
| 3 | 90 | 1 | 2／65 | 1／35 |
| 4 | 100 | 1 | 2／60 | 1／40 |
| 5 | 120 | 2 | 2／50 | 1／50 |

这是首版可调整数值，不叠加旧版逐轮金币、领奖台金币和大额首次金币。专属卡优先随机给予未签约且未持有对应卡的角色，没有候选时转为染色剂。角色夺冠与晋级规则保持不变。

专属签约卡、万能签约卡各消耗一张永久开启对应角色／任意角色的培养资格。所有角色仍可免费参赛；签约后用金币升级。染色剂用于永久解锁额外配色，保留原有免费配色。详情见[道具与杯赛掉落配置](道具与杯赛掉落配置.zh.md)。

### 7.4 视频范围

首版只做角色签约视频。赛后视频加成暂不做；后续若加入，仅针对本场常规金币，先发正常收益，不能翻倍首次夺冠、任务或整届奖励。任何视频都不购买比赛胜利或晋级资格。好友对战永远不挂奖励广告入口。

## 8. 成长节奏与经济验证

旧升级公式为 `round(800 × level^1.15)`，1→30 总计约53.7万金币。原型已改为 `round((500 + 250×level + 30×level²) / 50) × 50`，累计379,900金币；阶段预算与实测限制见原型接入记录。

| 目标 | 建议测试节奏，不以广告为前提 |
| --- | --- |
| 首签 | 免费自选 |
| 首次升级 | 约 2 场 |
| 主力 5 级 | 累计有效游玩约 15～25 分钟 |
| 第二角色签约 | 约 12～20 场普通收益，或累计 3 次视频 |
| 主力 15 级 | 累计有效游玩约 2～4 小时 |
| 主力 30 级 | 累计有效游玩约 12～20 小时 |

达到目标前需重算逐级价格表，不能把本表当成已成立结果。第二角色金币签约会与主力升级争夺同一钱包，测试时必须计算这项机会成本。

至少模拟保守/中等/熟练三种表现，以及不看视频/使用视频两条路径；纳入失败、杯赛重报、首次奖励、角色切换和赛事时长。检查累计净收入、可支付升级次数、签约时间及最高可达赛事，避免把所有玩家都按冠军收益预算。

## 9. 数据与实现边界

建议独立配置与服务：赛事定义、杯赛进度、赛事阵容、奖励结算、培养资格和表现估计。`GameManager` 保持编排，`PrepareRaceFlow` 不承担扣币或晋级计算。

建议字段（设计名，可按仓库风格调整）：

- 账号：联赛级别/积分与晋级资格、已领取杯赛首次奖励集合、首签是否已用、共享金币。
- 角色：等级、是否已签约、已核验视频次数、杯赛通关记录、当前杯赛进度引用。
- 杯赛：唯一届次 ID、归属角色 ID、定义版本、当前轮、种子、阵容、已结算轮次、完成/淘汰状态；不保存用于限制整届等级或属性的报名快照。
- 单轮比赛记录可保存该轮实际角色和开赛属性用于成绩核验，不限制归属角色下一轮升级，也不作为杯赛难度输入。
- 比赛上下文：来源（单人快速/联赛/杯赛/好友）、距离、规则、阵容配置版本、比赛 ID。
- 结算：比赛 ID、权威结果、金币明细、首次奖励标识、已发放状态。

奖励源采用明确白名单，好友来源直接返回无奖励且不调用任务/评级推进。不能只在 UI 隐藏金币，同时让 `ProgressionManager.awardRace()` 继续到账。

正式金币、签约、升级和首次奖励由后台权威计算/验证，按比赛或事务 ID 幂等；本地原型可模拟，但不能将可改本地记录当正式经济凭据。广告和结算重试恢复原结果。

联机只读取现有角色成长用于比赛，准备页展示等级；不新增杯赛同步协议，不改房间保活/再来一场，不调用 `endGame` 结束重赛房间。

## 10. 分期与验收

第一期：单场联赛、两轮晋级杯、正式赛事固定 AI 配置、快速比赛按角色等级与联赛/杯赛水平自动适配、培养签约、共享金币、轮间存档、奖励幂等、好友零奖励、大厅与必要二级页。

第二期：三轮大师杯、400 米收益校准、轻量表现推荐、成长曲线实测调优。

后续选项：统一属性技术挑战、单人任务、赛后可选加成。真人排位、多轮联机与复杂赛季不在本方案内。

交付前重点验证：

- 同级赛事升级后胜率/成绩确有改善，AI 不随玩家升级即时抵消成长。
- 快速比赛无手动难度入口；新账号、低等级新角色、高等级主力及不同联赛/杯赛成绩下均生成合理阵容，开赛后不再调整。
- 未签约能选用、免费名额只用一次、视频与金币混合路径正确、旧等级保留。
- 所有好友对战结算与重赛不改变金币、积分、任务、首胜、培养和首次奖励标记。
- 每轮只结算一次，杯赛退出续赛、异常恢复与重复回调不重复获利。
- 换角色后账号联赛级别与积分不变；杯赛切换为该角色自己的进度，不能接替其他角色的轮次。轮间升级该角色在下一轮生效，AI难度不变，无整届等级锁定。
- 普通玩家失败后仍有合理成长途径，400 米和低级杯不是唯一合理刷钱方式。
