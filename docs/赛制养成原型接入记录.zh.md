# 赛制与养成功能原型接入记录

日期：2026-09-13。已接入运行时代码，UI为临时功能面板，尚未完成美术定稿和微信真机验收。

## 1. 现在可以操作的流程

- 大厅右侧进入账号联赛、角色杯赛、单人快速比赛或好友对战，左侧继续复用角色预览与角色管理。
- 快速比赛只有200/400米、标准/狂野两组选择，四种组合均可使用；系统根据当前角色等级、账号联赛级别及该角色杯赛成绩选择AI属性区间与操作档。
- 账号联赛六级共用一套积分；换角色不降级或降低难度，旧级别可回打但不增加当前积分。
- 每名角色独立保存一届进行中的杯赛，支持两轮及三轮赛事。退出后从该角色当前轮继续；角色轮间升级立即生效，不能换人接替。
- 杯赛AI来自预设等级与智力配置，不跟随玩家等级缩放；中断重开同轮沿用种子。
- 角色全部免费上场。属性页原升级位置在未签约时显示“培养 / 签约”，打开签约弹窗；签约完成后恢复金币升级。
- 单人结算先通过后台接口保存，再展示金币与晋级说明，返回赛事后显示更新的积分/轮次。
- 好友对战结算不调用养成奖励、不推进联赛/杯赛；隐藏金币图标、金额、奖励标题和生涯提示。房间保活流程不变。

正常200米冠军且表现80分为480金币，同样表现400米为1,056金币；其余名次也必须实际完赛才获奖。金币上限取决于固定赛事系数，不按划水次数无上限增长。

六级AI等级范围：1～3、4～8、9～14、15～20、21～26、27～30；操作档随级别及杯赛轮次组合，新手至专家，极限测试档不进入正式原型赛事。

原型保留10秒尾随结算，不实施旧提案中的未完赛保底；符合后续确认的固定赛事门槛方向。新角色可自行选快速比赛或旧联赛，不自动降低当前联赛难度。

### 成长预算说明

按200米整局80秒粗算，5级需约12～18场有效完赛（约16～24分钟，取决于名次和表现）；15级若平均400～600金币约106～160场（约2.4～3.6小时）；30级若平均450～700金币约543～845场（约12～19小时）。这是收入假设下的预算，不是实测养成时长。失败、400米、阶段奖励与签约支出会改变结果，需实玩继续校准。

## 3. 存档、交易与恢复

- 档案版本提升为5。旧档金币和等级保留；等级大于1的已培养角色视为已签约，不重新收费。
- 账号记录联赛、首次奖励和免费名额；角色记录签约及视频进度；杯赛通过角色ID关联进度，不存整届等级锁。
- 单轮开赛凭据记录实际角色等级、距离、规则与AI配置。下一轮重新读取角色最新等级。
- 结算、签约、角色选择、升级和全档写入串行执行，避免并发保存覆盖金币。最近32份结算回执用于重复请求去重，旧回执被淘汰后也不能绕过当前比赛凭据重新发奖。
- 保存失败不会报告交易成功；本次进程保留失败结算，在下一次交易前重试。设备在存储持续失败时退出，无法保证保存该轮结果，原型不宣称云端可靠投递。
- 同一角色报名别的杯赛前，需在当前杯页面二次点击确认放弃；已得金币保留。换角色不删除其他角色赛程。
- 金币栏加号改成来源说明，暂不再提供看视频领金币；开发者加币仍仅保留在原有调试入口。
