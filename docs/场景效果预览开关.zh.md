# 场景效果预览开关

从大厅进入「场景效果预览」，左上角显示可收起的效果面板，右上角保留退出；空白区域仍可拖拽环绕，滚轮或双指缩放。面板不遮挡左下角性能统计。

| 开关 | 关闭后的行为 |
| --- | --- |
| 观众 | 隐藏整个 SpectatorCrowd 根节点，同时停用欢呼组件、闪光灯和其粒子系统 |
| 泳道浮漂 | 隐藏 lane_float_rope 开头的合批节点 |
| 顶棚灯架 | 隐藏名称含 ceiling 的顶棚、灯架批次 |
| 角色气泡 | 隐藏 Bubbles 根节点，并停止发射与骨骼发射点位置更新 |

默认全部开启。「恢复默认」恢复本次进入时各节点的原始可见性，不强制打开原本隐藏的节点。「收起」只收起面板，保留已选效果；点击「退出」返回大厅，下次进入重新使用默认状态。

关闭是停用现有节点，不销毁和重新加载资产，因此开关期间模型/材质缓冲仍驻留。主要用于比较 Draw Call、三角形数和帧耗时，不应以显存立即下降作为关闭成功的条件。四个开关均为视觉调试，不改变游动路线、镜头、正式比赛配置或联机状态。

实现边界：

- `SceneEffectPreviewState.ts` 仅在此模式创建，初始化和延迟观众生成完成后收集节点，切换时只写受影响节点；没有逐帧场馆遍历。
- `SceneEffectPreviewPanel.ts` 一次创建控件并绑定监听，文字和颜色只在状态变化时更新，使用项目 SemiBold 字体。面板没有逐帧绘制或刷新。隐藏面板后仅保留展开按钮的绘制开销。
- `GameManager` 只负责预览入口、延迟资源通知、气泡开关快照与退出释放；正常比赛不创建开关控制器或 UI。
- 面板使用可见区域命中检测拦截全局相机输入。从控件开始的触摸直到松开都不触发环绕/双指缩放；退出时清理触摸状态。桌面点击与滚轮也按面板可见区域拦截。

验证命令：

```powershell
npx.cmd --yes --package typescript@5.4.5 tsc --noEmit --ignoreDeprecations 5.0 --skipLibCheck
npx.cmd --yes --package typescript@5.4.5 -c "node --test tests/scene-effect-preview.test.cjs"
pnpm fonts:build
pnpm fonts:check
```

已离线验证重复点击的节点/监听数量、局部可见性与原始状态恢复、延迟观众、面板收起、输入拦截和字体字形。未启动或截图 Creator，未做微信真机验收。真机建议固定同一镜头逐项开关，确认画面、统计变化、点击不带动镜头，以及退出再进入的默认状态。
