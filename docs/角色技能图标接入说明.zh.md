# 角色技能图标接入

2026-09-20 按用户确认，将十枚彩色剪影接入大厅和角色详情。健身教练继续复用正式肺部图标。技能效果、角色 ID、存档和联机协议均沿用原逻辑。

## 资源与尺寸

- 定稿原稿：`art/character-skill-icons-v1/`，最终造型及颜色见该目录清单。
- 运行资源：`assets/race/ui/character-skills/`，十枚 112 × 112 透明 PNG，合计 68,928 字节；位于 race 分包。
- 导出：`scripts/export-character-skill-icons.cjs`，需要 Node、Playwright 和 Chrome。将原稿 alpha 遮罩按清单的主题色渲染，匹配已批准的纯色预览。
- 共用底板：`assets/race/ui/lobby-b/skill-base.png`。大厅直径 74px，角色详情 70px。
- 图标尺寸按底板直径缩放：一般 86%；飞毛腿 70%、潜水哥 75%、忍者哥 79%，为池壁、呼吸管及闪光保留圆形安全边距。保留原图透明画布，不裁剪轮廓。
- 教练在大厅保持 46 × 44px、上移 1px，详情按比例缩放。
- `runtime-preview.html`／`runtime-preview.png` 是使用实际运行资源与底板的离线排版核对，不是引擎截图。

## 接入方式

所有能力到纹理的映射集中在 `ResourcePaths.characterSkillIcons`。`PrepareRaceFlow` 的大厅使用已上场角色，详情使用正在浏览的角色；详情不再固定显示旧卡片内的肺部图案。

`CharacterSkillIcon` 只在能力变化时加载。节点和销毁监听一次创建；请求序号阻止过期回调覆盖新角色；独立 SpriteFrame 替换和销毁时释放。加载失败显示“技能”文字并允许后续刷新重试。没有比赛逐帧更新，不重建无关角色预览。

大厅点击技能图标使用 `CharacterAttributeTips` 的技能模式，替换原顶部 Toast。复用属性说明的深蓝圆角底、24px 标题、20px 青绿色技能名、18px 浅色正文和关闭按钮；卡片为 360 × 178，正文保留原有两行描述。弹窗锚定技能图标，通过来源相机与 Popup 相机转换坐标并限制在屏幕内；点击外部或关闭按钮收起，切页与尺寸变化时关闭。属性与技能弹窗互斥，节点与监听复用，仅内容变化时更新文字。此调整只影响本地说明展示，不改变技能效果或联机数据。
