# 角色准备蓄力与离台特效

本轮接入角色自身的出发台蓄力与起跳表现，不调整海豚跳、水面划水或入水水花。

- 聚拢：沿用上身骨骼中心，视觉向下偏 0.20m，短光片从周围约 0.76m 内汇入；单片径向长度 0.10m、最大宽 0.052m。速度随蓄力由 0.85 到 1.6 次/秒变化，衔接时保留连续相位。
- 颜色：低位青蓝，高位暖金；保留衣服纹理，身体轮廓以缓慢的小幅明暗变化加强。旧属性 chargeRed 为兼容材质继续保留名称，绑定颜色已改为浅金。
- 离台：Swimmer.performDive 的原准备延迟结束、抛物线更新之前触发一次 0.32 秒爆发；聚拢停止，出生位置固定，按赛道 direction 沿后方散开。不是输入松手时提前爆发；不修改延迟、初速、轨迹和起跳收益。爆发期间冻结随机种子，避免光点中途换方向。
- 清理：原生命周期负责爆发到时销毁，入水、取消、重开沿用 finishDiveChargeEffect。无蓄力时仍沿用原先无聚拢网格的行为。

预算：一个固定 MeshRenderer / Material，28 张单面朝相机光片，共 112 顶点、56 三角形；常态显示约 14 张。替代原双交叉条与三个 28 段光环（原共 448 顶点、224 三角形）。几何仅构建一次；无新纹理或逐帧 Graphics，沿用角色装饰节流及缓存向量。保留深度测试，因此身体和邻道选手可能遮挡部分光点。

联机：纯显示变化，沿用本机和远端已有 performDive 回放；不新增网络字段、不改输入或权威移动。单机与 AI 发令逻辑保持原样。

验证：TypeScript 5.4.5 通过；13 项起跳/镜头回归通过，新增断言覆盖蓄力和爆发强度变化下准备时长不变、离台事件前不爆发、离台只释放一次。独立 Chrome 实录检查了正常准备镜头的短光片及身后爆发，镜头切换时存在邻道角色遮挡。微信 iOS/Android 真机与联机双端视觉仍需验证。
