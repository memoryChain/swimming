正式输入是显式左右半屏，半透明手掌提供反馈但不限制触控范围。心率 HUD 保留数值、档位与心形跳动；已删除“下划宽度”整行。左右 PERFECT 弧线按本划心率变色并消费实际判定边界，白色进度标记不随心跳缩放。

镜头由 `camera/RaceCameraDirector.ts` 消费比赛快照驱动，不在 GameManager 里堆具体镜头行为；角色动画由动作模块管理，不能因为刷新心率/等级或切换菜单选项而重建模型、重启预览。

比赛 UI 遵守项目 AGENTS.md 的热路径要求：隐藏界面零工作、文字量化且变化才写、动态几何限频并缓存、稳定节点与监听。资源文件检查和离线回放不能替代真机 iOS/Android 微信表现确认。
