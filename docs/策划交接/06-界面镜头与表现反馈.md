# 06｜界面、镜头与表现反馈

## 1. 页面与入口

登录页提供：

- 距离选择：50m、100m、200m，默认 100m；
- 开始正式比赛；
- `MODEL DEBUG`：编辑器/调试用模型观察页；
- `AI DEBUG`：进入 100m 单 AI 调试赛并选择难度。

正式比赛结束后结果面板提供“再赛一次”和返回菜单入口。

## 2. 比赛 HUD

| HUD 元素 | 显示内容 | 当前显示时机 |
| --- | --- | --- |
| 进度条/百分比 | 玩家总进度；另显示 AI 距离文字 | 比赛 HUD 全程更新 |
| 名次 | `名次 X/8` 或 `X/2` | 进入比赛后每帧更新 |
| 计时器 | `分:秒.百分秒` | 从 DIVING 开始计时 |
| 速度 | 当前 m/s | 运行时每帧更新 |
| 遥测 | 稳定度、当前加速度、速度；比赛中追加 HR/EN | 每帧更新 |
| 心率条 | 0–200，按区间换色 | RACING 开始显示 |
| 体能条 | 0–100，低于 50/25% 换色 | RACING 开始显示 |
| 评级/连击 | 完美、良好、失误和当前连击 | 结算后短暂显示并淡出 |
| 跳水蓄力条 | 0–100% 竖向条 | COUNTDOWN/DIVING 蓄力时显示 |
| 提示文案 | 倒计时、蓄力中、出发、滑行中等 | 随状态切换 |

正式触控区节点名为 `StrokeInput`，是全屏按住/松开入口；视觉上不要求玩家选择左右区域。左右甜区盘和空中速度读数是当前实现的调试化反馈，跟随角色世界坐标映射到 2D HUD。

## 3. 输入反馈

- `PERFECT`：黄色文字、连击增加、玩家完美闪光、水花更强。
- `GOOD`：绿色文字和普通水花，不增加连击。
- `BAD`：红色文字、连击清零；普通 BAD 仍可能有基础划水推进。
- 短按踢腿：不显示 BAD 评级，只触发腿部动作和踢腿推进。
- 长按超时：产生 BAD（`timeout`），只给极小超时推进。

评分和连击文字约 0.7s 后开始淡出；角色到达终点后，空中的甜区/速度提示会隐藏。

## 4. 比赛镜头

默认是 `AUTO` 广播镜头，状态包括：

| 模式 | 说明 | FOV |
| --- | --- | ---: |
| AUTO/Broadcast | 赛前环绕、倒计时侧拍、游泳跟随、末段俯视 | 动态约 28–52 |
| SIDE | 泳道侧后方固定跟随 | 36/27 级别 |
| CHASE | 追拍视角 | 36 |
| TOP | 俯视 | 44 |
| FIRST | 第一人称 | 62 |
| FREE | 鼠标拖拽/滚轮自由镜头 | 38 |

赛前广播镜头约 2.35s 完成后才让 `RaceManager` 进入 3 秒倒计时；比赛末段距离终点 8m 内会切固定高位俯视。跳水入水和水下阶段会切换专用镜头，并由相机快照中的 `playerUnderwater` 控制水下视图遮罩。

编辑器快捷键：`C` 循环镜头、`V` 在自由镜头与广播镜头之间切换；AI 调试模式额外提供“跟随 AI/跟随玩家”。

## 5. 角色与场馆表现

- 角色使用低模自由泳骨骼/姿态；手臂按马达左右动作进度驱动，腿与对侧手臂联动，短按时播放对侧踢腿。
- 玩家完美时触发完美发光 effect；不同评级改变水花爆发规模。
- 水下阶段抑制腿部水花，避免水下继续产生表面水花。
- 场馆由低模泳池 prefab、透明水面、夜景天空盒、观众面片和跳台名次牌组成。

## 6. 性能相关表现规则

- AI 角色会按相机视锥和距离分级降低姿态更新频率，远处可冻结姿态并关闭水花。
- 水面、描边、水花、观众应保持低材质数和低面数；这些是表现层开关，不改变比赛规则。
- 正式运行时 `InputManager.pointerInputEnabled=false`，因此场景中的备用鼠标/左右半屏输入不会覆盖 HUD 的自动交替触控。
