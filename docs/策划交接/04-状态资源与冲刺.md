# 04｜心率、体能与冲刺状态

## 1. 这套系统在当前项目中的定位

状态层已经创建并在比赛中更新，玩家 HUD 会显示心率和体能；但它不是一个完全独立的“第二套速度系统”。当前真正接入马达的路径是：

- `efficiencyModifier` 被传入 `SwimmerMotor.setConditionSpeedScale`，并乘在稳定划水的主要加速度上；
- `qualityModifier` 被传入 `setConditionQualityScale`，但当前马达没有读取该字段；
- 体能耗尽只会降低两个 modifier，当前没有硬直、不能操作或自动停游。

所以本文区分“状态层计算结果”和“当前实际表现”。

## 2. 比赛阶段映射

| GameState | Condition `RacePhase` |
| --- | --- |
| `COUNTDOWN` / `DIVING` / `GLIDING` | `START` |
| `RACING`（玩家距离未达到 85%） | `PACE` |
| `RACING` 且玩家距离达到总距离 85% | `SPRINT` |
| `FINISHED` | `RESULT` |

进入 `SPRINT` 后直到结束都保持冲刺阶段；不是根据剩余时间触发，而是根据玩家累计距离比例触发。

## 3. 心率区间

心率使用 0–200 的抽象刻度，不代表真实医学指标：

| 区间 | 数值 | 颜色 | 状态层 modifier |
| --- | ---: | --- | --- |
| `LOW` | `<110` | 蓝色 | 质量 0.70；效率 0.65 |
| `OPTIMAL` | `110–149` | 绿色 | 质量 1.25；效率 1.20 |
| `HIGH_PRESSURE` | `150–174` | 橙色 | 质量 1.00；效率 0.95 |
| `OVERLOAD` | `≥175` | 红色 | 质量 0.80；效率 0.78 |

玩家心率不是每次划水直接加固定值，而是维护一个“持续用力样本”：

1. 每次划水结算，使用 `pressureScore`（当前为 `StrokeMetrics.effortScore`）和跳水启动修正刷新样本；
2. 每帧样本按 1.1/s 衰减；
3. 心率目标在静息 70 和最大稳定努力目标 140 之间插值；
4. 上升速度 42 点/s，恢复速度 26 点/s，并受阶段倍率影响。

`START` 阶段前 5 次划水会使用跳水质量带来的启动修正；高质量跳水修正 0.3，普通 0.6，低质量 1.0。

## 4. 体能

玩家初始体能 100。每次已接受的划水按当时心率区扣除：

| 心率区 | 每次扣除 |
| --- | ---: |
| LOW | 0.3 |
| OPTIMAL | 1.0 |
| HIGH_PRESSURE | 1.5 |
| OVERLOAD | 2.5 |

冲刺阶段再乘冲刺档位倍率：

| 冲刺档位 | 触发条件 | 体能消耗倍率 |
| --- | --- | ---: |
| `STEADY` | effort `<0.60` | 1.0 |
| `PUSH` | `0.60–0.84` | 1.6 |
| `GAMBLE` | effort `≥0.85` | 2.5 |

耗尽后（体能 ≤0）modifier 额外扣除质量 0.3、效率 0.5，并做 0 下限；没有额外硬直或强制减速。

## 5. 冲刺意图与玩家输入

`Swimmer.effortScore` 来自最近一段肢体动作指标，流程层在 85% 进度触发冲刺后持续读取：

- `<0.60`：`STEADY`
- `0.60–0.84`：`PUSH`
- `≥0.85`：`GAMBLE`

冲刺档位目前只改变体能消耗倍率并写入状态层；没有单独的冲刺按钮，也没有独立冲刺速度公式。

## 6. 跳水对状态的影响

跳水结果进入玩家状态层（解析器理论范围是 75–108；由于当前玩家最低力度为 0.30，实际玩家起始心率约从 85 开始）：

- 初始心率按跳水力度从 75 到 108 线性变化；
- 低/普通/高质量跳水分别需要约 7/4/2 次划水进入最佳区；
- 启动阶段前 5 次划水的 effort 会乘对应稳定性修正。

AI 不使用玩家的 `applyDiveResult` 状态路径；AI 状态是根据难度、进度和阶段每帧曲线推导，主要用于表现和 modifier。

## 7. AI 状态曲线

- `START`：目标心率为最佳区下沿附近（随难度从 104 到 116）。
- `PACE`：目标心率位于最佳区内部，难度越高越靠近高侧但更稳定。
- `SPRINT`：高难度 AI 可逼近 OVERLOAD，且随进度增加晚段加成。
- AI 体能按“当前心率区每秒消耗”预设曲线扣除，不由真实划水事件驱动。
- AI 心率和体能不在正式 HUD 展示，AI 的心率区 modifier 会影响其推进。
