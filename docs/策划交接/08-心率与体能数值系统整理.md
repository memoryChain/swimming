# 08｜心率与体能数值系统整理

本文记录心率/体能系统的设计思路、数值链路、改动清单与当前数值，作为后续调参与迭代的基准。

## 1. 核心设计思路

心率与体能是两条完全正交的影响线，各管一头，不交叉：

- **心率（瞬时状态）** 管两件事：动作质量（甜区宽窄）和体力消耗量（每划扣多少）。它不直接影响推进效率。
- **体能（累积资源）** 管一件事：推进效率（打中之后给多少速度）。它不影响动作质量。

一句话总结：**心率管"手稳不稳"，体能管"还有没有劲"。** 两者互不插手。

## 2. 数值链路

```
划水频率（玩家操作）
    │
    ├─→ 心率（瞬时状态，0~200刻度）
    │     ├─→ 心率区（蓝/绿/橙/红四档）
    │     │     ├─→ 动作质量倍率 → 甜区宽窄 → 容不容易打中PERFECT
    │     │     └─→ 体力消耗量（每划扣多少）
    │     │
    │     └─（心率不直接影响推进效率）

划水时机（玩家操作）
    │
    └─→ 划水质量（0~1，打没打中甜区）
          │
          └─→ 推进加速度 = 基础推进 + 划水质量 × 质量推进值 × 体力效率
                                                   ↑
体力（累积资源，0~100池子）─────────────────────────┘
    ├─→ 体力效率（缓启动曲线：0.5 + 0.5 × ratio^0.3）
    ├─→ 体力消耗（每划扣，按心率区）
    └─→ 体力回复（每秒回，按心率区，冲刺加成）
```

## 3. 心率区数值

心率分四档，使用 0~200 的抽象刻度：

| 心率区 | 数值范围 | 颜色 | 质量倍率 | 每划体力消耗 | 每秒回血(非冲刺) | 每秒回血(冲刺) |
| --- | ---: | --- | ---: | ---: | ---: | ---: |
| 低区 LOW | <110 | 蓝 | 0.70 | 0.5 | 0.8 | 1.8 |
| 最佳区 OPTIMAL | 110~149 | 绿 | 1.25 | 1.0 | 0.5 | 1.5 |
| 高压区 HIGH_PRESSURE | 150~174 | 橙 | 1.05 | 1.3 | 0.3 | 1.3 |
| 过载区 OVERLOAD | ≥175 | 红 | 0.85 | 1.8 | 0.15 | 1.15 |

说明：
- 质量倍率只影响甜区宽窄，不影响推进多少。最佳区甜区最宽，过载区最窄。
- 体力消耗按心率区分档：低区最省、过载区最贵。划得越猛消耗越快。
- 回血所有心率区都有，低区回得最多。冲刺阶段所有区额外加成 +1.0/秒。

## 4. 体力效率曲线

体力通过一条缓启动曲线影响推进效率：

```
效率 = 0.5 + 0.5 × (体力比例 ^ 0.3)
```

| 体力比例 | 效率 | 感受 |
| ---: | ---: | --- |
| 100%（满） | 1.000 | 全力推进 |
| 50% | 0.906 | 几乎无感 |
| 25% | 0.830 | 开始有感 |
| 10% | 0.751 | 明显变慢 |
| 0%（空） | 0.500 | 还能游，但只有一半效率 |

曲线特征：高体力时效率几乎不动（平台），最后 10% 断崖式下跌。体力见底不会让玩家完全游不动（底线 0.5），但推进明显打折。

## 5. 冲刺阶段

### 触发
玩家游到 85% 路程时进入冲刺。触发时：
- 屏幕上方弹出大号橙色"冲刺"字样（带缩放弹跳动画）
- 体力条从蓝青色变成火焰橙金色
- 体力回血开启冲刺加成（所有心率区额外 +1.0/秒）

### 冲刺档位
冲刺时根据划水强度分三档，只影响体力消耗倍率：

| 档位 | 触发条件 | 体力消耗倍率 |
| --- | --- | ---: |
| 稳推 STEADY | effort < 0.60 | ×1.0 |
| 发力 PUSH | 0.60 ~ 0.84 | ×1.6 |
| 豪赌 GAMBLE | ≥ 0.85 | ×2.5 |

### GAMBLE 的风险链
豪赌不额外加惩罚，风险从回血与消耗的差值中自然产生：
豪赌 → 心率冲到过载 → 单划消耗 1.8×2.5=4.5 → 回血只有 0.15+1.0=1.15/秒 → 体力净掉 → 体力下降 → 效率曲线下滑 → 推进打折。
玩家在赌"体力掉光前能不能到终点"。

## 6. 正交关系

| 维度 | 数据来源 | 影响 | 不影响 |
| --- | --- | --- | --- |
| 心率 | 划水频率 | 动作质量（甜区宽窄）、体力消耗量 | 推进效率 |
| 体能 | 消耗 - 回血 | 推进效率（曲线） | 动作质量 |

体力见底只让你游不快，不会让你手抖。心率过高只让你手抖，不会直接让你游不快。两者完全独立。

## 7. 改动清单

以下是本次整理过程中所有改动的归纳：

### 7.1 删除连击叠速死代码
- 删除 RHYTHM_BALANCE 中 8 个已失效的连击速度字段（maxComboBonus 等）
- 删除 RhythmTypes.comboSpeedBonus 字段（从未赋值）
- 删除 StrokeQualityScoring 日志中的 comboBoost 拼接
- 连击计数本身保留（给 HUD 显示和 XP 奖励用）

### 7.2 修复过速衰减 bug
- _effectiveComboOvercapDecay 原来误读 perfectComboMaxOvercap（超速幅度），改为读 perfectComboOvercapDecay（衰减率）
- 跳水超速回落速度回到设计值
- perfectComboMaxOvercap 和 perfectComboOvercapDecay 接入调参面板

### 7.3 接通质量轴（放大甜区容差）
- 新增 qualityZoneScaleStrength 参数（默认 0.5）
- qualityModifier 现在缩放 PERFECT 甜区半宽（相对中心，clamp 在 GOOD 区内）
- 心率最佳区时甜区变宽（更容易打准），过载/低区时变窄
- UI 黄框自动跟随甜区变化

### 7.4 效率维度从心率挪到体力
- 删除 efficiency.zoneModifier（按心率区查表）
- 改为体力曲线驱动：efficiency = 0.5 + 0.5 × (energyRatio ^ 0.3)
- 心率不再影响推进效率，只保留质量维度

### 7.5 体力回复机制
- 新增 regenPerZone：所有心率区都回血，低区回得最多
- 新增 regenSprintBoost：冲刺阶段所有区额外加成回血
- 让冲刺成为"燃起来"的情绪峰值，而非燃料耗尽的爬行

### 7.6 删除冲刺豁免开关
- 原来冲刺阶段体力耗尽不扣惩罚（phase !== SPRINT）
- 渐进式效率曲线下不再有突变，豁免开关删除

### 7.7 AI 体力回血补齐
- AiConditionModel 原来只有 drainEnergy 没有回血，越游越慢
- 补充 regenEnergy，和玩家用同一套回血参数

### 7.8 删除体力对质量的跨管惩罚
- 删除 depletedQualityPenalty（体力耗尽时额外扣质量 0.3）
- 删除 depletedEfficiencyPenalty（已废弃为 0）
- 删除 staminaSkill（高体力角色耗尽惩罚减半的养成加成）
- 清理所有相关字段、参数传递链路
- 彻底贯彻"体力管效率、心率管质量"的正交原则

### 7.9 数值微调
- 体力消耗：低区 0.3→0.5，高压区 1.5→1.3，过载区 2.5→1.8（压缩高低区差距）
- 质量倍率：高压区 1.0→1.05（拼命划的补偿），过载区 0.8→0.85（缓和断崖）
- 冲刺回血加成：1.6→1.0（提高 GAMBLE 风险）

### 7.10 冲刺视觉反馈
- 屏幕正上方弹出大号"冲刺"字样（72号字，金色，橙色描边）
- 进冲刺时缩放弹跳动画（backOut 缓动），退出时淡出
- 体力条冲刺时切换火焰配色（橙金色）
- 完赛/重赛时自动关闭冲刺指示
