# 鲨鱼大乱斗玩法说明

## 已确定规则

- 玩法归入“娱乐模式”，固定为 200 米。
- 鲨鱼属于关卡，不属于任何角色技能，也不消耗角色蓄气。
- 比赛开始后第 15、35、55 秒各触发一轮追猎。
- 第一轮前鲨鱼隐藏；首次出现后，轮次之间继续在泳池低速巡游，并作为会推挤选手的重型障碍。
- 每轮按距离选择最近且可攻击的选手，先警告和锁定，再给予短暂变向窗口，随后追击。
- 每轮最多咬中一人；被咬者永久淘汰，进入现有“退出／观战”流程，不复活。
- 全场最多淘汰三人。第三轮结束或达到三人后，鲨鱼下沉并停止参与比赛。

## 表现

- 使用正式 `SharkModel`、循环游动动画、目标锁定标记与咬合水花。
- 画中画只在警告、追击和咬合阶段开启，最高 30Hz；巡游阶段不额外渲染。
- 警告从泳池全景推进到鲨鱼本体；咬合后画中画保留约两秒。
- 赛中横幅按状态边沿更新，不在每帧重写文字。最终成绩把被咬选手标记为“鲨鱼淘汰”。

## 联机权威

- 单机直接运行同一套关卡控制器。
- 联机只由房主决定目标、轨迹、咬合与永久淘汰；其他设备不自行判定结果。
- 淘汰使用可靠帧事件传输，周期快照携带鲨鱼完整状态和淘汰掩码兜底。
- 房主掉线后，新房主从最近收到的鲨鱼状态继续运行，不重置轮次或已淘汰选手。
- 协议版本为 48，旧版本不能与本版本混跑。

## 验证清单

- 单机确认三轮时间、最近目标切换、永久淘汰、观战与最终排名。
- 双端确认目标、画中画、咬合、淘汰和最终成绩一致，并测试房主在三种状态下退出。
- iOS／Android 微信真机确认画中画开关、透明水花、模型贴图及比赛帧耗时。
