# 鲨鱼大乱斗玩法说明

## 已确定规则

- 玩法归入“娱乐模式”，固定为 200 米。
- 鲨鱼属于关卡，不属于任何角色技能，也不消耗角色蓄气。
- 比赛开始后第 15、35、55 秒各触发一轮追猎。
- 第一轮前鲨鱼隐藏；首次出现后，轮次之间继续在泳池低速巡游，并作为会推挤选手的重型障碍。
- 每轮按距离选择最近且可攻击的选手，先警告和锁定，再给予短暂变向窗口，随后追击。
- 每轮最多咬中一人；被咬者进入 2.5 秒急救阶段，本地玩家画面压暗并显示“急救中……”，随后在原赛程进度和自己的泳道中心重新入水，初速度清零。
- 重新入水后获得 2 秒无敌保护；击倒和无敌期间不能再次被鲨鱼锁定。
- 第三轮追猎结束后，鲨鱼下沉并停止参与比赛；不会因为咬中选手而提前结束整场比赛。

## 表现

- 使用正式 `SharkModel`、循环游动动画、目标锁定标记与咬合水花。
- 画中画复用娱乐玩法共用的 224×126 RenderTexture 和事件相机，只在警告、追击和咬合阶段开启，最高 30Hz；巡游阶段不额外渲染。
- 警告从泳池全景推进到鲨鱼本体；咬合后画中画保留约两秒。
- 鲨鱼横幅已提炼为六种娱乐玩法共用的赛事广播和个人反馈；文字按状态边沿更新，不在每帧重写。击倒阶段使用独占压暗层，无敌提示使用统一持续状态条，角色节点始终复用，主镜头持续跟随原目标。

## 联机权威

- 单机直接运行同一套关卡控制器。
- 联机只由房主决定目标、轨迹、咬合与击倒；其他设备不自行判定结果。
- 击倒使用可靠帧事件同步泳道和权威重生距离；周期快照携带鲨鱼完整状态，以及各泳道的击倒／无敌阶段和剩余时间兜底。
- 房主掉线后，新房主从最近收到的鲨鱼和恢复状态继续运行，不重置轮次或让选手永久离场。
- 协议版本为 61，旧版本不能与本版本混跑。

## 验证清单

- 单机确认三轮时间、最近目标切换、2.5 秒急救、速度清零、2 秒无敌和镜头连续跟随。
- 双端确认目标、画中画、咬合、恢复阶段和重生位置一致，并测试房主在三种状态下退出。
- iOS／Android 微信真机确认画中画开关、透明水花、模型贴图及比赛帧耗时。
