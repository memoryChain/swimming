# 水球点名玩法说明（原炮火逃生赛）

更新日期：2026-09-22

## 玩法定位

水球点名是 200 米娱乐玩法，替代原来的末位淘汰赛。入口继续使用稳定模式 ID `last-place-brawl`，避免旧存档和既有联机房间选择失效；玩家看到的名称、规则、HUD、结算原因和联机语义均已切换为水球点名；内部 cannon 与旧文件名作为兼容标识保留。

随机性只决定炮击目标、落点微偏和波次组合。预警出现后落点锁定；命中结果由玩家与落点的距离分区确定，不使用暗骰，也不再永久淘汰选手。

## 比赛规则

- 全程安排十次炮击，触发距离为 25、48、70、82、104、116、138、148、158、170 米。
- 180 米后不再生成新炮击，保留最后 20 米冲刺。
- 每发小水球预警 1.25 秒，水面同时显示红色核心区和橙色外围冲击区。
- 核心区约为纵向 1.05 米、横向 0.82 米的椭圆；若多人同时进入，只击倒离中心最近的一人。
- 外围冲击区约为纵向 3.4 米、横向 2.85 米；命中只产生后退、横向击飞、翻滚、布娃娃松动和大水花，不淘汰。
- 命中、危险区查询和 AI 避让统一使用场景的折返坐标换算，不以累计游程差判断远近；返程选手实际进入落点范围也会受击。
- 连续炮击不重复选择同一名目标；预警后小水球不会继续追踪选手。
- 中心命中沿用 B1 的 3.5 秒暂停与浮圈调整：短暂受力后回到水面搭圈，显示“调整中”恢复卡；按原位置与泳道恢复、速度清零，随后沿用 2 秒保护。水球外观与回弹不改变恢复时长和输入恢复时刻。
- 击倒期间和无敌期间不会再次成为炮击核心目标。炮击不会因暂时只剩一名可攻击选手而结束。

## 目标与公平性

房主从仍在比赛的选手中选择目标，并根据目标当前速度预估落点。每次只有一个活动小水球，因此不会生成覆盖全部泳道、没有逃生路线的叠加危险区。炮击目标可能是领先者或后方选手，不固定惩罚末位。

AI 在小水球预警后读取落点，按自身操作纪律产生不同反应延迟，再向核心和外围之外的最近可用区域横移。AI 使用正常转向输入，不免疫命中。

## 表现与性能

- 岸边使用蓝白运动场水炮、橙色短喷口和厚塑料底座；源文件为 [WaterBallCannon.blend](../art/water-play-obstacles/WaterBallCannon.blend)，运行时为 assets/race/items/WaterBallCannon.glb。每门两网格、共用一个不透明顶点色材质，1,012 三角面，无贴图。
- 两侧水炮在预告期用 1.8 秒入场，结束或取消预告用 1.2 秒从当前位置退场。底座纵向固定在看台中段；只在发射时转向，不沿看台追赶落点。晚快照直接就位。
- 小型蓝青色水球半径 0.25m，与 C 的橙色肩背定时水球区别明显。炮口端面本地中心 (0, 1.04, 1.02)m 变换到世界后作为弹道起点；发射后喷头用 0.28 秒轻微回弹并归零。原落点锁定、1.25 秒预警与 5.8m 弧线增高保持。
- 固定节点和同源几何在加载期间立即提供外观，GLB 成功后只交换网格引用；失败保留新造型。不会回退成旧军事炮架，也不会因晚加载重播发射或显示已经退出的水炮。
- 落水直接复用 B2 的 CANNON／EXPLOSION，强度 1.08、时长 0.95 秒，定位真实水面落点。没有第二套喷水池；B2 白蓝水冠、水柱、碎水与余波取代旧暖色爆心。
- 世界装饰保持 20Hz，水球和落点预警只改变变换／显隐，无逐帧网格构建。HUD 最高 10Hz，最终字符串变化才写入。
- 已有水球画中画读取实际水球位置，飞行时同时展示轨迹与落点，按两者包围范围调整镜头距离，避免远侧长投的落点出框；落水后保留原停留时间。保持原优先级、单一 256×144 RenderTexture、最高 30Hz；不新增浮标镜头。
- 图标 icon-cannon.png 与源模型一致，保留旧资源身份；20 组预告／行动文案使用水球点名口径，原确定性选择和轮换节奏不变。
- 实际音频只有背景乐与划水水声，没有水炮专属炮击／爆炸播放接线；本轮未新建音效系统或替换无关音乐。

## 联机权威

- 单机和房主运行炮击调度、目标选择和命中判定；访客不自行决定结果。
- 随机来源为房主种子派生的 `SeededRandom`，不使用 `Math.random()` 影响比赛结果。
- 可靠事件 `l` 同步炮击编号、落点、预警时长和版本；可靠事件 `x` 同步命中掩码、击倒泳道、权威重生距离和版本。v92 在 `x` 尾部追加本发爆心横坐标（毫米整数），并复用事件元数据携带比赛模拟时钟。
- 受击去重独立于活动小水球修订。下一发快照先到时，上一发仍可补结算一次，冲击方向取上一发爆心，同时保留当前预警和镜头；超过 3 秒的旧冲击不补播，返场代次仍隔离旧轮事件。广播降级时复用 32 条、3 秒、每次最多 4 条的有限重发缓存，不扩大 `S|` 快照。
- `S|` 快照同步炮击版本、完成炮击掩码、当前活动小水球，以及每条泳道的击倒／无敌阶段、剩余时间和重生距离，用于丢包恢复和房主迁移。
- 击倒不写入永久淘汰结果；退赛、断线等既有永久离场语义保持不变。
- 炮火扩大外围冲击范围的语义自协议版本 68 起生效；炮火继续通过既有 `x` 事件命中掩码同步核心击倒与外围击退。当前全局协议版本统一以 `NetRaceProtocol.ts` 和联机总文档为准，旧客户端不能与当前版本混跑。
