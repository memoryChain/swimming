# 生涯界面接入记录

## 入口与实现

大厅「生涯之路」进入新版页面。`CareerPrototypePanel`负责导航与数据命令，`CareerEventPage`负责稳定显示树，`CareerPageModel`负责六级赛事状态，`CareerPageWidgets`负责共享纹理与控件。资源路径集中在`ResourcePaths.careerUi`。

接入内容包括横向六级路线、锁定徽章、角色栏、积分条、联赛与角色杯赛、两轮及三轮赛程、淘汰重赛、真实晋级回顾、最高级再次挑战、规则及放弃确认。更换角色调用现有角色管理页，返回时保留浏览级别，按新角色读取杯赛；旧级别比赛结束回到旧级别，只有实际晋级结算显示下一联赛与上届夺冠回顾。快速比赛保持原有距离、规则和开赛命令。

## 美术与字体

- 主稿：`art/career-ui/生涯之路.psd`，沿用原画布1280×720。
- 切图：`assets/race/ui/career-v1`，24张PNG，共约3581KiB，全部放race分包。
- 来源、裁剪及尺寸：`art/career-ui/runtime-assets.json`。
- 导出：`scripts/export-career-runtime.jsx`；优化与徽章裁切：`scripts/prepare-career-assets.py`。
- 复用现有标题底、返回图标、角色肖像及全局金币/设置栏。角色头像按圆形Mask裁切。
- 按钮文字、名称、状态均为Label，使用随包ShuiMasterUI字体；不依赖PSD中的本机字体。

页面主体以安全区等比容纳，背景铺满。宽窄屏只在尺寸事件修改变换；共用顶栏仍由原组件管理。实际微信胶囊与顶栏叠放需真机确认。

## 生命周期、性能与联机

页面无逐帧更新，不接入GameManager.update。状态刷新只改有变化的文字、颜色、贴图、进度与可见性；重复选择不重建节点、监听或角色模型。纹理复用现有缓存，九宫格独立SpriteFrame随页面释放，异步回调检查资源路径及节点有效性。切换页面立即释放订阅，避免延迟销毁影响新页面。

此次不修改运动、AI、结算、随机数或联机协议。赛事命令继续经过原有单人生涯路径；好友赛不计生涯奖励的门控保留。新增美术只在赛前界面使用。
