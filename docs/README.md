## 文档维护规则

1. 一条现行规则只在主文档维护；过程文档链接主文档，不另存一套“当前数值”。实际值由代码配置与启动后加载的调参决定。
2. 未实现、待确认或停用内容在标题下说明状态；不能把设计提案或离线验证写成已上线／真机通过。
3. 操作流程放操作手册，模块职责放技术说明；某次接入、哈希、验证结果和回退证据放开发记录。被替代但有追溯价值的内容移入历史归档。
4. 新增或迁移文档后，更新所属目录 README，并同步修正文档、AGENTS.md、共享技能、脚本与测试中的路径。文档里的 `assets/`、`scripts/` 等路径默认相对项目根目录。
5. 角色／UV／动作技能真源在 `.agents/skills/`，UI 通用经验在 `tools/codex-skills/cocos-ui-asset-pipeline/`；场馆编辑仍先读 `sceneresource/README.md`。
6. 本地 PSD、预览图与源稿脚本位于美术设计的制作源稿／界面方案目录，沿用 Git 忽略规则；Markdown 说明共享。原已纳入 Git 的背景参考图继续保留，不把源稿放进运行时 assets。

迁移、归档与删除的完整清单见 [本次整理记录](开发记录/文档整理/2026-10-01文档整理记录.zh.md)。此前清理的文档与本次删除的重复资料均可从 Git 历史追溯。
