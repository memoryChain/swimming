- 领奖取景中心相对冠军台面高度为 0.65（从 1.2 下移），镜头位置与目标同步下移，露出领奖台正面，不改变近景距离。

- 右侧遮罩为 Photoshop 制作的 `right-shade.png`（512 × 16，约 0.9 KiB）：深蓝 RGB(5,18,39)，左端透明，前 36% 渐变至约 62% 不透明。单个 Sprite 放在 UI 最底层，向屏幕右边缘和上下边缘延伸，不遮住文字、不拦截触摸、不做逐帧绘制。可编辑遮罩源为同目录交付文件夹中的 `右侧渐变遮罩.psd`；不覆盖原结算 PSD。
- 排行榜行高 68、步长 70；前三名使用特殊底图及独立奖牌，TOP 暗纹是 Label；本人描边独立，姓名和用时用绿色。
- 返回按钮复用 `onlineRoomUi.exitButton`，主按钮复用 `lobbyUi.startButton`，小鸭货币复用 `characterUi.upgradeCurrency`；头像与圆底复用 `avatarPickerUi`。不复制这些资源，不把文案烘焙进按钮。
- 复用按钮贴图包含透明边距。运行时按已知画布/边距补偿视觉尺寸，保持 `Sprite.SizeMode.CUSTOM`、`trim=false`，点击区域保持设计尺寸。
- 按最新反馈，数字和英文复用 `PROJECT_UI_ENGLISH_BOLD_FAMILY`（当前为 `Arial Black`），与联机/金币栏一致；中文继续用随包 `ShuiMasterUI-SemiBold.ttf`。模式距离与“米”、普通称号中的名次数字、数值与未完成状态已拆分 Label。昵称使用完整字形回退。
- 注意：当前工程只有两份 ShuiMaster 中文字库，没有独立的 Arial Black 字体文件；上述英文入口是系统字体声明，不能称为已打包字库。后续若要求各平台字体完全一致，需要提供具有游戏嵌入授权的英文字体再接入，不能擅自复制本机商业字体。
- `lineHeight = fontSize + 4`，文本框高为 `fontSize + 10`，避免 SHRINK 因默认行高错误缩字。
- 导出描边时检查 alpha，而非仅查看透明像素中的 RGB；临时副本栅格化保留透明描边与柔光，不修改源矢量。
- 本人绿框导出必须保留原形状的 `fillOpacity`；设为 0 会同时去掉实色矢量描边，仅剩外发光，露出深色内圈。运行时按原 PSD 将 `SelfHighlight` 放在行底板下方，保留 666 × 117 的外扩画布，不缩放到行尺寸。修复复用原 PNG 与 `.meta`，不新建 PSD 版本。

## 数据、交互与联机

- 领奖鞋底增加 0.08m 的专用站位补偿，保留共用起跳/预览站位参数，不影响比赛姿态。
- 领奖补光由 `AwardsLighting` 临时提升现有固定卡通顶光暗面（0.62 → 至少 0.86）并减弱冷色阴影；退出恢复原材质参数。现有角色材质不响应普通点灯，场馆也曾出现动态光源剔除闪烁，因此不增加点光源、灯光 pass、实时阴影或新 Shader。补光用于获奖角色，不改全场照明、描边和水面。
- 彩带 48 → 96 片，12 × 8 分布，仍是一个网格/一个材质，768 顶点、1152 triangles；顶点提交限制为最多 30Hz，缓存提交对象，隐藏后零更新。相对原有 48 片、60Hz，顶点更新吞吐量相近，但实际设备上仍须确认帧率；不是零成本特效。

- 排名和成绩直接显示既有 `resolveNetLeaderboard` 的权威名单；不在 UI 重排、不编造未完成时间，不新增网络协议字段。
- 我的成绩和平均速度来自同一权威用时。退出、淘汰、未完成不授予前三名荣誉色，显示各自状态。
- 本机头像读取 PlayerData；远程成员按已同步泳道到房间成员身份的映射取头像；AI 按名字稳定选择现有头像，不随排名变化。
- 单机“返回大厅”跳过开游封面；“再来一局”走原有重赛流程。
- 联机主按钮为“返回房间”，不出现本地重赛按钮，沿用 keep-alive 房间重连，不调用 endGame。键盘确认走同一个动作与防重复保护。
- UI 只挂载一次，八个行控件复用，无 update 循环。异步图片回调验证节点有效性和请求路径，旧头像/名次请求不能覆盖新状态。变化字段才赋值。

## 验证与维护命令

1. 运行 PS 导出脚本；让现有 Creator 自动导入并生成 `.meta`，不要自动启动/重启 Creator，不手工造 UUID。
   `textures:check` 只审计已有导入信息；新 PNG 缺少 `.meta` 时，即使该命令通过也不能视为新图已验收。`test:results` 会额外拦截缺失的资源 `.meta`。
2. `python3 scripts/optimize-ui-images.py --root assets/race/ui/settlement-v1 --apply` 无损重编码。
3. `pnpm textures:fix`、`pnpm textures:check`。
4. 新文案后 `pnpm fonts:build`、`pnpm fonts:check`，禁止手改字体或生成字符表。
5. `pnpm test:results`、`pnpm test:awards`、`pnpm test:room`；固定 TypeScript 5.4.5 类型检查。
6. `npx --yes --package typescript@5.4.5 -c "node scripts/preview-settlement.cjs"` 生成六种状态的离线 HTML，输出在 `output/settlement-runtime`。这只能验 UI 排版，不代表 Cocos/真机视觉与性能验收。

本次非 GUI 验证包含资源引用、alpha/尺寸、重复显示的节点与监听数量、旧异步回调、单机/联机按钮、字体与纹理策略。仍需用户在现有游戏会话及 iOS/Android 微信真机确认：角色手脚不被裁切、真实场馆下文本可读、不同屏幕比例、双端权威成绩、返回房间后二次开赛。
