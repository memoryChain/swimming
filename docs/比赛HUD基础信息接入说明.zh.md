# 比赛 HUD 基础信息与海豚跳按钮

本次按用户指定范围接入速度、心率、体力、赛程进度、右侧头像排名及海豚跳按钮；左右手掌按钮、节奏线、评价和中央倒计时不在本次美术替换范围。中央数字已明确是倒计时，不能解释为连击数。

## 源稿与导出

使用桌面 `划水大师/比赛HUD/比赛HUD-1280x720.psd`，按现有 1280×720 源稿等比适配，不擅自变更旧 PSD 尺寸。
`scripts/export-race-hud-status.jsx` 从当前已打开的源稿导出 10 张小纹理到 `assets/race/ui/race-hud-v1`。不修改主 PSD，不包含背景场景或文字。

单色遮罩先合成图层效果再填白，避免海豚原图层的颜色叠加样式盖掉白色。运行时用 Sprite 颜色区分状态。
原导出约 200 KiB，`scripts/optimize-ui-images.py --root assets/race/ui/race-hud-v1 --apply` 无损重编码后约 11.9 KiB。全部图片小于 16K 像素，遵循项目小纹理保留 PNG 策略，不强行增加 ASTC 副本。
新资源与 `.meta` 必须由现有 Creator 会话导入；所有非平铺纹理使用 clamp-to-edge，禁止 repeat。

速度字体为已确认的 `ShuiMasterSpeed-Heavy.ttf`，源码复制到 `scripts/build-speed-font.py` 并用项目相对路径输出到 `assets/race/fonts`。仅覆盖数字、小数点、空格和 m/s，不能拿它显示中文。其余静态文字使用随包 ShuiMaster UI；所有文字仍为 Label。字体加载完成后才创建赛中 HUD，避免第一次开局回退字形。

## 数据与更新

入口为 `RaceHudStatusView`，由 `SpeedStarsUiPrefabBuilder` 挂载，并在 `GameManager.update()` 内先判显示状态，再按 0.1 秒采样。

- 速度：真实 `currentSpeed`，两位小数；原玩家头顶速度隐藏。
- 心率：真实心率整数，圆环按心率/200；心形及进度始终为红色，OVERLOAD 时警示在采样时钟下闪烁。
- 体力：使用 `PlayerConditionModel.energyRatio`，正确考虑养成修改后的上限，不把体力点数当百分比。
- 泳程：全程米数取 `getRaceDistance()`，进度为当前总距离/全程，转身后不重新归零。
- 蓄气：当前能量/上限。只有满蓄气且比赛正在进行时按钮可点；点击立即锁定，下一次采样按真实状态更新。
- 排名：复用原 `getLiveLeaderboard()` 的 5Hz 稳定列表与完成顺序。通过泳者对象绑定头像：本人取 PlayerData，远端真人按稳定泳道找到房间成员，AI 优先匹配对应模型的头像，找不到时按泳道选择稳定回退。不得按名次选头像。
- 本人排名数字、头像和金圈一起放大；每个名次固定节点，通过内容与位置更新，不重新排序节点或重新建表。换位时异步回调核查当前请求和泳者身份。

圆环使用一张纹理＋Sprite RADIAL 填充，起点 0.625、顺时针 0.75 圈；无每帧 Graphics 绘制。读数和填充仅在量化值变化时赋值；隐藏时不采样、不格式化、不更新排名。原 UIController 横条更新在新 HUD 存在时直接返回。尺寸变化监听在销毁时移除。

## 起跳交互与联机

删除 InputRouter 中“双侧同时按住”的检测和计时状态。左右半屏仍分别负责原划水/踢腿分类，不新增自动交替或可见划水按钮。
海豚按钮使用 Button＋BlockInputEvents，满蓄气点击调用原 `GameFlowController.handleDolphinJump()`；原 `tryDolphinJump()` 成功后才上传 `NetInputKind.DolphinJump`。不修改物理、能量消耗、网络字段或房间保活流程。
起跑台的长按蓄力/松手跳水仍由 RaceStartView 和原输入处理，不与赛中海豚跳混用。

## 检查方式

`pnpm test:hud` 覆盖隐藏零采样、10Hz 更新、重复值不写属性、满蓄气单次点击、非比赛禁用、头像换位与迟到请求、节点稳定性、宽窄屏、安全区和双侧长按取消海豚跳。
图片 alpha/尺寸、专用字体字形、TypeScript 5.4.5、字体子集及纹理政策分别校验。使用实际节点布局做离线合成检查，不能把它当作 Cocos 或微信真机的显示证明。

真实设备仍需检查长时间比赛、左右手多点操作同时点击海豚按钮、能量清空、手机安全区、本人换位、iOS 帧耗时以及单机/联机两端身份一致性。不得为验收自动启动或截图 Creator。
