本次依据 Photoshop 中的 `划水大师-大厅-B版-1280x720-v1.psd` 当前可见图层，按实际 1280×720 画布接入。截图中的名字、币数、等级、属性、联赛积分都是设计示例；运行时沿用当前选中角色和 PlayerData 存档。主 PSD 未修改，导出只操作临时副本。

## 资源与导出

- 导出脚本：`scripts/export-lobby-b-runtime.jsx`，从脚本自身位置解析项目根路径；先激活对应主 PSD 再执行。

- 所有按钮文字、等级、属性、积分、联赛名称都由 Label 显示。静态字形来自项目生成字体，未将文字烘焙到按钮。

- 生涯徽章目前复用本稿金色徽章；没有伪造六档独立徽章资产。

## 功能与生命周期

- 大厅生涯摘要由 `CareerPrototypePanel` 承载，现有 `CareerEventPage` 继续处理生涯地图与快速比赛。
- 当前角色有进行中杯赛时显示“继续杯赛”，进入该角色该杯赛所在级别；否则显示“继续生涯”，进入最高已开放联赛。
- 积分进度按实际 0～100 显示。100 分显示已开放晋级杯；最高联赛不越界读取下一站。
- 快速比赛沿用原距离、规则和开赛流程；联机沿用原好友房间入口、清除单人赛票的行为，不修改房间保活、网络协议或比赛结果。
- 属性点击沿用原说明；技能点击显示当前技能名和说明（4 秒）。`breathControl` 使用肺部图标；其他角色缺少专用美术时显示“技能”文字，不让所有角色误用呼吸图标。
- 角色与培养按钮沿用角色页；AI 测试入口保留为左下小型文字入口。
- 数据事件仅更新变化的文字、进度缩放与可见状态。没有新增逐帧 UI 工作，也不会因为积分或金币变化重建模型。
- 退出释放页面监听、窗口监听与持有的 SpriteFrame。背景异步请求有令牌校验，避免角色页与大厅快速切换时被迟到的图片覆盖。

- 当前积分采用 26px 青色 SemiBold、右对齐；分母“/ 100”独立为 16px 灰色 Label，二者按设计基线定位。当前值仍读取真实积分。
