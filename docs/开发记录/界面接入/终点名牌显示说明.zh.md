# 终点名牌显示

终点名牌与泳道昵称共用 `makeSwimmerNameLabel`、`makeLivePlacementBadge` 和距离缩放策略。保留实际完赛名次，取消深色胶囊背景、额外描边及独立字形；昵称使用 15px 动态文本字体，名次使用项目粗体和 22px 正圆，普通圆标紫色、本人金色。昵称截断规则与泳道一致。

终点定位使用 `Swimmer.getHeadTopScreenPosition()` 提供的实际头顶投影，名牌下边缘至少留 10 个 HUD 像素。两阶段投影先收集已完赛角色的头顶区域，再放置名牌，向上避开其他头肩保留区和已放置名牌。屏幕边缘按实际文字宽度内收；上方无空间则隐藏，不把名牌压回脸上。姿势与手势特别夸张时仍应真机检查。

名牌在完赛事件创建一次，昵称和名次不在投影循环中重复赋值。终点投影约 30Hz，使用固定条目和复用向量，排序仅发生于新增结果时；隐藏时无投影工作。成绩、排名来源和联网数据不变，领奖阶段继续隐藏终点名牌。

自动测试覆盖样式共用、正圆名次标、无长条背景、相邻头顶避让、名牌互避、顶部空间不足隐藏、隐藏零投影与清空重开；同时回归既有 HUD 测试。未启动或截图 Creator。最终观感需在现有游戏会话中验证，包括近景、边缘泳道、长昵称和多人连续触壁。
