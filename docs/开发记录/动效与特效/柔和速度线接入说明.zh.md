# 柔和速度线接入说明

2026-09-13，替换旧的硬边漫画放射速度线，沿用现有比赛入口。

## 表现与状态

- 两侧各三条柔边直线贴图，长短、垂直位置和循环相位错开；中央不绘制速度线。每条从边缘内侧向外掠过，淡入淡出，不铺满画面。
- 普通冲刺仍使用已有 `speedLineThreshold` 与镜头条件；海豚跳由真实 `isDolphinAirActive` 和 `flightPitch` 驱动，上升时显现，到顶淡出，落水及水下阶段关闭。
- GameFlowController 仅多传已有视觉状态，不改轨迹、判定、输入、能量或网络协议。隐藏 HUD、非比赛阶段与切换不可用镜头停止表现工作。

## 实现与预算

`CameraSpeedLineOverlay.ts` 复用六个 Sprite + UIOpacity，替代旧 24 条 Graphics 放射几何。没有新增常驻组件 update、Graphics.clear 或材质实例。30Hz 更新位置/透明度；位置和角度量化，属性值改变才写入；隐藏时不取布局、不投影、不改变换。HUD 销毁重建时重置尺寸和状态，旧加载回调按根节点身份丢弃。

纹理为 `assets/race/ui/vfx/SoftSpeedStreak.png`（256×32 RGBA），由 `art/dolphin-jump-preview/SoftSpeedStreak.svg` 离线栅格化。源稿包含两端透明渐变和柔边，运行时仅采样贴图，不执行 SVG 滤镜。导出时使用透明背景、256×32 CSS 像素、零页面边距；替换时保留 PNG 的 `.meta`。资源路径集中在 `ResourcePaths.softSpeedStreak`，使用现有 UI 纹理缓存加载器共享 SpriteFrame。

额外六个透明四边形，有透明覆盖和变换更新开销；同纹理有合批机会，但实际 draw call 与 iOS 帧耗需真机测量，不以节点数直接推断。

## 验证范围

- TypeScript 5.4.5 类型检查通过。
- `tests/camera-speed-lines.test.cjs`：隐藏零布局/变换、30Hz 采样、顶点阶段淡出、落水关闭、父 HUD 隐藏、重建及过期资源回调，共 3 项通过。
- Creator 已导入新纹理，压缩策略检查通过（238 项）；小纹理按策略保留原图。
- 独立浏览器使用实际 GameFlow 相机与速度线更新链路录制海豚跳，确认柔线只在两侧出现。录制隐藏读数方便查看特效，没有安装临时速度线覆盖层。
- 微信 iOS/Android 真机、完整 HUD 遮挡及不同宽屏设备仍待体验验证。

本次接入的是速度线。此前海豚跳大水花重设计仍位于 `art/dolphin-jump-preview/preview.js`，属于独立预览；正式游戏继续使用已有起落水花逻辑。

## 可见度修正

用户体验反馈偏淡后，线条长度由屏宽 22% 调至 28%，贴图显示高度由长度的 1/8 调至 1/4，峰值透明度由 155 调至 235。轨迹起点从半屏宽 79% 内移到 66%，让有效轮廓进入画面；淡入淡出从 sin² 改为 sin，延长可辨识阶段。上升俯仰达到 0.20 弧度即可满强度，仍在到顶后淡出、落水关闭。六个节点和原纹理复用不变，透明覆盖面积增加。类型检查和 3 项回归通过。

## 直线形态定稿

按用户最新反馈，纹理中心线改为水平直线，两端收尖渐隐，保留柔边。此前增强后的长度、粗细、亮度、两侧位置、错开相位与起落节奏保持不变。覆盖原 PNG 并保留 UUID，不新增资源、节点或材质。SVG 是可编辑源稿，运行时不绘制矢量。

## 清晰直线与快速掠出（当前）

用户确认直线后仍认为差异不明显，因此同时修正形态与运动：源稿边缘模糊从 0.7px 降至 0.18px；显示长度改为屏宽 18%，高度改为长度 1/8，形成清晰细线。峰值透明度 245，快速淡入、中段保持、尾段淡出；满强度周期约 0.21s，随后有空档。轨迹由半屏宽 58% 处向外加速到 128%，六条仍错开相位与长短。保留上升出现、到顶淡出和落水关闭；不新增节点、材质或贴图。类型、3 项回归及纹理审计通过。

## 发散方向修正

按用户反馈，取消近似水平掠过的路径和独立装饰角度。每条直线从相机投影消失点指向屏幕侧边锚点，位置沿同一射线向外递增，长轴角度由同一方向向量求出。接入原有消失点 X/Y，极端位置限制在屏幕中央区域；线条只在射线外段出现，保持中央留白。新增回归验证位移远离消失点且直线长轴与射线一致；类型和 4 项回归通过。

后续起跳水花已独立接入加强版，见 [海豚跳起跳点特效](海豚跳起跳点特效.zh.md)；此前“起落水花尚未替换”仅描述速度线初次接入时的状态，落水仍保持原逻辑。
