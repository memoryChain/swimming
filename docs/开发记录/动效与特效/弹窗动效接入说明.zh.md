# 弹窗动效接入

2026-09-12，按已确认预览接入音量设置（SettingsPanel）和头像选择（IdentityEditPanel）。美术、文字、保存数据与身份映射沿用原实现。

- 展开 260ms：面板从原位下方 16 个设计单位、92% 缩放进入，190ms 到 101.5%，再用 70ms 回到原尺寸；面板及原有深色遮罩用 140ms 淡入。
- 关闭 160ms：面板下移 8 个单位、收至 96%，与遮罩一起淡出。遮罩保留原来的最终深度，不新增模糊、粒子或全屏绘制效果。
- 取消/确认按钮按下 70ms 缩至 96%，松开或触摸取消 120ms 恢复。头像切换仅让新头像与选中框轻弹一次；重复选中无操作。
- 面板打开时重复 show 不重置草稿或重播动画；关闭途中再打开从当前变换接续。层级、组件和监听一次构建。所有动作完成后无常驻更新。

## 功能与输入

### 快速比赛复用（2026-09-22）

`QuickRacePopup`复用相同的`PopupUiMotion`及260ms展开、160ms关闭参数。安全区缩放保留在`QuickDesign`，内部`QuickMotion`负责位移与缩放，遮罩和退场输入阻挡保持全屏；尺寸变化只更新外层布局和输入覆盖范围。

`CareerEventPage`仅在进入快速比赛时调用show，距离、规则、积分或存档状态刷新不重播。点击关闭或空白遮罩后，保持弹窗导航与输入阻挡直到动画完成，再返回大厅；关闭期间拒绝改选、换角色及开赛。开赛仍先等待原存档结果，失败保留弹窗供重试。

换页、选角暂存或销毁通过hideImmediately取消动画和旧返回回调；重新进入使用原节点。自动回归覆盖动效入口、选项不重播、遮罩退场时序、窄屏缩放、20轮暂存恢复与迟到回调，同时回归头像和设置弹窗。真机视觉仍待确认。

共用控制器为 `assets/scripts/ui/PopupUiMotion.ts`，分别持有面板变换、透明度、按钮反馈和关闭期间的输入遮挡节点。底层输入直到退场结束才释放；全屏遮罩和关闭遮挡采用现有全屏适配工具，不跟着面板一起缩小。

控件业务触发统一使用 Button 的 CLICK，防止按下后移出/取消触摸仍执行保存。音量取消、直接隐藏或显示期间销毁均恢复预览前音量；保存仍一次写入现有设置。关闭阶段的滑块回调不再改变声音或草稿。

头像保存沿用现有 PlayerData.setIdentity；保存完成前不关闭，不允许重置草稿、选择其他头像或重复保存。失败保留弹窗并允许重试。异步回调校验原根节点身份，旧请求完成不会关闭重建后的弹窗。角色与联机身份仍使用原 avatarId，未改同步协议或比赛状态。

销毁时停止全部自有 Tween 并解绑反馈监听；不添加 update、逐帧 Label 更新、Graphics 重绘或资源复制。既有大厅动效保持独立。
