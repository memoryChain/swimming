# 巨浪与喷泉改为 Blender 资源

按用户确认，本次只把原有效果转换成 Blender 模型资源，保持原来的形状、颜色、透明度和运动节奏，不增加新的浪头或泡沫装饰。用户已在 `de2c8c1` 提交并推送。六份资源的 Creator 实际导入检查已通过。

## 改了什么

- 巨浪的浪面、尾流、拍岸，以及喷泉的水面泡沫、水束、水滴，共六份 GLB。
- 可编辑源文件放在 `modelresource/entertainment/GiantWave.blend` 和 `Geyser.blend`。每个部件独立一个场景，保持单网格和顶点色，方便直接编辑。
- 删除两处表现代码中的造型、顶点数组和网格裁切函数。赛前加载 GLB，开赛后只控制显隐、移动、缩放、朝向和原有透明度。
- 模型缺失或导入结构错误时不放行比赛；加载期间退出后，迟到回调不能重新创建效果。
- 重赛复用已经加载的网格。销毁仅清掉本局节点、材质和相机层绑定，不销毁 Bundle 持有的共享模型。

原来的加速、减速、喷泉命中、弹起、AI 绕行和联机门禁没有修改。仍只在本地 AI 娱乐调试中使用；主干的性能策略、公共数值、云端、存档和网络格式保持原样。

## 编辑与导出

日常编辑以上 `.blend` 源文件后，用统一后台入口导出；不重新执行 `create` 覆盖人工编辑稿：

```sh
python3 scripts/run-blender.py -- --python scripts/build-entertainment-vfx.py -- export --effect giant-wave
python3 scripts/run-blender.py -- --python scripts/build-entertainment-vfx.py -- export --effect geyser
python3 scripts/check-entertainment-vfx.py
python3 scripts/check-entertainment-vfx.py --imported
```

Windows 将 `python3` 改为 `python`。首次转换基准保存在两个 `*-reference.json`，不属于运行时资源。当前检查以“保持原有效果”为验收目标；以后经确认修改造型时，需要同步更新核准基准。

重新导出后等待现有 Creator 会话导入，保留生成的 `.meta`，再运行项目的纹理修复和检查。源 `.blend`、转换基准和工具脚本不进入游戏资源目录。
