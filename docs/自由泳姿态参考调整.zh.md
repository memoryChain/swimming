# 俯泳自由泳姿态（2026-09-11）

## 2026-09-12 松手回臂节奏修正

两种泳姿共用 `SwimmerMotor` 的动作计时与松手倍率；仰泳只反转视觉相位方向。此前俯泳的直臂保持从 0.90 相位开始，真实肩腕轨迹约在 0.86 就已接近终点，因此同倍率下显得回臂更急。现将回臂关键姿势延至 0.66、0.80、0.91、0.99，前伸混合改为 0.90–0.99；胸肩侧转峰值移到 0.72，换气回正同步延后。前伸结束仍保持绑定直臂外形。

深潜先锋与肌肉男的等相位采样中，回臂接近终点的时刻由约 86% 延后至 94%–95%，肩腕相对运动峰值下降约 23%–24%。这里只调整视觉曲线的时间分布，整圈周期、左右输入、松手判定、游速、仰泳路径及保存的 tuning 配置保持原值；联机直接消费原有相位，不新增计时器、同步字段或逐帧分配。上述百分比是两种角色离线骨架轨迹的测量，不代表真机观感已验证。下文早期阶段参数保留为调整记录。

回归覆盖全部 11 个角色的回臂时长与峰值、前伸蒙皮、肘部形变、胸肩协同、仰泳与翻身连续性。Blender MCP 当前连接不可用；本次通过实际 GLB 与 Cocos 数学库检查运行时轨迹，未启动 Creator 或修改模型资源。

根据用户提供的俯视、侧视两段 GIF 调整俯泳；两段参考各为 24 帧、2.4 秒。参考用于手工判断关键姿势，不是可直接重定向的三维骨骼数据。游戏仍由玩家的左右独立输入决定划臂时序，不强制交替，也不锁定为参考的播放速度。

## 动作与代码

- `assets/scripts/character/ProneFreestyleMotion.ts`：上臂／前臂方向关键姿势和周期 Hermite 插值。方向按角色实际骨长求解；不存固定肘腕位置，不增加动作资源包。
- `assets/scripts/character/FreestylePoseController.ts`：只在俯泳姿态中使用新方向；前伸时肩带先上举，大臂再对齐；掌心按动作阶段由整臂或前臂转向，手腕不强制折弯。旧 `applyArm()` 保留供仰泳使用。
- 正向单臂相位依次为：0 前伸入水，0.12 抱水，0.26 屈肘拉水，0.40 向髋部推水，0.52 出水，0.62–0.74 高肘回臂，0.84–1 前伸。抱水肘弯约 84°，回臂两个关键姿势约 101°／85°；这里只描述肩→肘与肘→腕的方向夹角，伸直为 0°，不是临床关节角度。
- 俯泳视觉侧转峰值对齐高肘回臂（单臂相位约 0.65）；根部侧滚幅度为原内置侧滚加 12°。胸背和上胸按 60%／40% 分配额外 32°侧转，前伸肩带随胸廓转动。头颈在不换气时抵消胸廓侧转的 85%，右侧换气时逐渐降至 25%。腿部求解保持现有实现。
- 俯面半周完整应用新姿态；身体朝上投影从 0 到 -0.5 时平滑混合；投影 ≤ -0.5 时完整应用原仰泳姿态。现有 `CartoonSwimmerRig.updateVisualArmCycles()` 的转向、迟滞和周期边界规则保持不变。

## 玩法、联机和性能

全部变化是已有相位与身体朝上投影的直接表现，不新增随机数、积分计时器或同步字段。保持原推进、划水质量、左右输入、速度、碰撞与比赛结果逻辑。原有骨骼降频和离屏裁剪继续生效；向量、四元数缓冲复用。正常俯泳只求解新动作，正常仰泳只求解旧动作，翻身混合区才同时求两套手臂姿势。

本次没有修改角色 GLB、贴图、共享采样动作、已保存的调参文件或泳池资源。

当前新增 `motion.proneChestRollDegrees`，默认 32°、范围 0–45°，对应调参面板的「俯泳胸肩侧转」。沿用现有参数保存／加载；旧 JSON 没有该字段时使用默认值。新增调参文案后通过仓库脚本重建字体子集，并保留字体 `.meta`。

### 2026-09-12 肘部折叠修正

用户确认整体方向，但指出肘部明显折叠。放大两段 GIF 的回臂帧对比后，发现首版在 0.62–0.74 相位把前臂横向指向身体内侧，导致手腕缩到肩／脸旁。改为回臂中段先让前臂留在肘外侧，随抬肘向前带，再逐渐伸展；只修改三个前臂方向关键姿势，保留上臂路径、胸肩和换气。

回归不再仅断言“弯肘超过 100°”：增加全周期肘内角至少 65°、肩腕距离大于整臂长的 52%、回臂中段腕位在肘外侧的独立骨架检查，覆盖全部 11 个角色及关键帧间插值。角度数值是本项目此次美术调整的验收范围，不代表从二维 GIF 精确量得的三维动作。新一轮 47 项检查及 TypeScript 检查通过；重新渲染俯视／侧视确认。

### 2026-09-12 前伸直臂修正

前伸阶段另于 2026-09-12 修正：加入跨周期 0.90–1–0.08 的直臂保持段，前后平滑过渡。不能用“骨点夹角小于 12°”替代网格验收：规范骨架的肘腕枢轴存在偏置，分别对齐骨点、分别翻掌，即使三点共线，仍可能折弯可见网格。前伸改为保留 T 姿势的肘腕局部关系，将整臂朝向游进方向，再整臂共同翻掌；离开保持段才渐变回屈肘求解。仰泳继续使用旧路径。

测试直接比较实际 GLB 的上臂、前臂、手部 `worldMatrix * inverseBindMatrix`：整个保持段三者必须是同一个刚性蒙皮变换，同时肩到腕沿前进方向。由此确保保留原始直臂网格外形，不再用不准确的骨枢轴角度自证。重新检查两个不同身材角色的前伸俯视／侧视渲染。

### 2026-09-12 双臂前伸肩部修正

上一版只保持肘腕形状并将大臂向前旋转，却把肩带留在横向展开的位置，双臂同时前伸时出现宽 U 型和肩头拐角。前伸改为先按原自由泳的肩带前伸尺度上举肩骨，再求解大臂和肘腕；使用同一前伸权重平滑放回，骨骼局部位置、长度、父子关系和模型权重均不改变。

检查新增双臂同期完整周期、肩带前向分量、双手间距及肩关节枢轴不变；保留直臂蒙皮、交替动作和仰泳回归。离线渲染必须包含双臂同时前伸的俯视、侧视、正视和斜视，不能只看交替单臂预览。

### 2026-09-12 细长手臂的扭拉修正

以用户指出的深潜先锋（`CartonSwimmer13.glb`）为主检查。此前上臂方向、前臂方向和掌心分别求解，推水结束时前臂还会额外转动约 150°；骨长没有变化，但肘部混合权重网格被拧细、拉斜。肌肉男的粗手臂会掩盖一部分问题。

现在保留已求得的前臂世界朝向及肩肘方向，用当前角色自己的前臂绑定旋转反求上臂滚转，再以最短摆动恢复上臂方向。这样翻掌由上臂协同承担，肘部相对绑定姿势不再叠加长轴扭转。前伸保持段仍整体旋转手臂；局部位置、缩放、骨长、蒙皮权重和仰泳路径不变。仅增加复用向量／四元数计算，无每帧分配或网格遍历。

验证包括深潜先锋、霓绿少女、肌肉男的俯视／侧视离线渲染，以及全部 11 个模型的肘部旋转、骨长、掌心、前伸和连续性检查。新增真实三角形边蒙皮回归，纳入 `UpperarmTwist`／`ForearmTwist` 辅助骨权重；48 帧肘部边长倍率的 95 分位，深潜先锋从 1.676 降到 1.434，霓绿少女从 1.707 降到 1.475，肌肉男从 1.604 降到 1.341。这是弯曲区域的统计指标，不能替代实际外形检查。三组回归共 50 项和 TypeScript 检查通过；未进行 Cocos 或真机渲染验收。

### 2026-09-12 胸肩转体与回臂协同

再次对照两段参考：回臂中段胸廓仍明显侧转，回臂侧肩膀随之抬高。此前侧滚沿用前伸余弦信号，峰值落在出水阶段，到了高肘回臂胸肩已经接近放平；额外胸肩角度也只有 8°。本次把俯泳转体峰值移到 0.65 相位，并将胸肩相对根部的侧转加到默认 32°，分布到 `Spine01`／`Spine02`。按当前保存的换气参数，胸肩回臂峰值约 51°／55°；此角度是本项目的美术调整结果，不是从二维 GIF 精确恢复的三维角度。

前伸锁骨的目标方向随胸肩侧转，不再反向锁回根节点水平面；不换气时头颈作反向补偿，换气时平滑释放。胸段每帧从绑定姿势求解，翻身或切回仰泳不残留转角；同期双臂的侧转信号抵消，仍由玩家独立选择左右划臂。

最终检查包括全部 11 角色的胸肩／髋部角度差、头部补偿、前伸、肘部蒙皮、仰泳和周期连续，共 51 项动作测试；另验证新参数从保存值覆盖默认值，TypeScript 与字体审计通过。11 角色双向游进的原仰泳快照摘要完全一致。离线检查深潜先锋和肌肉男的完整俯视／侧视周期，并补充深潜先锋五个阶段的正视及斜视。未启动 Cocos，也未做真机验收。
