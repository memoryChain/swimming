## 1. 目标与范围

面向中国微信小游戏、抖音小游戏，以 8+ 为设计目标，将娱乐模式调整为轻松的水上机关竞速。保留七事件轮换、争抢、传递、追逐、绕行、失速与搞笑翻滚，重点弱化现实武器伤人、动物咬伤、人体残缺和溺水抢救的完整视听表达。

本计划覆盖共用恢复、七个事件、赛事广播、个人反馈、画中画、模型图标、音效检查、联机恢复和提交素材。角色、场馆与经济系统只检查是否存在直接相关的问题，不借此次整改整体重做。

工作分类：

- **主要修改**：共用恢复演出与文案、定时炸弹和鲨鱼的完整表现、炮火和水雷的道具表现。
- **局部调整**：苏打／冰沙的设定与说明、漩涡与垃圾的广播、共用镜头与图标。
- **联动验证**：AI、物理判定、导演、协议、存档与性能。没有因果依赖时不改规则。
- **发行检查**：适龄提示、平台功能、昵称与社交、提交图片视频。检查结果决定补项，不把未查明的问题写成已存在的缺陷。

完成目标是得到内容一致、可评审、可提审的版本；不能将完成计划等同于取得平台通过或法定资质。

## 2. 已确认方向与待收敛选择

2026-09-22 已确认：

- **共用恢复：浮圈托住。** 短暂翻滚后由浮圈托在水面，晕头转向地扶稳，再继续游；保留原有暂停时长。
- **恢复细化：双臂搭圈，状态清楚、正文搞笑。** 胸前靠圈、双臂搭圈、双腿轻摆、头小幅晃动，保留三颗眩晕星。原运动转播卡的小标题固定“调整中”，正文轮换简短幽默句。

- **水雷：喷水浮标。** 圆钝浮标触碰后喷起水柱并退场，与可传递的水球保持清楚区分。
- **D／E 造型细化（2026-09-22）：** 用户选择调皮运动款充气鲨（蓝青色、鼓鼓身体、短圆鳍、得意表情）、运动场水炮（蓝白主体、橙色细节、圆钝短炮口、厚实塑料底座）、圆盘喷泉浮标（低矮宽圆盘、软包边、短喷口）。完整制作与接入任务见第 18 节；颜色比例、尺寸、动作幅度等未逐项确认的细节为首轮制作基线。

## 4. 共用恢复：先消除持续下沉与严重伤害联想

### 4.1 当前实现

`EntertainmentRecoveryController` 提供 ACTIVE、KNOCKED、INVULNERABLE 三阶段，默认暂停 3.5 秒、保护 2 秒；恢复时速度清零。可见性函数控制旧位置闪退与新位置闪入。B1 实施前另有约 102° 侧翻、模型下沉和四肢浮力姿态；本阶段已替换为双臂搭圈，保留短落水路径，详见第 4.9 节。

### 4.3 关键动作边界

- 水面受击：短促翻滚／偏移后进入托浮，头部回到水面上。
- 空中受击：沿既有落水链衔接，暂停计时仍从真实事件开始，不因落地重新计时。
- 水下受击：新视觉在可解释的短过渡内回到水面，不修改权威赛程与碰撞位置。
- 临近恢复才收到快照：直接还原当前托浮或保护阶段，不从头补播翻滚。
- 换位：原位置闪退、隐藏期间换位、新位置闪入继续掩盖复位，托浮物跟随同一显隐边界。
- 普通碰撞、疲劳、海豚跳的布娃娃效果保留；只替换娱乐暂停专用的失能下沉层。

### 4.4 B1 人物与浮圈制作规格

**用户已确认的视觉目标**：人物胸前靠住浮圈，双臂搭在圈上，头保持在水面上；腿轻摆、头小幅晃动，表现被撞懵后正在扶稳。保留三颗眩晕星和原有短轨道拖尾，不增加面部骨骼作为前置条件。

首轮制作基线由助手拟定，制作时可在目标范围内根据实际角色尺寸调整：

- 浮圈采用圆钝、略厚的充气圈轮廓，建议亮橙主体加少量浅色分段，复用现有运动卡的救生用品配色。无需脸、文字、绳索、复杂扣具或透明材质。
- 胸前搭在靠近人物的一侧圈沿，前臂自然沿两侧铺开。头颈略抬，肘膝小角度弯曲，腿向后下方放松；不能变成脸埋圈、双臂僵直展开或反向折叠。
- 圈随人物所在位置托浮，以身体尺寸配置圈径与托举高度，至少覆盖最宽／最窄躯干。可以复用一份网格做实例缩放，不为每个角色复制完整资源。
- 保持轻微上下浮动与小幅侧摆，人物、前臂与圈必须同步，不能手留在原处而圈独立穿过手腕。头部晃动幅度低于肩部大动作，避免抽搐。
- 使用共享低面数网格、共享材质和每泳道复用实例；既有资产无法满足时制作一个专用浮圈。建议新资产路径为 `assets/race/items/RecoveryFloatRing.glb`（尚不存在），统一在 `ResourcePaths.ts` 登记；源文件放 `art/`，不得塞进运行时目录。
- 托浮物只承担视觉，不给圈加游戏碰撞体，不改变原泳者身体范围、速度或赛程。

### 4.5 B1 时间轴与显隐规则

以下秒数以当前默认 3.5 秒暂停、2 秒保护为例，作为可实施的首轮分镜。实际代码读取配置与权威剩余时间，不在表现层再硬编码一套计时。暂停与保护时长不因动画未播完而延长。

| 阶段 | 画面 | 状态与边界 |
| --- | --- | --- |
| 命中至落回水面，通常前约 0.3～0.62 秒 | 保留短促惯性翻滚／落水；浮圈在接近水面时从下方出现 | 不额外叠加第二次击飞；水下命中接入回到水面的短过渡 |
| 落水末段至约 0.9 秒内 | 浮圈小幅上浮，人物转为双臂搭圈；约 0.2～0.3 秒平滑落稳 | 与落水阶段重叠衔接，不能落地后重新计满 3.5 秒；头随后持续露出水面 |
| 稳定托浮至暂停末段 | 圈和身体轻晃，腿轻摆，头顶星星转动；恢复卡正文保持本次抽中的一句 | 只晃姿态，不前进；不每帧抽文案，不新增救援人员 |
| 暂停最后 0.55 秒，默认 2.95～3.5 秒 | 人物、圈和附属眩晕表现跟随同一闪退节奏，头继续保持水面以上 | 保留原三次闪退；不能只有人物消失而空圈仍悬着 |
| 暂停结束，默认 3.5 秒 | 在隐藏的交界复位位置与游姿，并停用浮圈；解除暂停输入拦截 | 沿用原权威位置、速度清零与保护状态；清掉扶圈骨骼叠加 |
| 保护前 0.65 秒 | 人物按原规则三次闪入，已可正常划水；圈不在新位置重新出现 | 闪入和 UI 退场不延迟控制，不把保护延长为动画等待 |
| 保护余下时间至默认 5.5 秒 | 正常游泳，保留保护轮廓光与独立状态条 | 保护期到时结束，圈／星星／恢复卡均无残留 |

晚到快照、低帧率跳过阶段或资源晚加载时，直接根据当前权威阶段选择稳定托浮、闪退或保护表现；不补播已过期的圈入场。若暂停剩余时间不足以完整播入场，就缩短或跳过入场，优先保证当前位置与阶段正确。
