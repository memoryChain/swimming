## 2. 通用造型语言

- 风格是年轻、时尚、有潮流玩具感的 3D 角色，不是儿童玩偶，也不是写实人体。
- 身体约五头身，可在约 5.0～5.3 头身范围内微调，但同一角色四视图不得发生比例漂移。
- 头部连同头发和贴头配饰的主体宽度不得超过肩宽。高耸帽饰可突破高度，但不能继续横向放大头部。
- 腿要长，胯部至地面约占可见人物总高的一半。不能通过缩短小腿或放大头部制造低幼感。
- 四肢采用圆润、饱满、连续的软胶圆柱体语言。关节转折柔和，不表现骨点、筋腱或写实皮下肌肉。
- 手脚可适度放大以保持潮玩识别度，但不得挤压四肢长度。五指结构完整，避免手掌畸形。
- 鼻子只做轻微面部隆起，嘴部尽量弱化。所有角色均以不透明眼镜、墨镜或面罩遮住眼睛，不出现裸露眼睛。
- 材质以不透明软胶、塑料、布料为主。禁止依赖透明、半透明、镂空网纱、玻璃雨衣或透明鞋底作为核心设计。

## 3. 标准男生体型

母版优先级：蛙蛙少年正视图 > 蛙蛙少年侧背视图。

- 肩部略宽于胯部，躯干偏直，不做夸张倒三角。
- 手臂和腿的厚度必须稳定，不能因换服装或换主题突然变细。
- 上臂、小臂、大腿、小腿均为圆润饱满体块，允许轻微自然收分，但不出现肌肉峰、明显小腿肌或骨感手腕。
- 视觉年龄是少年或年轻男生，不通过大头、短腿、窄肩表达可爱。
- 服装可宽松，但宽松衣服不能被误读为身体变小；裸露四肢仍应保持母版厚度。

## 4. 标准女生体型

母版优先级：蛙蛙少女与短发少女共同约束。蛙蛙少女负责着装体量，短发少女负责基础人体比例。

- 肩部与头部比例稳定，头部主体不超过肩宽。
- 腰部可以自然收窄，形成轻度曲线，但不强调写实胸腰臀解剖。
- 手臂圆润、顺直，粗细变化平缓；不得出现三角肌、肱二头肌或小臂肌肉隆起。
- 腿部修长且略粗，膝盖弱化，小腿进入鞋口处要自然收束，不能形成肉感鼓包。
- 鞋体允许略大，但不能因此缩短腿部视觉长度。
- 发型可变化，但中短发优先；发髻、马尾等必须在左右和背面保持固定生长点。

## 5. 特殊体型：肌肉大汉

- 只在明确指定特殊壮汉、健身或力量型角色时使用。
- 核心轮廓是小头、极宽肩、明显倒三角躯干、粗壮四肢。
- 允许表现夸张肩峰、胸背、上臂和小腿肌肉体块，但仍维持玩具化圆润表面，不走写实健美皮肤细节。
- 不继承到标准男生：标准男生禁止照搬其超宽肩、肌肉分块、粗颈和缩短躯干。
- 特殊体型也必须遵守眼睛遮挡、配件连接完整、四视图方向一致和低模预算规则。

## 6. 服装与配件设计

设计允许有趣、有层次，不再限制为单一大块面；但细节必须形成清晰层级：

1. 一级识别：帽型、发型、外套轮廓、裙裤轮廓、鞋型等远距离剪影。
2. 二级结构：一条主背带、一个主包、大片拼色、宽包边或护具。
3. 三级点缀：少量主题挂件、扣具或大图标。

低模简化原则：

- 简化的是重复、细碎和低分辨率无法识别的内容，不是删除个性。
- 同一局部避免堆叠多条细带、密集小扣、微型拉链头和大量小徽章。
- 服装接缝用少量宽线组织结构，不用密集缝线纹理。
- 图形以大色块和大图标为主，不使用小字、细小文字或高频花纹。
- 网眼、蕾丝、密孔和透明叠层必须改成实体布或通过一个大色块概括。

### 背带与配件连接硬规则

- 背带必须形成完整受力路径：肩部起点 → 躯干路径 → 调节扣或固定扣 → 包体接口。
- 被手臂或身体遮挡时只能发生合理遮蔽，遮挡前后两段的位置、宽度和方向必须能连续推导。
- 不允许包体悬浮、背带凭空中断、带子穿入身体或接口错位。
- 正、左、右、背四个视图必须保持同一条背带的斜跨方向和同一包体所在侧。
- 腰带、鞋带、护腕、挂件连接件同样需要检查闭环与固定点。

## 7. 鞋子规范

- 每只鞋控制为约 3～4 个主要结构块：鞋底、鞋身、鞋头或侧片、鞋带或魔术贴。
- 鞋带只保留少量粗带；可优先采用一至两条宽魔术贴。
- 禁止透明气垫、透明鞋底、密集孔洞和大量细碎鞋片。
- 左右鞋必须使用同一结构和配色逻辑，侧视与背视必须能解释鞋头、鞋跟和侧片的连接。
- 鞋可以略大以强化潮玩感，但不得大到破坏五头身和长腿比例。

## 8. 荧光绿换色区

- 荧光绿是程序识别后的换色区域，设计时使用纯亮、边界明确、材质一致的荧光绿色。
- 换色区应形成连续大面，优先放在帽饰、外套主拼片、宽背带、腰带、短裤侧片、腕带、袜子或鞋侧片。
- 避免把换色区拆成大量细线和小点；512 贴图下必须一眼可辨。
- 同一物件的荧光绿区域需要在四视图中连续闭合，不可在某一视图突然消失。
- 头发、肤色和固定身份色默认不参与换色，除非单独指定。

## 9. 四视图规范

- 每个视角单独一张图，不合并在同一画布。
- 默认画布为 1536×1024，灰白中性棚拍背景，角色全身完整居中并留安全边距。
- 正视图：严格正面、双臂水平侧平举、手掌朝下。
- 左视图：严格 90° 正交侧面，鼻尖朝画面左侧。
- 右视图：严格 90° 正交侧面，鼻尖朝画面右侧；不得重复输出左视图。
- 背视图：严格 180° 背面，不出现脸、鼻子或正面眼镜图案。
- 侧视 T-pose 中双臂会投影重叠，但两条手臂必须都存在、长度一致，不能被误画成缺臂或短臂。
- 发型生长点、帽檐方向、包体所在侧、单侧裙片、口袋、腕表和挂件必须按三维旋转关系转换，不能简单做二维镜像。
- 同一角色四视图的头顶、下巴、肩线、胯线、膝线和鞋底线应尽量对齐。

## 10. 生产预算

目标角色模型约 5000 面，贴图约 512×512。概念阶段按以下原则控制：

- 优先把面数留给头部轮廓、手部、鞋体外轮廓和影响剪影的服装结构。
- 小徽章、小扣件、细缝线和重复纹理优先合并进贴图或删除。
- 不能依赖透明排序、复杂多层材质或大量独立小零件实现效果。
- 材质数量保持克制；大多数服装通过少量材质加大色块区分。
- 512 贴图中，核心符号必须足够大；细线和微小文字不作为身份识别信息。
- 最终建模前应确认“5000 面”的项目统计口径是三角面还是四边面，再分配具体部件预算。

## 11. 生成与交付前检查清单

- [ ] 标准角色使用正确的男体或女体母版；肌肉大汉没有被误用为标准男体。
- [ ] 头部主体没有超过肩宽，整体约五头身，腿部保持修长。
- [ ] 标准男女四肢圆润饱满，没有肌肉、骨点或忽粗忽细。
- [ ] 眼睛完全被不透明眼镜或面罩遮挡。
- [ ] 没有透明、半透明、网眼或低模无法实现的核心结构。
- [ ] 荧光绿换色区是连续大面，四视图能够闭合对应。
- [ ] 鞋子结构已压缩为少量大分件，左右鞋一致。
- [ ] 背带、腰带、鞋带与挂件连接完整，没有断带、悬浮或穿模。
- [ ] 左视图鼻尖朝左，右视图鼻尖朝右，背视图不露正脸。
- [ ] 发型、帽檐、包、口袋、侧裙和腕表的方位在四视图中正确。
- [ ] 双臂完整伸直，双手和双脚均未裁切，五指结构正常。
- [ ] 细节在约 5000 面、512 贴图条件下仍具有可实现性和可读性。

## 12. 后续角色的默认继承顺序

1. 先选择标准男体、标准女体或明确指定的特殊体型。
2. 锁定头身比、头肩关系、四肢粗细和腿长，不随主题变化。
3. 设计一级剪影和主题识别点。
4. 添加二级结构与少量三级点缀，同时检查低模可实现性。
5. 布置连续的荧光绿换色区。
6. 先确认正视图，再生成左、右、背视图。
7. 用本规范第 11 节逐项验收后交付。

### 默认流程口令

- 当正视图已经确认后，用户说“OK，进入下一步”，默认含义是：以当前确认图为唯一母版，继续制作左视图、右视图、背视图。
- 三个视角必须分别输出为三张独立图片，不再等待用户重复说明视图要求。
- 生成顺序默认是左视图 → 右视图 → 背视图，并执行鼻尖方向、配件方位、背带闭环、遮挡关系和四肢完整性检查。
