# Boss调试体验说明

2026-10-02。八个Boss已接入现有AI调试入口，用于先试玩战术。生涯联赛、杯赛、普通快速赛和好友房均未启用这些关卡，调试赛不发金币、不推进积分或杯赛，也不创建奖励票据。

## 进入与操作

1. 点击“开游”进入大厅，选择出场角色，再点左下角现有“AI 测试”入口。
2. 点击“测试类型：普通 AI”，切换为“Boss 关卡”。
3. 点击“上一关／下一关”或关卡名，查看玩法提示、人数、模式、距离、AI等级和体验目标。
4. 点击“开始 Boss 体验”。AI使用本关固定阵容，玩家沿用当前出场角色的实际养成等级。

普通AI调试仍可统一设置角色、等级、模式和智力。Boss逐席位设置强度，普通调试选项不会覆盖Boss。种子按钮共用；“再来一次”保留阵容并重置战术、资源和输入，用同种子便于比较自己的操作。切换关卡需返回大厅的AI调试入口。

赛前信息显示关卡名与体验目标。比赛中可用原有“查看AI／下一个”切换跟随镜头，展开“AI 信息”查看该AI当前战术和真实动作，例如“靠近预备／协作争位／拉开换班／潜航让线”。面板默认收起，收起或隐藏时不采样诊断。切镜头只是观察，玩家仍自行控制自己的角色。

Boss试玩沿用原有规则：首人触壁后开始10秒倒计时，全员完赛时立即结算。界面的“前几名／冠军”是试玩目标，当前结算仍展示真实名次，不记录单独Boss通关状态。建议先玩七兄弟会，再按自己的养成选择其他关卡；高阶关的专家阵容需要较高养成与熟练操作。

## 团队行为的边界

`BossAiConfig.ts`管理固定席位、独立策略ID和参数；`BossAiDirector.ts`每秒最多四次协调当前赛况。`AISwimmerController`按自身智力反应执行普通起划、左右转向、短按踢腿和合法海豚跳。每关的节奏参数都是独立副本，普通AI的全局策略不被修改。

争位队员必须正在比赛、同向、实际靠近玩家且有余力；领队不负责围堵。常规单侧关预备0.8秒、施压最多2秒、间隔6秒；高级双侧关预备0.6秒、施压最多3秒、间隔4秒。换班拉开意图持续2秒。玩家靠池边、折返、跳跃、下潜或需要碰撞恢复时停止当前围堵。专家也不能无视真实体力、心率、转向和碰撞；友军没有碰撞免疫，低智力会迟到、错过协作。

潜航由真实踢腿触发，上浮由真实划水恢复，蛙少小跳仍需蓄气与空间资格。飞毛腿的优势来自原有蹬墙能力，机甲的持续巡航来自原有无限体力；战术层没有写位置、速度、体力或判定。拉开差距能真实脱离协作范围。

## 验证记录

- TypeScript 5.4.5检查、AI／入口／生涯／云端／教学／开场等261项回归通过。Boss与切换入口的17项检查通过，额外覆盖Boss恢复10秒收尾且不影响生涯票据窗口。
- 12角色×8关×30／60Hz×3种子（42、2468、20261002），共576场代表养成与操作基线回放，按恢复后的10秒规则重新检查，542场焦点完赛，34场因收尾倒计时结束记未完成；数据见下表。状态未出现非有限数或负体力。最长连续低进展采样为6秒；这是每秒前进不足0.1米的诊断值，不是连续围堵时长。
- 高级肌肉队72场中70场出现近距施压，全部72场至少三名护卫先后收到施压指令；全明星72场中69场出现近距施压。初级肌肉队72场中23场出现近距施压，68场焦点达到前四参考目标，4场在10秒收尾时未完成；低档队员常会错过窗口。
- 另做12角色×8关×30／60Hz共192场解除收尾倒计时的回放，焦点和所有AI均能游完全程。正式试玩仍保留上述尾随窗口，玩家先完赛时较慢AI可能记未完成。
- 潜航关检测到实际下潜和蛙少小跳；潜水哥与机甲没有非法跳跃。固定种子复现成绩、资源与换班，失衡撤退、池边与墙前停止招募、远端真人排除和重赛重置已回归。
- 界面反复切换不增加节点或监听；面板适配1280×720、1600×720、960×540及竖向窗口，使用项目随包字体。1471字符字体子集已重建并审计。
