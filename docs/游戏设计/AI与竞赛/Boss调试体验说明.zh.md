# Boss调试体验说明

2026-10-02。八个Boss已接入现有AI调试入口，用于先试玩战术。本轮将原先局部争位改为全队统一指挥：集结、搭档、配速、让线与交接由同一协调器安排，队员按实际身体状态执行。生涯联赛、杯赛、普通快速赛和好友房均未启用这些关卡，调试赛不发金币、不推进积分或杯赛，也不创建奖励票据。

## 进入与操作

1. 点击“开游”进入大厅，选择出场角色，再点左下角现有“AI 测试”入口。
2. 点击“测试类型：普通 AI”，切换为“Boss 关卡”。
3. 点击“上一关／下一关”或关卡名，查看玩法提示、人数、模式、距离、AI等级和体验目标。
4. 点击“开始 Boss 体验”。AI使用本关固定阵容，玩家沿用当前出场角色的实际养成等级。

普通AI调试仍可统一设置角色、等级、模式和智力。Boss逐席位设置强度，普通调试选项不会覆盖Boss。种子按钮共用；“再来一次”保留阵容并重置战术、资源和输入，用同种子便于比较自己的操作。切换关卡需返回大厅的AI调试入口。

赛前信息显示关卡名与体验目标。比赛中可用原有“查看AI／下一个”切换跟随镜头，展开“AI 信息”查看该AI当前战术和真实动作，例如“协同集合就位／前卫拦截／侧翼协作封线／接班队员提前就位／先锋下潜开路”。面板默认收起，收起或隐藏时不采样诊断；展开后沿用5Hz采样与文字变化检查。切镜头只是观察，玩家仍自行控制自己的角色。

Boss试玩沿用原有规则：首人触壁后开始10秒倒计时，全员完赛时立即结算。界面的“前几名／冠军”是试玩目标，当前结算仍展示真实名次，不记录单独Boss通关状态。建议先玩铁臂兄弟团，再按自己的养成选择其他关卡；高阶关的专家阵容需要较高养成与熟练操作。

## 统一团队策略

`BossAiConfig.ts`管理固定席位、独立策略ID和参数；`BossAiDirector.ts`每秒最多四次协调全部对手，为每人指定职责、搭档、横向通道、必要的前后位置与配速目标。指令对象和缓冲区复用。`AISwimmerController`按自身智力反应执行普通起划、左右转向、短按踢腿和合法海豚跳；普通比赛不挂团队指令。

队伍采用“休整→集合→协作→撤退”状态机。领队继续冲线；前卫与侧翼通过真实游动就位，接班者提前接应，其余队员保留各自巡航通道并避让已预约路线。待命者不统一减速，也不全部挤向玩家同侧。队伍依据成员当前距离、方向、体力、状态和使用次数选人；真人、停赛、异向、折返或失衡成员不能被招募。

集合范围18米，队员需进入7米协作范围，并在横向目标1.2米、前后目标2.5米以内才视为到位。预备最短0.8秒／0.6秒只是读招时间，不能到点便假装队形已经完成；集合10秒仍未到位就撤退。每次配合锁定一条进攻路线，玩家横移超过3米就中止重组；有条件时双侧展开，同侧成员错开前后位置。接班者必须实际接替已进攻成员并开始下一次协作，才计一次交接。

初级单人主动争位最多2秒，休整窗口6秒；高级最多两人主动配合、最多3秒，休整窗口4秒。撤退让线2秒计入休整窗口。玩家靠池边、墙前、折返或需要碰撞恢复时退出进攻；跳跃和下潜时保持接应、重新评估到位，不能攻击空中／水下玩家。队员失衡、退出或变成真人都会取消整组配合。友军仍会碰撞，专家也不能无视体力、心率和恢复；启蒙、新手会迟到或错过窗口。

潜航队按两名队友的真实进度和速度集合，潜水哥实际下潜后才允许蛙少穿越与合法小跳；潜航期间不因玩家横移就取消队友间的接应。全明星的潜水哥选择实际靠近的领队、追逐王牌或拦截者开路。折返关在距墙35米内开始集合，22米内或池段开头窗口才主动施压，最多两人；飞毛腿侧翼为主将出墙让线。最后50米没有下一折返墙时使用真正终点距离，避免团队错误地一直认为已靠墙。

配速目标只改变何时划水／踢腿，不打断正在进行的一划，不能绕过心率、预算或失衡恢复。转向维持真实斜游并考虑当前转向速度，使远处队员有能力游到集合通道。潜航由真实踢腿触发，上浮由真实划水恢复，蛙少小跳仍需蓄气与空间资格。飞毛腿蹬墙、机甲无限体力都沿用原角色能力；指挥层不写位置、速度、体力或判定，也没有隐藏追赶补偿。

## 验证记录

- 团队策略调整时，TypeScript 5.4.5检查与111项AI／调试界面／开场／好友房／碰撞恢复回归通过。其中17项Boss测试覆盖真实集合、集合失败、全队职责、候补通道、真实交接、真实潜航放行、折返提前集合、最后池段、同种子重现及普通比赛隔离。10秒收尾且不影响生涯票据窗口的回归保留。
- 12角色×8关×30／60Hz×3种子（42、2468、20261002），共576场代表养成与操作基线回放，沿用正式10秒收尾，536场焦点完赛、40场未完成；数据见下表。状态未出现非有限数或负体力。最长连续低进展采样为5秒，这是每秒前进不足0.1米的诊断值，不是连续围堵时长。
- 六个七人团队预设的全部场次，七个席位均实际收到团队职责。高级肌肉队62／72场出现至少一名队员近距施压，35／72场出现两名队员同时近距施压，合计43.5秒；全明星5／72场出现双人近距施压。潜航关47／72场、全明星37／72场出现真实潜航接应。机甲、肌肉、折返及全明星均观察到实际交接；折返关双人同时近距仍较少（1／72场），真人试玩还需关注这组动作的可读性。
- 另做12角色×8关×30／60Hz共192场解除收尾倒计时的回放，焦点和所有AI均能游完全程。正式试玩仍保留上述尾随窗口，玩家先完赛时较慢AI可能记未完成。
- 潜航关检测到实际下潜和蛙少小跳；潜水哥与机甲没有非法跳跃。固定种子复现成绩、资源与换班，失衡撤退、池边与墙前停止进攻、远端真人排除和重赛重置已回归。
- 原调试界面层级和动效未改；反复切换不增加节点或监听、隐藏不工作等回归通过，面板适配1280×720、1600×720、960×540及竖向窗口。命名更新后，1501字符字体子集按生成器重建并审计，原UUID保留。
