# 道具配置草案（未接入游戏逻辑）

当前所有角色免费使用，可直接消耗金币升级，无签约、视频或道具门槛。道具仅保留配置供设计调整，不开放道具页，不创建库存，不发放或消费道具，不增加额外配色。

## 保留的配置

- `assets/scripts/progression/ItemConfig.ts`：专属签约卡 `sign_角色ID`、万能签约卡 `sign_universal`、染色剂 `dye`，包括名称、描述、类型、堆叠上限。描述是未来设计，不代表当前生效。
- `assets/scripts/progression/DyeConfig.ts`：永久解锁额外配色的设计草案，包含配色与消耗；未加入可选配色列表，原免费颜色正常使用。
- `assets/scripts/progression/CupRewardConfig.ts`：`championCoins` 与 `firstClearCoins` 用于额外冠军金币及账号首次通关金币；`firstChampion`、`drops` 是未启用的道具奖励草案。可配置指定物品、数量、权重，但现在不会抽取或发放。

## 当前杯赛奖励

2026-10-02起，新开杯赛每轮完赛均按常规公式发金币；额外冠军金币为300／600／1000／1800／3000／4800，每级账号首次达标额外600／1200／2200／4000／6500／10000金币。八人新秀决赛前五、俱乐部前四达标可领首通金币，冠军奖励仍只给第一名。金币首通使用`firstClearPrizes`，不会写入未来道具首奖字段`firstPrizes`。不发道具，好友对战不发奖励。旧在途票据沿用旧金币规则。完整数值与发布状态见[生涯难度与奖励调整](生涯难度与奖励调整.zh.md)。

角色旧存档的签约标记只为兼容保留，不限制任何角色升级；旧签约或染色命令会返回未开放，不扣金币、不消耗道具。此前测试版票据即使带道具奖励配置，也不会发放道具。
