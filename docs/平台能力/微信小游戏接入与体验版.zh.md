2026-09-20：用户确认小游戏 AppID 为 `wx89ee56c51312f147`。本轮完成项目侧构建配置和检查入口，尚未构建、上传、扫码或完成平台后台验收。

## 构建配置

- 共享配置：`config/build/wechatgame.json`，可在 Cocos Creator 3.8.8 的构建发布面板中导入。
- 平台：微信小游戏 `wechatgame`；横屏：`landscapeRight`。
- 输出目录：`build/wechatgame`；启动场景：`Login`。
- 当前预设 `debug=true`，用于开发、体验验证。它不是正式提审配置。
- 微信构建扩展每次读取共享配置，应用 AppID、游戏名、横屏；原有 race/music 分包、字体、贴图、mip 链、主包大小和联机参数检查继续生效。
- AppID 是公开标识，可以随项目同步；AppSecret、上传私钥、平台登录凭证不能写入客户端或本配置。

## 本机操作顺序

1. 运行 `npm run wechat:check`，检查配置、字体和贴图策略。
2. 在已有的 Creator 工程中打开「项目 → 构建发布」，创建微信小游戏任务并导入 `config/build/wechatgame.json`。确认 AppID、横屏和 Login 启动场景后构建。无需手动改生成目录中的配置。
3. 构建完成后运行 `npm run wechat:check -- --build`。若使用其他输出目录，追加目录路径。此命令检查构建包身份和入口；完整 mip 链及主包体积检查由构建钩子执行。
4. 在微信开发者工具中导入 **`build/wechatgame`**，项目类型为小游戏，确认 AppID 为 `wx89ee56c51312f147`。不要导入仓库根目录，也不要使用测试号代替真实 AppID。
5. 使用已加入该小游戏开发成员的微信登录开发者工具，先编译，再通过「预览」扫码做真机测试。
6. 验证后使用开发者工具「上传」填写版本号及说明；在微信公众平台版本管理中选为体验版并配置体验成员。体验版与正式提审发布是不同步骤。

本说明不代表已上传或已通过审核。项目检查脚本不会启动 Creator、微信工具或上传代码。

## 体验验收

- iOS、Android 各完成冷启动、资源加载、单人比赛、结算、重启读取本地进度。
- 检查横屏安全区、左右触控、音频及切后台恢复；确认 ASTC 角色与泳池贴图无异常。
- 两台手机使用好友邀请完成建房、加入、选角、准备、比赛及结算；继续「再来一局」。
- 检查邀请冷启动/热启动、退房、断网重连和版本不匹配。
- 登录 `wx.login` 返回 code 仅证明平台接口调用成功；未接服务端换取账号会话，不等于云端账号系统完成。

## 正式提审前仍需完成

- 主体、游戏资料、素材权属、备案及适用的出版资质；隐私、实名及未成年人保护要求按后台核实。
- 清理或通过正式包开关关闭调试入口、免费加币、调参等能力；仅设置 `debug=false` 不保证业务调试按钮自动消失。
- 确认首发广告、云存档、排行榜的产品范围，并完成对应接入或隐藏未实现入口。
- 使用非调试构建重新通过包体、字体、贴图、代码检查以及真机回归，再上传提审。
