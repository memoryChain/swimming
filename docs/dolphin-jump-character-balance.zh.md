# 海豚跳角色差异化：200 米验证表

## 固定基准

- 赛程：200 米。
- 角色等级：30 级。
- 难度：竞技。
- 操作：熟练玩家，稳定交替划水，以 GOOD / PERFECT 为主。
- 不把碰撞补偿计入必达释放次数；单独记录碰撞补偿带来的额外能量。
- 每次海豚跳消耗整条 100 蓄气，不消耗普通体力，成功发动时心率 +25。
- 标准轨迹测试须直线游泳且前方空间充足，避免墙边自动压缩改变结果。

## 首轮通过标准

1. 每个角色至少完成 5 局无碰撞补偿的 200 米样本；成功释放次数的常见区间符合上表。
2. 前方空间充足时，高度、空中距离与滞空相对目标误差不超过 5%；墙边压缩样本单独统计。
3. 三角色在相近 GOOD / PERFECT 分布下，海豚跳带来的整场完赛收益差距控制在 10% 内；比较的是相对不释放海豚跳的完赛时间改善，不只比较飞行米数。
4. 灵波飞鱼应明显读成低平快速跃，铁臂狂鲨应明显读成高远重跃，破浪新星保持标准抛物线；不能只是同一动作的轻微数值差。
5. 单机、本地联机玩家、远端真人回放使用相同角色配置。AI 从明确的 `dolphinProfileId` 取配置，不能从随机模型外观推断玩法值。
6. 联机双设备验证能量归零、再次充能、起跳轨迹和落水衔接。不同设备必须使用同一份 `tuning.json`；调参面板的运行时修改不在房间内广播。
7. 显著视觉或轨迹调整最终需在 iOS 与 Android 微信小游戏真机验证。
